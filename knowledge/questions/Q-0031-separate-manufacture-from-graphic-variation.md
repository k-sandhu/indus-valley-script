# Question

Do fine modifiers, small marks added to signs, follow a production group or a category observed independently across production groups?

# Why it matters

A recurring carved feature can arise from manufacture as well as the inscription’s function.

# What is needed

Use high-resolution views we hold, tool marks, material and independently coded production groups. Keep the feature coder unaware of the category comparison. Read [DATA.md](../DATA.md) for the gaps this task depends on.

Sources: [knowledge/directions/research-roadmap.md](../directions/research-roadmap.md); [knowledge/directions/context-data-plan.md](../directions/context-data-plan.md).

# How to decide

Freeze the feature and the held-out production-group prediction before scoring. A pass requires transfer beyond production baselines; drop any feature with inadequate agreement between observers.
