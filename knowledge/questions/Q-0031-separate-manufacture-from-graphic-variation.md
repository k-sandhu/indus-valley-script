# Question

Do fine modifiers track a production group or an independently observed category across production groups?

# Why it matters

A recurring carved feature can arise from manufacture as well as the inscription’s function.

# What is needed

Use held high-resolution views, tool marks, material and independently coded production groups. Keep the feature coder blind to the category comparison. Read [DATA.md](../DATA.md) for the gaps this task depends on.

Sources: [knowledge/directions/research-roadmap.md](../directions/research-roadmap.md); [knowledge/directions/context-data-plan.md](../directions/context-data-plan.md).

# How to decide

Freeze the feature and held-out production-group prediction before scoring. Pass requires transfer beyond production baselines; stop any feature with inadequate observer agreement.
