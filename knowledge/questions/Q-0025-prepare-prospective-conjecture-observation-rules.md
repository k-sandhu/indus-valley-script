# Question

Can a contributor write reproducible rules for which future objects count, and how they are recorded, for the predictions about future finds on the three conjecture cards?

# Why it matters

A future assemblage should be judged under rules recorded before its outcomes are seen.

# What is needed

Write a protocol in a new dated package defining the publication cutoff, duplicate handling, complete faces, required fields and the existing pass rules. Leave the cards unchanged until a maintainer reviews it. Read [DATA.md](../DATA.md) for the gaps this task depends on.
