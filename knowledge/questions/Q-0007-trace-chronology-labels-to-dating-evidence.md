# Question

Which period and stratum labels in the Harappa block we hold can be traced to an excavation sequence and independent dating evidence?

# Why it matters

Tests of change over time depend on residuality (objects older than their layer), secondary deposition and how an excavated lot relates to an object.

# What is needed

Keep the raw phase terms, the sources' date ranges, the dating basis, disturbance and object–context links. Use the item and context tables we hold before designing a test over time. Read [DATA.md](../DATA.md) for the gaps this task depends on.

Sources: [knowledge/directions/context-data-plan.md](../directions/context-data-plan.md); [knowledge/directions/research-roadmap.md](../directions/research-roadmap.md).

# How to decide

Stop at the fixed set of sources. A calendar date for an object needs a cited phase-to-date model and a stated object–context relation; otherwise keep the source phase and mark calendar age unresolved.
