The user requested a deep unattended study and paper on the Indus excavation gap, the sizes of unexcavated sites, likely additional evidence and overlooked places. They added later cities, alluvium, mountains, caves, landslides and submerged coasts, then requested Claude Code Opus 5.5 CLI review and authorized Codex contributors. The work extends the preserved October 8 excavation outlook and does not rerun inscription research to estimate settlement coverage.

## Outcome

The [paper](../../papers/005-settlement-survey-gaps/manuscript.md) has approximately 12,400 words and a [33-page printable export](../../output/pdf/indus_settlement_survey_gaps_2026-10-11.pdf). A 72-record source register has 69 cited references and 50 local witnesses. Twenty-one editorial regions give archaeological questions, alternative explanations, sampling units and demotion rules. The package includes a source-linked claim map, original figures, aggregate code and an unrun block-level preservation pilot.

The familiar 96-of-roughly-1,000 account belongs to historical inventories. The reviewed 142-site excavation compilation covers Early and Mature phases through 2024, so it cannot form a current fraction with either old Mature-only denominator. Repeat studies have different outcomes: field-confirmed gaps in earlier reports, archaeological sites lacking map associations, unconfirmed remote proposals and finer mound units. Ganweriwala's 81.5-, 66.7- and approximately 33-hectare estimates measure different footprints. Geography alone cannot identify an unseen site's size. The reviewed evidence supports further contextual investigation without a national site count or artifact forecast.

## Review, design and preservation

The complete first draft was frozen before commissioned review. Distinct Codex contributors checked sources, numerical outputs, mountain/cave integration and the sampling design. The first manuscript audit found that P18 did not contain Ghazi Shah; a new box extends north to 26.6 degrees and contains the official Ghazi Shah and Kai points. Kalibangan and Sutkagen-Dor provide two additional published containment checks. These checks do not validate every proposal coordinate or intervening landform.

Two actual Claude Code CLI reviews used `claude-opus-5-5`. Tools were disabled, limiting them to the supplied authored packets. An invalid external API key initially prevented use of that route; omitting it only from the child process enabled the existing Claude subscription. The first completed review was saved before the wrapper encountered a relative-path metadata error. Recovery preserved the result and left unavailable exact invocation times and subprocess exit status null. The second invocation completed with exit code 0 and recorded its model. The [response](../../experiments/2026-10-11-settlement-prospection/review/response-to-reviewers.md) accounts for every finding.

Reviews materially changed the paper. They added local repeat-survey comparisons, clarified detection selection and chronological units, separated evidence classes from operational priorities, and removed synthetic fragment totals and inscription metadata from the main narrative. Capture–recapture remains a proposed framework with matching, common-frame and detection assumptions; its naive estimate is not a guaranteed lower bound. Structural classes invisible to all methods cannot be sized by adding a model term.

The pilot now uses blocks as inferential units, with profiles nested inside them. Descriptive preservation reporting uses all adequately resolved blocks; eight held-out blocks evaluate a prediction rule locked before their labels are released. A stratum with no adequate observations remains unresolved. Negative decisions require spatial coverage, visibility, depth and chronological resolution. Shared-frame rules cover every overlap, and known-margin calibration transects are excluded from negative draws. Separate demotion rules distinguish channel activity from later margin use, ancient occupation from Indus affiliation, and target-age survival from old substrate or young cover.

The final source/region audit recorded 127 passes and two clarifications. Its actual input versions remain in the log. Successor registers resolve the locator and apply P2 consistently as documentary archaeological survival somewhere in a region, including other periods. Every region has a rationale and F0, feasibility unverified. These editorial levels supply no discovery probability or target-parcel survival estimate.

Numerical runs and drafts were preserved rather than overwritten. The final main endpoint has 64 bookkeeping checks. A separate seven-row inline-arithmetic endpoint has 17 checks. The 32 metadata fields consumed by the numerical crosswalk match the original source register and final successor versions; constants reside in the preserved code. New narrative qualifications did not silently change calculations.

Full-size inspection also found a rounded diagram border slightly crossing the axes edge; a separate layout script repaired the spacing using frozen synthetic inputs. Both earlier exports remain local. All 33 pages were rendered with Poppler and inspected; changed pages were rechecked, while identical PNG bytes document unchanged layouts. The final export has 69 verified reference URLs and zero out-of-margin text spans. The [inspection record](../../experiments/2026-10-11-settlement-prospection/review/pdf-inspection.json) distinguishes export checks from scientific review.

Raw acquired material stays local; authored findings, code, pointers, hashes and original figures form the reusable package. No external submission, publication, field intervention, CI/CD or recurring automation was added by this task. Source-level coordinates, gazetteer concordance, accessible project footprints, local coastal/fan chronologies and partner calibration would make a new research run informative. Repeating broad site-count arithmetic or deriving an artifact total from the existing aggregates would not resolve the missing assumptions.

The first final verifier used newline-delimited text stdin for Git on Windows. Newline translation caused Git to inspect quoted paths with a carriage-return suffix, producing one false ignore-check failure. A successor uses NUL-delimited binary paths and passes all 41 checks. The failed report remains preserved; no source file or archaeological result changed during that repair.
