Question

Can the project hold one register with a row per physical object, separate tables for faces (the records of inscribed sides), images, identifiers, contexts and assertions (each recorded value with its source), and a value_status for every field, populated from all held sources and regenerated by one script?

Why it matters

Our first priority is a complete record of every object. Today the metadata sits in the Lipi export (our local transcription corpus), two packages of the evidence census, the object ledger pilot, tables of objects drawn from excavation reports and several study folders, each with its own keys. The target schema in DATA.md defines the fields and their current coverage; this task makes it a working dataset that later enrichment tasks write into and that coverage reports read from.

What is needed

Read DATA.md, the observation model in context-data-plan.md and the object ledger pilot. Start from the pilot's schema version 2 and its validator. Populate from the Lipi export and image index, the older Indus website export, the Mayig corpus of Mohenjo-daro unicorn seals, the museum records the census joined to objects and the ledger pilot first; add CISI basic data, excavation tables and chronology mappings as their tasks finish. Keep raw values beside normalized values, record each assertion's source and page, and keep the register under data/ with a tracked schema, build script and coverage report. Release of record-level data waits on Q-1028.

How to decide

Done when the build script regenerates the register from the manifest's sources without manual edits, the validator passes, and the coverage report reproduces the object-level numbers of the data inventory in DATA.md for the fields it already measured (for example 4,075 objects with a CISI number and 3,598 with at least one dimension). Any difference must be explained by a recorded rule change.

Prior attempts

The object ledger pilot built two trial registers of 200 inscribed objects each, with 6,991 and 7,004 assertions; the dataset landscape specified the register without building it.
