Question

G01, an eight-sign text, recurs on eleven Lothal sealings. Can an independent reading of our views of L206 reproduce the contact observation that ruled out angular board edges as G01's only attachment?

Why it matters

Where the repeated inscription was attached should rest on visible features.

What is needed

Code curvature, texture, cord path, coverage and stamp identity, masking the inscription where practical. Keep alternative readings and the limits of incomplete objects. Read DATA.md for the gaps this task depends on.

Sources: knowledge/directions/decipherment-readiness-2026-10-02.md; experiments/2026-10-02-six-hour/lothal-physical-use/README.md.

How to decide

Pass the narrow contrast only if independently linked images show the incompatible geometry. Stop if the contact shape is not visible, and report the unresolved feature instead of a category label.

Prior attempts

LOTHAL-TRACE-01; ARCH-02. Read their outcomes and retry_when conditions before running this task.
