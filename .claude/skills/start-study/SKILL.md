# Start study

Search prior attempts and read their retry conditions and retrospectives. Follow [CONTRIBUTING.md](../../../CONTRIBUTING.md) and the [experiment template](../../../templates/EXPERIMENT.md): create a dated owned directory, record the protocol before outcomes, then add a file in [registry/attempts](../../../knowledge/registry/attempts/). Choose fields from [VOCABULARY.md](../../../knowledge/registry/VOCABULARY.md); preserve earlier endpoints and disclose model and harness.

For a reading, sign key, meaning map, inscription conjecture, restoration model or segmentation, select the relevant [bench task](../../../bench/README.md) in the protocol, exercise its synthetic mode, and declare the comparison and pass rule before outcomes, recording the resulting versioned JSON and hashes in the owned package. For archaeological, urban, archaeobotanical, comparative or formal-model studies outside the inscription corpus, declare and record the matching domain controls, source checks and verification outputs instead. Acquire or restore required local inputs through `knowledge/DATA.md` and `tools/fetch_data.py`.

Put new raw inputs under `data/raw/YYYY-MM-DD-slug/`, keep them local-only, and record logical and physical paths as described in [LOCAL_STORAGE.md](../../../LOCAL_STORAGE.md).
