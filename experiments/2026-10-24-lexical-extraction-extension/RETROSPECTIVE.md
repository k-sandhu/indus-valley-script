# Retrospective

The prior review supplied concrete failure cases and forty source judgments. We used those records to define an extraction repair before running the complete dictionaries. We kept the original parser and the source-review guard unchanged, imported them through an owned adapter, and separated the parser's output from exact-headword boundaries supplied by the Tamil Lexicon. This separation preserves the dependence between dictionaries for any later comparative study.

The increment rule generates analyses from a noun ending in u and an exact second noun. It replaces the final u with am and checks the matching nasal before a stop. The dictionary's connecting-particle entries and the reviewed botanical compounds motivate this candidate generator. They do not establish the rule's full grammatical distribution. We therefore retain the candidates as unresolved morphology and leave their selected members empty unless a separately printed boundary supplies them. The source lemma murukku also retains its doubled consonant; no rule changes it into muruku.

The first provenance scan printed no progress and wrote no endpoint during several minutes of low CPU use. Direct source-read checks succeeded. We stopped that scan before it produced an output; the process returned exit status 1 without a traceback identifying a stalled operation. We added a resumable per-page hash log on D:. The replacement scan records the precise logical and physical path, bytes and content hash of each completed page and completed successfully. This implementation repair changed no extraction outcome. Terminal output then needed regular draining while the foreground process advanced. During the second complete hash verification, Windows process counters showed the read-operation count advancing from 2,073 to 3,539; this was slow progress, not an identified stall. We have no measurement that attributes the delay to one file or to storage hydration. The final frozen manifest precedes the full extraction.

The sequential source verification was stopped before writing an extraction output after its read count had reached 4,811. We preserved its frozen adapter and added parallel content verification with a per-run hash cache. This checked every source hash in seconds and avoids reopening a page for each row's provenance. The subsequent full parser encountered two malformed headword blocks that the original parser skips. The selected-entry guard had required one parsed principal for every block; we retained and counted the original skip rule. Freeze versions 1, 2 and 3 and the two earlier adapters preserve these pre-outcome implementation changes.

The first regression validator expected both known botanical increments to produce candidates. The complete source metadata instead shows that cettal is labelled a verbal noun. Our frozen generator requires exact noun principals, so the dry-wood compound falls outside its scope. We retained that outcome and corrected the validator's expectation; validation version 1 and its failing check remain preserved. Version 2 passes and explicitly checks the source-backed exclusion. We did not expand noun eligibility after seeing the outcome.

The focused tests exercise exact source identity, ambiguity, the inherited roman-transcription alignment convention, grammatical roots, parent borrowing marks and increment candidate status. The synthetic segmentation and shots runs test the existing harness. All source checks in this package are author checks. They cannot substitute for an independent Tamil specialist's review.

Parent code review then found that the increment generator uses the inherited e/ē and o/ō folding outside cross-dictionary source alignment. The report's restriction of that convention to exact Tamil-headword alignment was therefore wrong. The existing ambiguity test even accepted pe and pē noun alternatives, but our author review failed to connect that behavior to the frozen exact-match requirement. We preserved the frozen adapter, extraction, candidates and previous report text. A new audit checks exact surface reconstruction, left increment formation and right lemma equality for every candidate. It finds two folding-dependent analyses among 59, both failing exact right-lemma equality, and supplies a separate 57-analysis exact subset. All 57 rows retain one exact analysis. Five focused audit tests pass. The original and filtered candidates remain unresolved and scorer-ineligible; no substantive statistic was rerun.

The remaining work concerns the interpretation of the extracted records: noun sense, borrowed ancestry, native picture eligibility, phrase boundaries and historical attestations. Principal compounds lacking etymologies or a matching printed Lexicon boundary also need separate recovery. The extraction and exactness audit make these decisions visible and reproducible for the next contributor.
