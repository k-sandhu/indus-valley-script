# Visual-atlas retrospective

The earlier slide deck explained the results with charts and tables. We expanded it into 32 separate graphics so that the reader can inspect architectural directions, source images, uncertainty, dating and horizons at a larger scale. Direction diagrams draw the published angles to scale and label their schematic segment positions. Source plates retain their original plans or imagery, their locators and their handling status.

The first run stopped at a horizon-count assertion. Thirty usable profile records describe twenty towns because some compilations use different observer points. We retained every usable record in the comparative plots instead of selecting one profile silently. The second run stopped while drawing Lothal error bars because Matplotlib accepted a colour sequence for the error-line collection but not for the cap lines. We drew each product's interval separately. Earlier run outputs remain on D:.

The third run produced all 32 graphics. Review found an overlap between the Harappa and Banawali labels on the location plot and wording that counted towns as profiles. The fourth run moves the label and states the coverage unit explicitly. The underlying observation files remain unchanged. The register's point errors, uncertainty bounds, partial errors and unquantified horizon error retain their separate meanings.

PDF assembly preserved the individual vector figures and added a cover, catalogue and bookmarks. A ZIP check ran before the writer closed and reported failure. Reopening the completed archive passed its CRC checks. We moved verification after writer closure and preserved the original archive. The final archive carries the corrected packaging and verification recipes under a new filename. The atlas PDF itself did not need replacement.

We inspected the figures and rendered all 35 atlas pages through Poppler. Source hashes, all 96 figure-file hashes, PDF text placement, page count, bookmark count and archive integrity pass. The four source plates and the DEM-derived plots remain in the D: local outputs. The package changes no archaeological coverage and spends no confirmation population.
