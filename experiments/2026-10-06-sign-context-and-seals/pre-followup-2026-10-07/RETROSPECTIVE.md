## Computation and refinements

The first run used 4,695 physical components and retained whole text payloads in every reference. Simple side-alias union did not merge additional numeric families; five ambiguous references were left unresolved. Sparse object-type groups can separate binomial nuisance coefficients, so a predeclared nonintercept ridge of 0.000001 made all 30 descriptive fits converge. No fit was treated as independent token-level evidence for a site-size effect.

The original area-vector reference gave sign 520 q = 0.044 across 17 sites, but ten sites had fewer than 20 readable objects. The reference exchanges site-level residual estimates with unequal precision. The dated amendment specified a second law that moves whole object site labels inside type blocks while keeping area fixed. Its q = 0.223 for 520, and the seven-site adequately sampled comparison had no corrected result. Both endpoints remain visible; the report does not retain the original borderline area claim.

The original rare/unicorn comparison gave both longer unicorn texts (q = 0.0012) and sign-distribution divergence (q = 0.0033). The amendment conditioned motif-label exchange on exact length as well as site/type. The divergence then had q = 0.20525, while length was invariant in every reference. The exploratory file preserves the original statistics and labels the additional law. Its helper returned a nested frozen-status label; `SOURCE-NOTES.md` explicitly states that the enclosing exploratory status governs it.

Dimension parsing treated zero as missing and left ranges unconverted. Exact `complete` preservation selection excluded an apparent spelling error and ambiguous preservation records. The primary size sample had 1,027 square-seal objects; an all-preservation sensitivity retained 1,451. Both had CV near 0.29. A later exploratory supplement counted every seal type and missingness reason, because scalar thickness summaries alone concealed 407 range-valued records. It made no new inferential test. Catalogue unit conversion and rounding still limit an ancient-unit or tolerance argument.

## Checks and remaining work

The first and verification directories were created separately; existing outputs cannot be overwritten by the analysis. The verifier reconstructed corpus totals, selected counts, HHI and CV, recomputed 82 saved permutation tails and exercised transitive grouping and block preservation. The script compared the five analytical file hashes; the input-summary timestamp/runtime naturally differed. The prose scan and file inventory document the final written package without editing shared files.

The final checker recomputed another 26 exploratory tails and used SciPy's Benjamini–Hochberg implementation to check all correction families. Its first invocation used an incorrect JSON field name for the across-site correction and stopped before writing a result. Changing that lookup to `q_bh_across_sites_and_outcomes` completed 43 checks. Adding a fresh-output command option to the descriptive supplement allowed a byte-identical rerun without replacing its endpoint. The final prose scan reports zero flags across six Markdown files.

A separate reviewer should rerun the command in [README.md](README.md), sample the area witnesses, inspect catalogue measurement conversion and preservation labels, and verify the inherited-versus-enclosing status note. Better archaeological comparisons need occupation-area estimates matched to dates, excavation denominators, minority-motif samples at several sites, original measurements and independent workshop/carving-style assignments. Those missing observations prevent the concentration figures from choosing among the political, production and recovery explanations.
