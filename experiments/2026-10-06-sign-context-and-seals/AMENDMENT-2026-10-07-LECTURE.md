## 1. Inventory, sample size and site area

For every site with readable principal objects, report object count, readable-token count, observed richness, token singletons/doubletons and object-incidence uniques/duplicates. Also report all-face richness. Compute exact finite-sample hypergeometric rarefaction: `sum[1 - choose(N-f,k)/choose(N,k)]`, using abundance counts for tokens and incidence counts for objects. The token curve is a descriptive independent-token model; no token-wise bootstrap or token-wise permutation supplies a significance claim. Object curves retain each object's full sign set.

Use the standard Chao lower-bound unseen estimate: `(N-1)/N * f1^2/(2*f2)` when `f2>0`, and `(N-1)/N * f1*(f1-1)/2` otherwise. Replace N/f with object count T/incidence frequencies for Chao2. Extend richness by `Sobs + f0 * [1-(1-f1/(N*f0+f1))^additional]`. Limit extrapolation to twice the observed token or object count. These fitted curves are point estimates; unseen-sign dependence and excavation selection are not estimated by a token-level confidence interval. Mark a zero unseen estimate or single-object sample as insufficient for an asymptotic inventory conclusion.

The sample-size test permutes whole object site labels within **exact object type and exact readable length**, preserving every site's object and readable-token counts. Recompute site richness in every reference. This provides a shared inventory curve conditional on the observed sample sizes and type composition. Include all labels in exchange blocks, but test geographic sites with at least 20 readable principal objects; `Unknown` is descriptive. Use two-sided deviations centred on the reference mean, Monte Carlo tails and BH across eligible sites. Give pointwise reference intervals and simultaneous 95% bands from the maximum absolute standardized deviation, with immovable/zero-variance sites identified. Report which sites lie outside either comparison and compare observed richness with the lecture's stated bands. Join the frozen area/type table for context without treating inscription counts as a measure of physical site area.

## 3. Terminal 740

Primary texts are complete observed, single-line principal faces, with specified R/L or L/R direction, no `000` and at least two positions. Report singleton 740 separately because its terminal status is forced. For global, site and exact object-type groups, report 740 occurrences, texts containing it, texts ending with it, final occurrences/all 740 occurrences, and ending texts/all texts.

The position-matched expectation is conditional on each object's exact length and inventory: its probability of 740 at a uniformly selected anchor is `count740/length`. Sum independent object-level Bernoulli anchor indicators to obtain the exact Poisson-binomial upper tail for terminal enrichment. This reference chooses one anchor per whole object and does not resample tokens or rearrange the observed sequence. Confidence intervals for the excess ending-text rate resample whole principal objects within exact type blocks. Report the matched reference interval. Test global enrichment separately, and BH-correct the site/type groups with at least 20 eligible objects together. No terminal test is run on an assumed direction. This probes position under an explicit unanchored reference, without assigning a sign meaning.

## 4. Harappa motif persistence with interval dates

Primary population is known-motif square-seal components at Harappa labelled Period 3 or a 3A/B/C subphase. Kenoyer's published intervals are 3A 2600–2450 BCE, 3B 2450–2200, and 3C 2200–1900. Subphase labels inherit their parent's whole interval; no internal subphase date is invented. Period 3B/C spans 2450–1900, and unspecific Period 3 spans 2600–1900. Unknown periods and later Period 4/5 records are listed separately. The primary range spans 700 years and cannot supply a millennium-long evaluation.

Give unicorn, Gaur and other motif shares and whole-object bootstrap intervals by raw label and coarse unambiguous parent phase. Include Wilson intervals for unicorn share so a sample containing only unicorns does not imply certainty. Test (a) a categorical unicorn-share statistic over raw labels with at least ten known motifs and (b) a temporal score using the interval's expected time. Exchange complete motif payloads against interval/period labels within exact object type; retain one object per physical component. Correct these two tests together. Also give an untested three-category concentration description.

Fit an interval-integrated logistic model of unicorn share: for each object, average `logit^-1(a+b*t)` uniformly across its allowed interval, with t measured in centuries after 2600 BCE. Report the fitted change from 2600 to 1900 and its 95% profile-likelihood interval, allowing the intercept to vary. The uniform latent-time assumption is a model, not a dated observation. State the size and direction of changes outside that interval that the model excludes, and check optimizer/profile boundaries.

For a distribution-free dating sensitivity, compare unambiguous 3B with unambiguous 3C and enumerate every assignment of 3B/C unicorn and minority counts to either phase. Give the sharp observed-share difference range and the envelope of Bonferroni 97.5% Clopper–Pearson share intervals, which yields at least 95% coverage for the difference under independent physical objects. Exclude unspecific Period 3 from this two-phase calculation and report that exclusion. This sensitivity does not force an ambiguous object into a preferred date or infer stability from a non-rejection.

## 5. Core and external motifs

Core regions are the export's Lower Indus, Upper Indus, Inter-Riverine, Eastern Headwaters and Gujarat/Kutch. External regions are Persian Gulf, Mesopotamia, Iranian Plateau and Central Asia. Other and South India remain separate because their provenance/type does not identify a comparable Bronze Age regional sample. Give Persian Gulf plus Mesopotamia as a restricted external sensitivity. Region classification refers to find locations, not manufacture.

Bull1 suffixes identify the unicorn proxy. **Gaur** is the strict available-code proxy for Indian bison/Bos gaurus, supported by the 2016 Salūt article's biological identification. The export mapping is not a photographic check of every object; keep Bull, Bult, Zebu, Buff and composite scenes separate. Also report the combined bovine-code share as a broad diagnostic, not as authenticated bison classification. Describe all seal types and give square and circular type-specific counts, since the published external discussion emphasizes Gulf-type round seals.

Compare unicorn core-minus-external share and Gaur external-minus-core share. Permute complete object region-class labels inside exact object-type blocks, use two-sided centred reference deviations, and correct the two comparisons together. Repeat the restricted external comparison as a declared sensitivity. List all external physical objects, their face aliases, catalogue references, site, region, object type and available motif in a local-only CSV/JSON; report aggregate site/type counts in the owned directory.
