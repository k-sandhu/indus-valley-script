# Publication screen of untracked files, 13 October 2026

This protocol was written before any file was screened. It defines how the untracked research packages, navigation files and the twelve modified tracked files are classified before the coordinator commits them to the public repository `k-sandhu/indus-valley-script`. The screen applies the decisions of the [October 11 asset review](../2026-10-11-public-release/ASSET-REVIEW.md), the [redistribution record](../../knowledge/provenance/REDISTRIBUTION.md) and section 7 of [DATA.md](../../knowledge/DATA.md). It edits no existing file. Its outputs are a decision per file or homogeneous group, proposed `.gitignore` lines and proposed additions to the public omission list.

## Scope

The file list is frozen at the start of the run from `git ls-files --others --exclude-standard` and the modified entries of `git status --short`. Paths, byte counts and SHA-256 hashes go to `data/raw/2026-10-13-publication-screen/inventory.json`. Files that parallel contributors add after the freeze are reported as a delta, screened by the same scripts if time allows, and otherwise listed as unscreened. This package's own outputs are excluded from the frozen list and screened at the end.

## Checks

**Lipi sequences.** The Lipi export has no licence, so tracked files may hold only aggregates, identifiers, short attributed examples of at most three consecutive codes, and the twenty catalogue windows already published. The reference index is built from `data/normalized/lipi_observed_faces.jsonl` and `lipi_observed_parts.jsonl`: every contiguous window of four codes in reading order and in visual order, from whole faces and from single lines. Windows made only of the unknown-sign placeholder `000` are dropped. Every text file in scope is tokenized into runs of three-digit codes separated only by spaces, commas, quotes, brackets, `+`, `-`, `/`, `|`, `>` or `.`; a run is broken by any letter or other character. Each run is slid in windows of four and checked against the index. Per file the screen reports matched windows, maximal matched stretches by length, stretches equal to a complete Lipi text of length four or more, and the longest stretch. A second, looser pass also accepts one- and two-digit integers padded to three digits, to catch codes written as JSON numbers; it is used to find files the strict pass missed and is not itself a decision rule. A file with any matched stretch is inspected by hand to decide whether the stretches are Lipi texts, generated or synthetic units, or coincidences in numeric data.

The decision rule for sequence content is fixed now. A file whose inspected matches include full Lipi texts or reconstructable contextual windows longer than three codes is `keep-local`, unless the matches are confined to a small section that can be removed without changing the frozen result, in which case it is `track-after-edit` with the edit named. Frozen endpoints are never edited by this screen; an endpoint that needs an edit is kept local instead, and a later dated derivative may be proposed.

**Record-level field signatures.** As on October 11, each JSON, JSONL, CSV, TSV, MD and HTML file is counted for field names that carry corpus records or source text: `signs_reading_rtl`, `signs_visual_ltr`, `text_code_visual_ltr`, `sequence`, `target_code`, `source_text`, `caption`, `excerpt`, `<LEND>`, `translation`, `transliteration`, `quote` and `quotation`. Counts of fifteen or more queue the file for inspection.

**Third-party text and images.** Every binary or image file (PNG, PDF, SVG with embedded rasters) is identified by origin from its package manifest or generator script. Imagery must be project-generated, a crop of the CC BY 1979 Helsinki chart with attribution, or an openly licensed product whose attribution is recorded (Sentinel and Copernicus products, Natural Earth, OpenStreetMap under ODbL, Leaflet under BSD-2). Commercial basemaps, CISI photographs, Lipi image crops and unlicensed scans are `keep-local`. Text payloads in the Bronze Age package and the semantic comparison are inspected for edition texts (Sumerian, Akkadian, Egyptian, Linear B), dictionary entries and quotations longer than about fifteen words. ORACC material is CC0 and can be tracked with attribution; AED-TEI and AES are CC BY-SA 4.0 and can be tracked only with that notice and share-alike scope recorded; LiBER and dictionary text without an explicit licence stay local. Short quoted wording with a citation, used for a stated purpose, is retained as on October 11.

**Credentials and personal data.** All files are scanned with the October 11 token pattern extended to Hugging Face, AWS, Google API keys, Slack tokens, bearer headers, cookies and signed-URL parameters (`X-Amz-Signature`, `Signature=`, `sig=`, `token=`), and for email addresses. Email addresses are reported masked. The owner's address must not appear anywhere. Personal names are reviewed only where they are not authors of cited publications or public tool maintainers.

**Size.** Files over 50 MB are flagged for GitHub's warning and over 100 MB for rejection. Files over 5 MB are reviewed for whether they are derivable from tracked inputs and seeds. A large derivable output whose generator, inputs and hashes are tracked can stay local; a large frozen endpoint that is the only record of a claim is retained unless another check excludes it.

**Earlier decisions.** Paths matching the October 11 omission list, the `.gitignore` local-only rules or `tools/audit_git_payload.py` forbidden paths are flagged. The modified tracked files are screened for the same content and for changes that remove existing exclusions.

## Outputs

`decisions.json` holds one entry per file or homogeneous group with `path` or `glob`, `decision` (`track`, `keep-local` or `track-after-edit`), `reason` and `evidence`. `proposed-gitignore.txt` holds the exact lines for keep-local files, written as anchored paths in the October 11 style with a comment per group. `proposed-public-omissions.json` lists keep-local files that public navigation refers to, in the format of the existing `public-omissions.json`. `summary.json` gives counts and bytes per decision. Intermediate files that list sequences or third-party content go only to `data/raw/2026-10-13-publication-screen/`, which the existing `/data/**` rule ignores.

The screen is bounded. Pattern matching finds the forms of sequence, credential and quotation it is written for; files are opened by hand where a check fires or where the origin of an image or text payload is not recorded.
