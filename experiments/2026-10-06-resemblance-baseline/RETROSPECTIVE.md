# Source and computation retrospective

The pilot completed a declared descriptor comparison and an independent coding sample. It did not recover the complete 2025 monograph or implement a generator of new geometric drawings. All endpoint outputs remain in `run-v1/`; uncertain coding and source failures remain available for review.

Before research, the repository guidance, writing and redistribution rules, registry and relevant October 2 South Indian report and retrospective were read. Registry entries TN-STROKE-01 and TN-SOURCE-02 document the earlier brochure mismatch and source limitations. The pilot reused that source audit, the preserved brochure, the base-sign crosswalk and atlas source coordinates. The Mayig schema was inspected but contains a different sign-feature schema and was not used for manual shape measurements. The 2026 volumes were available; a heading search in volume I did not locate an uppercase base-sign table and was not treated as a full-volume reading. No earlier numerical endpoint was rerun.

The analysis computes finite-inventory coverage, subsampling intervals and descriptor collisions. Exact formulas check the Monte Carlo means. Raw query matches stay local; aggregate outputs carry input, code and protocol hashes. A read-only rerun reproduced every aggregate and query result exactly. Source-sheet preparation also regenerated the seeded selection and drawings in a new raw directory. The acquisition script was then changed to require a fresh subdirectory, preserving the original failed requests and successful witnesses on future runs. [verification.json](verification.json) records the final checks.

The pilot establishes that the computational baseline and manual codebook are usable for a bounded comparison. Its strict descriptor has lower agreement than the coarse rules, the inventories have different complexity distributions, and several drawings require better sources. These measured obstacles define the next work: recover the full matching method, improve the drawings, use trained human coders, balance control inventories and validate a generator on held-out geometric forms.
