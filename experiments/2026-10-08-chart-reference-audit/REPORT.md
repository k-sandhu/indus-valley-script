# Printed numbers on the 1979 chart

The proposed v2.1 reference changes eight primary codes and two upper classes among 687 chart cells. It provisionally resolves all 16 retained lower-code ambiguities. Twenty-two rows change values or alternatives; confidence updates bring the total to 36 changed numeric records. The reference has 687 distinct lower codes. The classes span 1–401 without a decrease or missing class. These are the final values of [comparison-v2.1.json](comparison-v2.1.json), `summary`, and [chart-reference-v2.1.json](chart-reference-v2.1.json), `rows`. The current reference is v2.1, dated 8 October 2026, with status Exploratory: two AI readings, no expert review. It has 33 medium-confidence cells and 654 high-confidence cells. The amendment lowers 32 labels from v2; the already medium 333 remains medium. Confidence is qualitative and uncalibrated. The confidence rule and every reason are recorded in `cell-observations-v2.1.json`, `review_amendment.confidence_reasons`.

## Method and scope

[PROTOCOL.md](PROTOCOL.md) preceded the new readings. Full pages were rendered at 6 pixels per point, and every cell at 8. Forty sheets displayed the printed class, drawing and lower code with cell identities; old numeric readings were absent from the sheets. [visual-readings.json](visual-readings.json), `columns`, stores every first-pass pair. The first pass differed from the original at 21 lower codes and two classes. Fifteen of the 21 code differences were reader errors corrected on reinspection. In the original audit, 630 cells were read once by one model and checked only by the class and code sequence. Two final corrections, `p20_c4_r1` and `p21_c6_r31`, followed hints from the v3 adjudicator. A rule selecting mismatches, old ambiguities, difficult-digit notes and repeated first-pass codes selected 56 cells. Follow-up inspection of the added v3 hypothesis produced 57 distinct reinspected cells. Full-cell reinspection used 16x renders; difficult comparisons also used 24x digit bands. The review follow-up inspected eight native cell crops, adding six previously unreinspected cells and bringing the audit model's total to 63 distinct reinspected cells. This does not change the historical count of 630 initially read once. No OCR or PDF text layer supplied values.

The embedded page image is a 4880 by 7010 one-bit raster at about 8.34 pixels per point. The 16x and 24x renders enlarge the same pixels and add no scan information. Confidence is an uncalibrated visual judgement. The original audit used one model for both passes. The reviewer later read 63 cells blind, including 23 core cells and 40 random cells selected with seed 20261008. Its five initial 5/6 eye-pass disagreements were resolved on native pixels. All 63 final classes and codes agree with v2 and v2.1. The whole-chart pixel sweep agrees on code values and identified the additional class correction. Its 939-digit nearest-neighbor check agreed on 938 digits, with the same class digit as the sole exception. These checks reuse model-labelled templates; they do not certify expert accuracy. Two sweep cases remain unsettled by pixels: code 734 at `p21_c7_r21` and the faint first digit of class 300 at `p21_c4_r21`. Both are now medium confidence. Exact witnesses are `review/reading-comparison.json`, `review/knn-5-6-8-check.json` and `review/pixel-check-mismatch-resolution.json`. The complete evidence is in `cell-observations-v2.1.json: rows`, and the first pass and later changes remain separate. This package audits this edition's printed numbering; it provides no sound or meaning assignments.

V2.1 retains all original row fields and auxiliary flags. Its comparison against the original contains 36 changed numeric records, including 22 rows with changed classes, codes or alternatives. The amendment appends dated logs to 32 rows that differ from v2 in confidence or class. All 687 rows received a new `source` string in v2, and all 687 receive updated review provenance in v2.1. These global provenance updates are excluded from the numeric-change counts. V2 and the reviewer files remain unchanged; `preserved-inputs-v2.1.json` pins them. The original PDF, atlas metadata and numeric reference retain their initial hashes. Consumer hashes are in [consumer-input-integrity-v2.1.json](consumer-input-integrity-v2.1.json), `inputs` and `unchanged`; mechanical coverage and replay checks are in [verification-v2.1.json](verification-v2.1.json), `checks`.
