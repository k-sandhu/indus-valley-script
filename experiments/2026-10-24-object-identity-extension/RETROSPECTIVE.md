# Retrospective

We selected a contiguous 28-row Dholavira block because every candidate already carried an accession and two table serials. The earlier identity audit reviewed metadata without opening primary pages. Direct primary checks could therefore establish whether the cross-references actually held before the project used them in another register layer.

We extracted only serial and accession columns and compared each target in the context table with its individual catalogue entry. The two arrangements agreed for all 28 rows. The accession pairs provide a reproducible source identity layer, while the missing corpus concordance leaves all family links at candidate status.

The page-location command exposed descriptive remarks and inscription counts in page beginnings. An initial identity clip was also too wide. We recorded the exact affected pages and content types and narrowed later display. The word-coordinate verifier initially missed an accession crossing the clip edge and a serial above its assumed top margin. Corrected coordinate bounds passed all 56 observations. The raw outputs and exposure records remain on D:; source hashes and aggregates stay in the experiment package.

The contributor was gpt-6.1-sol using Codex collaboration. No separate reviewer participated. The strongest supported result is a checked two-table source identity for each of the 28 registrations.
