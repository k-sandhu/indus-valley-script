# Retrospective

The seven-row block combined two different access problems. Harappa references contain lot and item numbers but do not name the publication behind their figure labels. Dholavira's short numerical references lack a verified namespace. Reading the primary Harappa identifier convention improved the lookup targets without supplying object photographs.

The Dholavira report yielded a useful composite metadata match. Grid square, depth, location and dimensions led to accession 20781 and its illustrated entry. The published caption's eight-sign count disagrees with the export's nine, and the numerical concordance remains absent. Keeping that candidate outside the admitted recovered-face count preserves the evidence needed for review.

Direct Harappa requests returned 403 while web text access returned captions. The publisher and institutional CISI routes provided bibliography; the store's HTTP 200 response was a bot challenge. Recording content admission beside transport status avoided counting it as a successful source acquisition. The 1999 report's PDF lacked text, so we searched its existing OCR separately and retained the limitation.

A script called inspect.py shadowed Python's standard module and stopped PyMuPDF imports. Renaming it to inspect_sources.py repaired the run. A first table crop landed on row 48 and a second missed the rightmost columns; both were retained before the full-width version 3 was saved. The review caught these defects before admission. Search-bound overruns for two identifier stems and a figure query are disclosed in the report and local search log. Future searches should count object-specific and figure-specific queries together.

Parent review found that Windows path separators prevented logical-path prefix removal in version 1. Version 2 repairs those fields and adds a relative-path check. Both versions are preserved, and the scientific counts remain unchanged.
