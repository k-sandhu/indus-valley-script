# Kanmer inscribed pendants: source and physical-use audit

This audit will reconstruct the source evidence for the three Kanmer clay objects discussed as identity cards, passports or access passes. The existing literature audit preserves Mukhopadhyay's 2023 functional interpretation, while the registry contains no Kanmer object-level acquisition endpoint. The new evidence sought here is the original excavation description, individual registrations and contexts, source figures and physical traces behind that interpretation.

Initial public search snippets have already exposed a three-object group, a reported common stamped face, individually differing reverse marks, a perforation measurement and a pointer to page 832 of the 2012 excavation report. The protocol is therefore a bounded source-annotation plan. It makes no blind selection claim. Write and hash this file before acquiring or annotating the new object outcomes.

## Frame and acquisition

Seek the 2012 final excavation report and the earlier annual reports through institutional, publisher and author-hosted public routes. Also seek the original 2010 Antiquity project report and its figure assets, cited work by the excavators, and the earliest accessible source of the passport suggestion. Retain the complete three-object group, including unreadable faces and missing registrations. Add another object only when an original source explicitly connects it to the group's stamp, reverse marking or operational interpretation; record the inclusion reason.

For each acquired source, preserve the URL, title, authors, publication date, retrieval time, format, byte count, SHA-256, pagination and visible rights notice. Record ordinary failed routes and source-title mismatches. Keep downloaded PDFs, images, HTML and extracted text local-only under `local-witness/`. Track our acquisition code, source assertions, annotation protocol, object ledger and aggregate results.

## Object annotation

Record each source's individual object ID, registration and figure position separately. A matching caption is needed to join a displayed specimen to an excavation entry. Preserve unnamed figure positions as stable source-relative IDs when the report supplies no registration. Record material, dimensions, physical faces, perforation position and axis, attachment or wear traces, stamped versus incised marks, broad sign count and layout, motif, impression polarity, production sequence, breakage and find context. Distinguish visible observations, author-reported measurements and published interpretations in the ledger. Source dating should include its basis and exact context join.

Inspect original figure pixels before transcribing graphic details. Preserve first annotations and later reinspections as separate records. Report whether shared-stamp identity is an author assertion, a visible correspondence or a measured matrix match. Do not merge differently worded material or face descriptions silently. The analysis will count acquired objects, faces, source-supported joins, missing fields and disagreements.

## Operational question

Trace which source first proposes pass use, which observations it cites, and whether later reports add physical evidence. Build explicit predictions for the object's handling: suspension, portable display, closure attachment, repeated checking or disposable distribution. Evaluate only observations actually acquired. A useful result is a source-to-object ledger that identifies which physical measurement could discriminate those operations. Preserve competing supported operations and missing data together in the methods description.

## Completion and reuse

Deliver a concise report, source ledger, object and face observations, access/failure record, reusable helpers, verification and retrospective. Link claims to source coordinates and saved outputs. Preserve dated endpoints and report changed paths to the parent. Perform no Git actions, shared registry edits, CI/CD, automation or external messages.

Write to maximize reader comprehension. Explain observations and assumptions together in connected plain prose; avoid repeated corrective comparisons, stock phrases and warnings that interrupt the argument. Review the prose before handoff.
