# Acquisition and analysis retrospective

The existing literature audit discussed Kanmer as a possible access-control case through Mukhopadhyay's 2023 interpretation. This branch acquired individual source entries and physical views. Its useful additions are a four-object photographic frame, seven restored registrations across the expanded comparison set, the original three pendants' dimensions and contexts, and labelled 2012 scanner views with method provenance.

The final excavation volume was initially found as a catalogue entry with ISBN 9784902325720 and 844 printed pages. An original Antiquity publisher page supplied three-object photographs. Its April 2026 online date reflected the current platform; the retained citation was March 2010. A relative PDF link failed with `MissingSchema`, then succeeded after resolving it against the publisher origin in a new acquisition endpoint.

The public author chapter route returned a challenge to ordinary HTTP requests. A public preview supplied original chapter text and figure atlases through URLs explicitly exposed on the page. Those atlases contain clipped figure material rather than complete page screenshots. The Chapter 8 page 5 atlas shows the broken 06-1054 object and comparative material; it does not contain a missing three-pendant photograph. This distinction prevented a false figure assignment.

The Occasional Paper 10 preview used private-use characters for digits. Mapping U+F0030–U+F0039 to decimal digits recovered the dimensions, and the decoded numbers were checked against independently readable report text. The original characters, decoded view, mapping and hashes are preserved locally. The institutional multicultural-site PDF supplied the same three-object arrangement; its filename's page range differed from its printed pages, so the ledger uses the inspected headers.

The 2023 author page supplied complete chapter text through the web reader. Its PDF button opened a signup/login invitation, which was closed. The in-app browser was unavailable; ordinary Chrome browsing could access the public figure pages and their visible Download figure links. One image locator matched two page elements, so the visible download link supplied the exact asset URL. No account was created or used. The acquired native composite shows four fronts and four numbered reverses, adding an unregistered specimen to the source frame.

The automatically selected public figure-page caption described upper signs while the downloaded pixels showed a two-hole shell object and faience seal. Printed chapter captions and image inspection resolved the mismatch. This makes original pixels necessary for source joins even when a public page offers plausible extracted text.

The proposed passport use was traced to the acquired May 2010 Science news report, where Lawler attributes it to Osada. The author's website has a misleading January date and retains errors corrected in the journal. Institutional brochures supply a permissioned photograph and small article excerpt/thumbnail. They do not reproduce the whole original article. The public 2009 journal route returned an HTTP rejection; the web reader revealed that its PDF was only a four-page contents list. The earlier article remains a source gap.

A search for the cited 3D methods led from NDL's digital chapter entry to the Science Tokyo repository. The web reader returned 403, while a normal public HTTP request acquired the metadata page. Its PDF-icon link yielded a 49.5 MB author copy containing Chapter 5. The inspected file supplies numerical object-stem captions, front/reverse views and profiles, and names the scanner and wrapping procedure. It contains no embedded mesh file.

The first image extraction assumed PDF resource order followed page layout and assigned six wrong caption filenames. Image rectangles exposed the error before the object analysis. The first images, manifest and code are preserved. A new endpoint sorts images by their printed page positions, checks the captions and retains unchanged embedded raster bytes. The audit's 129 checks include all corrected xref/caption pairs and source hashes. A terminal read also encountered Windows' default character encoding; UTF-8 output resolved it without changing source text.

The final ledger keeps the source's layer 8, top-of-layer-9 and layer 8c statements separately. It also keeps the goat-like and wild-ass descriptions as published animal interpretations. The outside-fort find in the four-object paragraph is not tied explicitly to a displayed number. Repeated reports add observations and proposed joins; the ledger retains the original objects as one archaeological group.

The first final-review report checked its own README link before writing the report, giving one temporary missing-file finding. Its 28 passed checks and that failure remain in `verification.json`. A separate reviewed endpoint passes all 29 checks after the file exists. The counts and source inputs are unchanged.

The next acquisition has a defined purpose: restore the original meshes, context register and fourth registration, then test orientation and wear under declared handling actions. Another broad search for the same passport proposal would add little without those physical or source joins.
