# Same-length forms with shared symbol mass

This is a fresh-world stress test developed after paper 004. The question is whether reference-only choice and symbolic mapping retain their administrative recovery when record length no longer identifies a form and role distributions share symbols. The main run will use twelve fresh twenty-symbol systems, reference sizes 40 and 400, encoded training size 640, and 400 held-out records. Mixture changes are 0 and .35. The grid has four matched variants, producing 192 mapping conditions.

The separated variant uses the preceding administrative generator's four disjoint pools and three forms of lengths 4, 5 and 6. The common-length variants extend the first form with role indices 0 and 3 and the second with role index 3, giving three six-slot forms. Existing slot probabilities are retained. Added slots draw new Dirichlet(.7) distributions inside their specified pools. Each common-length slot distribution is `(1-alpha) p + alpha b`, where `b` is one shared twenty-symbol Dirichlet(.7) distribution per system. Alpha is 0, .35 or .70. Positive alpha gives every slot full symbol support; alpha measures shared probability mass, rather than the fraction of shared inventory members.

Main system seeds are `1010261002 + 1000*r`, for r = 0 through 11. A separate pilot uses 2010261002. The preceding generator determines base parameters. Added-slot and background draws use seed + 100. Reference, training and held-out streams use seeds + 1, + 2 and + 3. Every sampled record draws a form uniform and six slot uniforms before truncation; the same uniforms are reused across variants. Encoding uses seed + 4. Save full parameters, records, form labels and hidden maps. The selector and primary decoders receive only their declared record inputs; hidden forms, parameters and identities stay in evaluation.

Retain the existing graph comparator: two deterministic FAQ starts, ten randomized starts, their 2-opt refinements and the frequency candidate, with fixed start/end correspondences. Solver seed is `1110261002 + 1000*r + 10*shift_index + reference_index`, shared across variants. The slot objective uses observed length and position with one pseudocount per reference symbol. The reference-only selector uses three folds, seed + 50, and chooses the larger conditional whole-record reference log likelihood, with ties choosing graph. Graph likelihood divides by its exact length probability. Fit both methods regardless of the choice.

A separate stronger-input diagnostic supplies an observed form label on both reference and encoded records. It fits independent form/position probabilities and a linear assignment, with one pseudocount per symbol. The main selector never receives these labels. Its held-out score conditions on form and uses the same token denominator. This diagnostic measures the value of an additional record-class observation under these generated forms.

Report returned complete recovery, symbol accuracy, reference choice, both ordinary conditional held-out losses, and optimal slot-score alternatives. Verify every slot optimum with a dual bound. Independently rebuild scalar counts, folds, choices, scores and truth comparisons from saved records; use a state recursion for the graph normalizer. Search code-exclusion alternatives and certify retained equality witnesses with exact integer-factor likelihood ratios. Numerical objective tolerances are 1e-7; a near equality is retained separately if exact cancellation fails. These certificates cover linear objectives; the twenty-symbol graph search has no global optimality certificate.
