# Approach, checks and repairs

This branch turned the unfamiliar-artifact proposal into a fixed quantity-inference experiment. I read the project index, registry, literature retrospective, cross-disciplinary memo, redistribution rules and writing guide before building it. Earlier metrology work already demonstrated scale ambiguity, while the office-routing control demonstrated predictive structure in a system with a known administrative purpose. The new branch therefore introduced physical membership as an additional observation and measured what it identifies.

## From analogy to a calculation

Conservation laws and observability supplied the model. A parent container's label and the labels of its complete children give a linear equation. Repeated assemblies increase rank; an independently counted object fixes scale after a relative vector is identified. I used six unfamiliar codes with randomly assigned values and balanced their frequencies so that the text-only pool supplied no preferred permutation.

The [protocol](PROTOCOL.md) was written before execution. The generator enumerates all valid two-, three- and four-child multiset compositions, then samples without rank selection. Twelve assemblies train the solver and eight further assemblies assess it. Twenty-four seeds produced 840 prefix/control records. Exact fractions retained dependencies between equations; exhaustive enumeration retained every assignment compatible with a supplied finite value bag.

The complete-condition results and the missing-data results diverged in a useful way. All twelve-complete-assembly collections identified the relative values. Six complete assemblies plus six incomplete assemblies preserved the answer through inequalities, but seven collections retained additional relative vectors. A finite supplied value bag selected one answer in those same cases. I wrote exact certificates after the run to expose the remaining alternatives, then checked positive integer alternatives that also preserve the single physical count. Both certificate stages remain separate.

## Cases that failed

The scrambled groups and independent badges preserved label frequencies while changing the meaning of membership. At the full training prefix, every control system had rank six and no positive solution. Treating incomplete visible contents as a complete group had the same outcome. The incorrect equality added by a missing child contradicted the actual quantity relation.

At five observations, two scrambled collections and three incorrectly completed collections had a wrong positive relative vector. Their eight withheld relations rejected each vector. These cases are retained in the records because they show exactly how a small set of equations can fit a wrong physical hypothesis. I did not discard or regenerate them.

## Observation error found while preparing blind inputs

The first run measured an ownership-labelled object by indexing the quantity answer key with its badge code. Once badge labels are shuffled independently of quantity, that index no longer measures the object bearing the badge. The blind-input export made the missing object-level trace apparent.

I recorded the [correction](ANCHOR_CORRECTION.md) before rerunning. Every possible measurement now identifies a preselected physical object, its observed code and its actual concealed quantity. Selection uses the inventory and label before reading the count. The corrected run uses the same 24 seeds and all the same assemblies. The first run and its source snapshot remain in `main/`; the corrected run is in `main-corrected-anchor/`.

The [comparison](anchor-correction-comparison.json) verifies that all 840 matrix triples and unanchored ranks stayed unchanged. After ignoring the added counted-object identifier, changed records were confined to 156 ownership-measurement diagnostics. All nonownership records remained numerically unchanged. This repair did not alter the main complete/missing-content results or the full-prefix control rejection.

## Verification and interface

The implementation checks pool balance, distinct object identities, exact concealed conservation, marginal preservation under scrambling and badges, inequality direction and rank-five answer recovery. It verifies each rational rank with a nonzero minor computed by a separate integer determinant algorithm.

The [independent review](corrected-review.json) then recomputed all 840 finite candidate sets by ordinary direct enumeration, checked ranks over two prime fields, evaluated nullspace and anchor residuals, traced the selected counted object, and checked active measurement choices with exact fractions. Snapshot hashes tie the result to its code and protocol. All checks passed.

The staged blind export assigns neutral object identifiers and hides condition names and mappings. It supplies labels first, training membership second and one physical count third. Withheld membership and the export key are separate files. These are reusable inputs for a future human or agent experiment; this run used the declared solver and had no human participants.

## Source search and collection target

I searched original museum and author sources for envelopes with enclosed tokens and exterior marks, using Susa inventory numbers and bulla/content terms. The Louvre notice and JSON for SB 1932 provide a stable accession and photographic entries. Schmandt-Besserat's 2018 chapter names SB 1940, while the 1986 article records exceptions to outside/inside correspondence. These gave a collection target and required completeness fields.

The public catalogue lacks an enclosed-token itemization, and the search did not locate an official SB 1940 notice. A CDLI bulla record appeared in search, but its direct page returned an internal error through the web reader; I retained the accessible museum target rather than treating the search excerpt as a contents inventory. Photographic URLs were recorded without making a pixel count. The acquired notices and papers remain local with [hashes](source-acquisition.json).

The resulting [acquisition plan](ARCHAEOLOGICAL_TARGET.md) asks for accession-linked opening records, token membership, exterior zones, completeness and geometry. These fields support a withheld prediction test before weighted numerical interpretation. Future work can extend the simulator to separate exterior/interior inventories, mixed commodities, uncertain membership and measured geometry, each in a new dated run.
