# Representation audit record

The Harappa source audit found all eight combinations of lower-face form and displayed position. Before testing associations, we asked which distinctions would survive an uncertain drawing convention. The source audit checked the original discussion and caption; they describe turning the object but supply no explicit common-end map. That assessment preceded this calculation.

We froze a protocol for four representations and calculated the orbit partitions. A face-exchange operation changes which form occupies the middle drawing row while preserving the form-specific sides. A common reversal changes both sides. Separate reversals allow each drawing to choose its own end. The latter is useful as a sensitivity endpoint because it removes every distinction in this projected inventory.

The review went back to earlier annotation files rather than the main run's summary. Native resolution had resolved specimens 15 and 21 and part of 22. Applying those preserved refinements recovered the same 19 complete pairs. Every complete pair explicitly contained one A and one D, validating the main routine's inventory assumption. Direct labels reproduced the 8, 4, 2, 1 partitions and their object memberships.

The missing scale bar and ambiguous pagination were found in a separate source reread while this work was active. Their correction record preserves the earlier fields and supplies a 30 mm bar and distinct PDF/author/book locators. Neither correction changes the displayed arrangement input or this result.

The next branch needs adjoining-face photographs or 3D observations with identified ends. The source already associates engraver groups with microscopic cutting and arrangement observations, so using the published groups as an independent target for these same drawing features would reuse part of their construction evidence. An acquisition study can conceal those labels during new coding and compare the frozen observations afterwards.
