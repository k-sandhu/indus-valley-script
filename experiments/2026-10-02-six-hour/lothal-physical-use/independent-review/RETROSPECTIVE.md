# Methods, challenges and outcomes

The review began with the root protocols, provenance and aggregate endpoints. I wrote the independent-reading protocol, then transcribed both Table 1 pages from the preserved source pixels. All 93 objects were entered before opening the root's CSV. The known aggregate results were recorded as prior information. Comparing five fields per object produced 465 agreements and zero disagreements.

The table totals and prose totals differ within the same chapter. I inspected the original embedded page images at the cited passages instead of resolving the difference by changing table cells. This confirmed L174's two-versus-one count and found another such difference for L179. It also placed the prose total of 130 impressions and 63 single-impression objects on PDF page 20, printed page 82. The root's frozen endpoint remains intact, and the reviewed coordinate is recorded separately.

The context discussion supplied the construction of W1: objects bearing recurrent stamps from the documented warehouse group were assigned to that area. This gives a concrete dependency between stamp identity and the source's context inference. The field recommendations record context basis so a future context model can account for that dependency.

An independent program joined the table frame to the preserved observed corpus and rebuilt the exact inscription groups. Its first endpoint reported 93 joined objects because a `defaultdict` created an empty list whenever an absent object was examined. There were still 86 actual faces. A check against the root coverage caught the mismatch. I preserved that endpoint and its code, changed the object count to count nonempty face lists, and wrote `main-refined`. All 14 checks pass there. The raw first transcription was unchanged.

For photographs, I first inspected Figures 3–7 in the available page renders, then extracted the largest original embedded image from each PDF page without changing its bytes. The figure files and extraction manifest are local-only. The original images provide more pixels, although halftone reproduction still limits fine texture and stamp counts. I retained visible geometry and the authors' material interpretations in separate fields.

The figures contain 35 distinct labelled objects. Twelve selected objects were annotated for physical traces, along with the unnumbered fingernail inset. The inset could not be securely assigned to an object from the available caption. Its repeated cuts are retained as an unassigned observation. The source's reported five cuts on L142 and up to six in the elephant cohort remain attributed counts.

The inscription recurrence check reproduced nine strings among 29 eligible objects. Two groups contain 21 of those objects. The source already describes the general contrast between a frequently reused stamp on varied fastenings and the elephant stamp on wooden surfaces. The reviewed outputs make the corpus coverage and object membership explicit, while identifying the photographs and missing faces needed for a matched physical-use comparison.

No source file, root endpoint or imported corpus was changed. The tracked review holds code, aggregates, coordinates and selected observations. Full table transcriptions, object joins, strings and source pixels remain local under the repository's rights policy.
