# Identity reports copied from a shared source

Written on 2 October 2026 before the pilot. The physical and catalogue audits preserve source dependencies: alternate transcriptions can share an object or publication, and Lothal context W1 was inferred from stamp recurrence. This experiment tests an explicit reporting channel over the synthetic mapping benchmark. Database truth-discovery research already models source dependence; this run adapts a small, enumerable channel to mapping identities.

Generate 24 new systems per family with seed 610261002 and the existing family/repetition offsets. Use 400 reference records, training prefixes of 40 and 160, and process-mixture changes 0 and 0.35. Freeze the integrated first-order score over eight-symbol bijections. Randomly order the codes to be reported, independently of their identity and reference score.

Source A supplies either the correct identity map or one uniformly selected transposition of two reference identities. Conditions deliberately include both source states. Inspect prefixes of one, two, four and eight reported identities. One, three or ten derivative reports repeat those same source-A claims exactly. A second source B is either absent or supplies one correct report on the same prefix. These controlled source states are stress conditions, rather than a random sample of source reliability in archaeology.

Compare four treatments: hard reported identities; independent per-claim errors counting every derivative report; independent per-claim errors counting source A once; and a coupled source channel counting source A once. The latter gives probability1−q to an unchanged source map and q/28 to each possible transposition, with declared q values0.1 and0.5. Its single-code marginal has correct probability1−q/4 and probabilityq/28 for each wrong identity. Use those same marginals for both independent models. Source B uses the same assumed reliability channel and is observed once. Exact hard conflicts can leave no compatible map, which must remain an explicit outcome.

Report identity recovery, selected-map conditional mass, true-map mass, confident wrong selections and empty hard candidate sets. Distinguish dependence across claims within a source from dependence caused by copied reports. For each source-aware treatment, duplicating a source report must leave every map score unchanged. Independently check the coupled likelihood by enumerating its29 latent source states and its marginal response probabilities. Review the main likelihood and outcome fields on a new independent calculation, and summarize paired changes at the generated-system level.

Preserve the controlled source states, observed claims, code snapshots, pilot and completed endpoints. This experiment supplies an assumed source-error model. A real application would need provenance and a justified reliability model for its archaeological measurements.
