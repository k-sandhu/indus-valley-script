# Second-order restoration on the saved artifact-held-out benchmark

Written on 2 October 2026 before fitting this model. The earlier first-order comparator reached 34.59% exact top-one restoration on 8,009 saved masks. This branch asks whether a second preceding state adds useful predictive information on the same artifact/string-held-out queries. Higher-order Indus n-grams have published precedents. [Yadav et al. 2010](https://arxiv.org/abs/0901.3017). A September 2026 author abstract reports trigram-over-bigram gains under its own evaluation; the full SSRN page was inaccessible in the current source retrieval. [Bose abstract](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=7436801).

Use the same normalized input, unique-string representative with all physical aliases, 1,526 transitive components, five outer folds and seed20261006. Recreate and compare all saved query keys, targets, group assignments and folds before fitting. Every fold learns its vocabulary only from training data. Unseen targets receive the existing unknown bucket for loss and fail exact sign accuracy.

Count the next state after each two-state history, with two start sentinels and an end state. The prior for a history is the first-order transition row after its latest state; the initial-history prior is the first-order start distribution. Fix the first-order backoff strength at20, as in the preceding comparator. Shrink observed second-order counts toward that prior with strength in{5,20,100,500,2000}; also include a backoff-only candidate that exactly reproduces the first-order model. This is a new model family chosen after prior benchmark outcomes.

For one masked state, multiply every full-sequence factor containing it: its own next-state factor, the following factor and the factor two positions later, including the terminal factor when applicable. Other factors cancel. Normalize over the training graphic vocabulary and unknown bucket, excluding start/end states. Independent tests must compare this local calculation with complete-record likelihood and confirm that replacing the hidden target leaves predictions unchanged.

Three inner component-held-out folds select strength by exact top-one restoration accuracy, using the same seed offsets as MARKOV-01. Ties prefer the strongest shrinkage, with backoff-only last. Evaluate the chosen model on the unchanged outer queries. Report top-one/five/ten, bucket loss, equal-text and equal-code scores, position/frequency strata, calibration and paired component-bootstrap differences against first-order and PMB. Intervals reuse the fitted predictions and do not refit tuning.

Run mathematical self-tests and a one-outer-fold pilot before the main five-fold endpoint. Preserve pilot results, original snapshots and all failures. Independently reconstruct second-order count probabilities and check every final candidate ranking, target loss and query correspondence. Raw detailed predictions remain local under the slot-audit rule. Track aggregates, code, seeds, hashes, methods and a retrospective.
