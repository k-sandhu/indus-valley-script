# A reference-only choice after the two-model comparison

The preceding graph/slot comparison favored different score families in transition and administrative records. We froze a new experiment in which held-out reference prediction chooses the family. The known generator family stays in evaluation as a diagnostic. New generated systems provide the mapping outcomes.

The two reference likelihoods needed a common conditional space. The graph model has an end state and therefore assigns probability to record length; the slot model is already conditional on length. Dividing graph likelihood by its exact length probability made complete-record scores comparable. Tiny sequence enumeration checked normalization before the pilot, and an independent state recursion later reproduced every normalizer and selection.

The first pilot completed its four systems but failed to serialize a NumPy boolean in the self-check dictionary. We preserved the source and failure report, converted the outcome to Python bool, and reran the deterministic pilot into a new directory. No fitting or selection rule changed. The main 48-system run then completed in 47.26 seconds.

The independent review passed 6,489 checks. Reference selection retained the generator-specific mapping method in all twenty-symbol conditions, and lost one eight-symbol administrative recovery against the supplied-family diagnostic. Six small eight-symbol reference samples preferred the graph model. These choices and failures remain in the output.

The additional review tested unresolved assignments with exact integer-factor likelihood certificates. It found eleven tied slot conditions and retained 32 alternative maps, including five conditions that enter selected administrative outputs. This improves the record of compatible identities without changing any selected mapping or recovery count.
