# Choosing the mapping model from reference records

Written on 2 October 2026 after the slot-mapping comparison and before this branch's generation. Graph and length/slot mapping favor different known record mechanisms. This experiment selects a model from held-out reference prediction, then tests mapping recovery on fresh generated systems without supplying their family to the selector.

Use 48 new systems from the same two generators and inventories, with seed 910261002 plus 1,000,000 per inventory index, 100,000 per family index and 1,000 per replicate. Use twelve replicates per family/inventory, reference sizes 40/400, encoded training sizes 160/640, process change 0/.35 and 400 separate test records. Source, inputs and known identities are preserved. The model-development choice follows earlier outcomes; these worlds are new.

For each reference sample, assign records to three fixed random folds using seed `system seed + 50`. Fit reference distributions on two folds and score the third. Each model scores the entire known-reference record conditional on its observed length and the supplied inventory. The length/slot model multiplies independently smoothed slot probabilities. The first-order model uses learned start, transition and end probabilities, then divides by its probability of exactly that record length. Compute that normalizer as `start × transition^(L−1) × end`. It makes the two models comparable on the same conditional sequence space. Use one pseudocount per category or transition destination, as in the earlier mapping studies.

Choose the smaller pooled held-out negative log score; ties choose graph. The selector receives only reference records, inventory size and fold seed. It receives no generated family, truth mapping, encoded test records or hidden parameters. Fit both mapping methods on full reference and encoded training, then retain the reference-selected map for evaluation. Preserve all three outputs, selection scores and choices. No tuning is done on mapping accuracy.

Report selected family, complete and symbol-wise recovery, losses under both conditional reference models and timing. Compare selection against each fixed method and the supplied-family diagnostic, which is explicitly oracle information used only in evaluation. Aggregate the eight conditions within each generated system before bootstrapping twelve systems per family/inventory 20,000 times. Keep unresolved assignments and their observation scope alongside point recovery.

Run a four-system, small-sample pilot after checking that exact enumeration of a tiny sequence space sums each conditional model to one and matches the matrix length normalizer. Then execute the full grid. Independent review must recreate reference folds, smoothing, conditional scores, every choice, mapping objectives and answer-key comparisons. Retain failures and do not overwrite the preceding graph/slot endpoints.
