# Identity-acquisition investigation

CRYPTO-03 showed that integrated reference uncertainty reduced some confident errors while leaving process-mismatch failures. I developed a subsequent experiment around the next observation: choose an independent identity measurement using entropy, random selection or observed frequency. The protocol fixed new systems, conditions and complete histories before the outcomes.

The implementation computes the score of every permutation once. Each revealed identity restricts that fixed set. I separated the response oracle from the query function; the function has no truth or oracle argument. For exact identity responses, marginal identity entropy equals the expected reduction in map entropy. A pre-run enumeration check verifies the equality.

Two pilot attempts failed at JSON serialization after calculating twelve conditions. The first repair converted one NumPy Boolean but missed a second check value. Both attempted programs and failure records are preserved. The complete repair converts all check values and serializes them at startup, then serializes the final result before creating its output directory. The checked pilot saved 324 prefix records. The main run saved all 15,552 records from 48 systems.

The entropy rule used fewer measurements to reach the known map, but its retrospective 95%-mass stopping diagnostic made more mistakes in the administrative systems. The frequency heuristic sometimes had fewer stopping errors while taking more measurements. I retained the separate outcomes, every sample-size condition and paired system-level comparisons.

Review also clarified a redundant protocol outcome. Under fixed map scores and reliable identity responses, a true map that wins once keeps winning as rival maps are removed. First-correct and permanently-correct prefixes consequently coincide. The saved protocol is retained; the finding explains this property rather than treating their agreement as an empirical confirmation.

The independent review rewrites the likelihood by moving encoded counts into reference coordinates, then replays all three policies for one system in each of 24 source conditions. Every map and query matched. Algebraic errors, oracle leakage and wrong history bookkeeping would have produced distinct failed checks.

A primary-source search located MacKay's original information-selection article and Tang, Sloman and Kaski's 2026 paper on model mismatch. The Caltech download redirect was inaccessible through the web reader, so the citation currently uses the inspected repository abstract. The PMLR PDF was acquired directly after the web reader rejected its generic binary content type; its 32 pages, hash and extracted text are recorded in [the source manifest](active-learning-sources.json), with PDF and text kept local. Its main model-setting and acquisition sections were inspected. Applying its regression-specific correction to this discrete mapping task remains a separate design step.
