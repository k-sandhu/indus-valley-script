# Reference-fitted latent forms

A three-component categorical mixture fitted from reference symbols recovers 24 of 24 large-reference maps at both zero and .35 shared symbol mass. The previous reference selector recovered 22 of 24 in each case. A new reference-only three-model selector reaches the same 24-of-24 counts. Three is a supplied form-count prior; fitting receives no per-record form labels.

This post-outcome experiment reuses the [common-length benchmark](../overlapping-forms/REPORT.md). Read the [report](REPORT.md), [methods](METHODS.md) and [retrospective](RETROSPECTIVE.md). The [protocol](PROTOCOL.md) preceded fitting. The [independent review](review-v1/verification.json) passes 68,014 checks, including all 4,433 mapping assignment duals and likelihood bounds. [Reviewed outcomes](review-v1/reviewed-rows.json) give scores under all three models. The [collapsed-profile control](collapsed-v1/verification.json) isolates the coincident-component smoothing, with its [separate protocol](COLLAPSED_PROTOCOL.md).

The complete main result is preserved in a [lossless chunk package](git-package/main-results-v1/manifest.json). [Reconstruction instructions](git-package/main-results-v1/RECONSTRUCT.md) restore its exact original bytes. The local original `main-v1/results.json` exceeds GitHub's blob limit and is excluded from tracking. The [execution freeze](main-v1/execution-freeze.json), [source snapshot](main-v1/code_snapshot.py), pilot, reviews and package remain available. [Final verification](verification.json) checks navigation, source preservation and package reconstruction.
