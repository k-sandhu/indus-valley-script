# Latent-form follow-up

The previous stress test showed a recovery benefit from supplying form labels on common-length records. This branch fitted form profiles from reference symbols and retained the component count as an explicit prior. The protocol fixed the fitting equations, pseudocounts, starts, iteration limits, selection rule and same-record comparison before execution. A separate pilot used the preceding pilot worlds. The main run completed 144 conditions in 27.73 seconds.

The two optimization stages needed separate ascent checks. Reference pseudocounts define a penalized MAP objective, while symbol assignment uses actual likelihood with the reference model fixed. The source stores both reference trajectories. The independent review records 27,805 raw reference-likelihood decreases alongside monotone penalized objectives. All 4,433 mapping updates pass actual likelihood ascent, their Q checks and the EM lower bound. Keeping those objectives explicit made the update equations and their guarantees inspectable.

The review rebuilt responsibilities with scalar Bayes normalization and reconstructed every terminal reference M step. It independently checked all mapping weights and assignment dual bounds. Its 68,014 checks pass. Six failed mixture maps score below the true map, identifying a search limitation that the earlier graph stress grid did not expose. The other 56 failed mixture maps prefer a wrong identity under the fitted objective. The main retains every starting and intermediate candidate, with no distinct top-score candidate ties observed.

The fitting rule also changes smoothing when three components coincide. After the primary result, a separate protocol specified that closed-form control. It recovers fewer large-reference maps at zero and .35 mass than the fitted mixture, and its CV comparison confirms a predictive gain from the learned profiles there. At .70 mass, CV favors ordinary slot prediction. These controls keep the source of the improvement available for future model changes.
