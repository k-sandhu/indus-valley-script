# Latent form mixture on preserved common-length worlds

This post-outcome comparison reuses the frozen common-length worlds from the overlapping-forms experiment. Twelve twenty-symbol systems have alpha 0, .35 or .70 shared mass, reference sizes 40 and 400, mixture changes 0 and .35, training size 640 and test size 400. There are 144 conditions. The records and previous graph/slot/supplied-form maps stay fixed. Outcomes on reused worlds measure this new model on the documented benchmark; they form no new independent recovery sample.

Fit a mixture with m = 3 independent six-slot categorical profiles. The supplied component count is an extra form-count prior. No per-record form labels, hidden role pools, generator probabilities or mapping truth enter fitting. For a reference record x, `p(x) = sum_z pi[z] product_j theta[z,j,x[j]]`. Responsibilities are each component's normalized contribution to that probability. The M step adds one count per component to mixture counts and one per symbol to each component/slot count. Thus `pi[z] = (N[z]+1)/(N+m)` and `theta[z,j,r] = (C[z,j,r]+1)/(N[z]+20)`. This maximizes the MAP objective `sum_i log p(x_i) + sum_z log pi[z] + sum_zjr log theta[z,j,r]`, corresponding to Dirichlet(2) priors. Record raw data likelihood and penalized objective separately.

Reference fitting uses eight fixed starts: one repeated marginal profile, one deterministic farthest-record initialization, and six balanced random record partitions. Marginal initialization uses one pseudocount per symbol. Farthest records begin at index 0 and maximize minimum Hamming distance, taking the first index on ties; profiles mix .8 exemplar mass with .2 marginal mass. Partition seeds are `fit_seed + start_index`. Each start has at most 150 MAP-EM iterations. Stop after an objective improvement no larger than `1e-8 * (1 + abs(previous_objective))`; require penalized ascent within 1e-7. Select the highest final penalized objective, retaining the first start on exact equality. Preserve all starts, trajectories and final parameters.

For a symbol map f on encoded records y, maximize the fixed reference model's actual likelihood `sum_i log sum_z pi[z] product_j theta[z,j,f(y[i,j])]`. At each step compute form responsibilities under the current map, then assign code c to symbol r with weights `W[c,r] = sum_izj R[i,z] 1(y[i,j]=c) log theta[z,j,r]`. A linear assignment maximizes this conditional expectation. Check both its Q improvement and the actual mixture-likelihood change within 1e-7. Keep every initial and intermediate candidate; return the largest actual likelihood. Starts are the frozen slot map, graph map, a unigram-frequency assignment, identity, reversal and six random permutations. Skip duplicate maps while recording their names. Use at most 25 updates per distinct start, stopping on a repeated map. Retain distinct visited maps within 1e-8 of the returned score as candidate ties.

Full-reference fit seeds are `1310261002 + 1000*replicate + 100*variant_index + 10*reference_index`; fold fits add `100000 + 100*fold`. Mapping random seeds are `1410261002 + 1000*replicate + 100*variant_index + 10*shift_index + reference_index`, plus 200 through 205. Three-fold reference CV reuses the frozen folds.
