# Model, fitting and verification

The model assigns a six-symbol record probability by summing three component contributions: `p(x) = sum_z pi[z] product_j theta[z,j,x[j]]`. Each component contains independent categorical distributions for the six positions. EM and mixture fitting are established methods; the precedent is Dempster, Laird and Rubin's [1977 article](https://rss.onlinelibrary.wiley.com/doi/abs/10.1111/j.2517-6161.1977.tb01600.x). The present contribution is the specified benchmark comparison and preserved numerical checks. Component indices describe fitted profiles; exchanging their indices preserves record probability.

Reference fitting adds one pseudocount per component and per categorical cell. This is MAP-EM with Dirichlet(2) priors. Its objective adds the log mixture weights and log categorical probabilities to data log likelihood. Eight fixed starts have at most 150 iterations, with the declared relative-objective stopping threshold. The selected start has the largest penalized objective among those retained. There are 288 full/fold reference fits and 2,304 individual starts; 178 starts reach the iteration limit. Both raw likelihood and penalized trajectories are preserved. [Exact equations, seeds and initializations](PROTOCOL.md), [executed source](main-v1/code_snapshot.py).

For encoded records, the reference mixture is fixed. A current symbol map determines soft form responsibilities. Their expected code/position counts produce linear assignment weights against the reference profiles. The best assignment increases the conditional expectation, and the implementation checks the actual mixture likelihood after every update. Starts include the frozen graph and slot maps, frequency, identity, reversal and six seeded random maps. Duplicate initial maps remain identified. Every initial and intermediate candidate is retained, and the returned map has the largest actual likelihood among them. Mapping stops on a repeated map or after 25 updates.

Three-fold reference prediction uses the preceding benchmark's exact folds. The mixture competes with the frozen conditional graph and slot likelihoods, with no encoded test data or mapping answer in selection. All records have length six, so the mixture and slot products are normalized on that record space; graph probability is conditioned on length through its existing normalizer. Held-out losses share a 2,400-token denominator. The model receives the component-count prior of three. Per-record labels enter only the preserved supplied-label comparator.

The independent implementation uses scalar logarithms and Bayes normalization. It checks every reference start's initial/final scores and terminal E/M equations, all reported MAP ascent and stopping conditions, all reference-fold scores and choices, every mapping E step, every assignment weight and an independent row/column-potential dual program. It also checks the likelihood-change bound against the Q change. All 68,014 checks pass; the largest assignment-Q discrepancy is 1.46 × 10⁻¹¹ nats. The smallest checked EM-bound residual is zero. Tiny rational mixture enumeration verifies normalization. Dual certificates cover linear subproblems. Reference EM and nonlinear map search retain finite budgets; their global optima and global uniqueness remain unproved. Intermediate reference trajectories are retained as reported scores, while terminal update equations receive independent scalar reconstruction. [Review protocol](REVIEW_PROTOCOL.md), [verification](review-v1/verification.json).

The post-outcome collapsed-profile control has probabilities `(count+3)/(N+60)`, the closed form for coincident three-component profiles. It uses a global linear assignment, 144 independent dual certificates and direct scalar likelihood checks. Its separate four-model selector receives the same reference folds. [Protocol](COLLAPSED_PROTOCOL.md), [checks](collapsed-v1/verification.json).

All paired intervals resample twelve systems, keeping each system's two reference sizes and two mixture conditions together. Twenty thousand draws use seed 1510261002. The same records support all methods; this reuse measures their paired differences on the established benchmark.
