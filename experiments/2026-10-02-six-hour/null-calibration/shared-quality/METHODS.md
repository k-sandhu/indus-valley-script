# Conditioning on observed measurement quality

The study supplies a quality label for each object and keeps it fixed across slots and faces. Given that label, latent signs and replacement draws are independent across slots. The observed pair in a slot has the categorical law `r_q(a,b)=Σ_x p(x)K_q(a|x)K_q(b|x)`. A table's probability factors across its site/slot/quality cells. Conditioning on each cell's ordered-vector counts fixes every exponent in that product, making all compatible labeled tables equally probable.

For a cell of n objects with vector counts h(v), there are `n!/∏_v h(v)!` distinct arrangements. Permuting n labeled vector occurrences gives each arrangement exactly `∏_v h(v)!` representations. The quality reference permutes those occurrences independently for each slot and site/quality cell. It preserves the complete ordered vectors, their broad and quality-specific counts, scalar face margins, fixed object aliases and quality labels.

The broad reference holds the site/slot vector counts while allowing their allocation between quality classes to change. Its uniform permutations generally differ from the probability weights of the supplied quality-dependent generator. In the exact four-object example, the two low-error labels precede the two high-error labels. Two `(0,0)` and two `(0,1)` vectors admit six distinct columns. Their rational probabilities are stored in [the exact endpoint](exact/results.json). Conditioning additionally on one of each vector within each class leaves four columns with probability 1/4 each. Three independent illustrative slots give sixty-four equally likely tables. [The independent audit](verification_exact.json) checks all 128 ordered-pair probabilities, all six conditional column masses and all 20,000 sampler draws.

The low-error replacement rate is 1/40 and the high-error rate 3/5. Face agreement has probability `(1−ε)²+ε²/7`, or 1331/1400 and 37/175 for those classes. For a three-slot object, conditional whole-string agreement is the cube of that class's agreement probability. Mixing classes across a broad vector reference changes how repeated face observations are allocated among objects. Physical aliases already join each object's faces; whole-string repetitions between objects add text edges. The actual statistic rebuilds that closure for every proposed table.

For a single face, the supplied symmetric kernel gives `m_q(a)=1/8+t_q(p(a)−1/8)`, where `t_q=1−8ε_q/7`. Selecting an object uniformly from the balanced classes gives adjacent-slot covariance `Var(t_q)(p_i(a)−1/8)(p_j(b)−1/8)`. Here `Var(t_q)=529/4900`, and the largest absolute event covariance is .0006072704. The corresponding largest covariance between ordered two-face-vector events is .0057955982. [The rational calculation](analytic-moments/results.json) checks all 256 single-face and 16,384 vector entries. [Its independent audit](analytic-moments/verification.json) replays every single-face entry and four vector maximum witnesses by summing latent sign pairs. These values describe the supplied signal available to different observations; the main run separately measures the frozen statistic's rejection behavior.

The frozen prediction model reads sign sequences and `(site,type)` strata. It never reads the extra quality field. Both source inspection and a fitted quality-relabeling check verify this correspondence. Conditioning the reference on quality is compatible with a statistic that ignores it: the rank argument concerns the conditional table law and any specified finite statistic. Here the statistic equals the original nested gain on tables with at least five components and zero on smaller tables, with observed abstention on those smaller tables. The [protocol](PROTOCOL.md) declares that rule before generation and keeps infeasible reference states in the space.
