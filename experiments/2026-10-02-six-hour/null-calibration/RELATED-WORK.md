# Repeated measurements and conditional table laws

Repeated measurements supply an established way to think about multiple records from one physical object. Winkler and colleagues describe exchangeability blocks that move related observations together and can be nested for more complex dependence structures. Their examples include repeated scans and relatives. [Multi-level block permutation, NeuroImage 123 (2015), 253–268](https://pmc.ncbi.nlm.nih.gov/articles/PMC4644991/).

The face-vector reference applies that sampling principle separately to each sign position. An object contributes an ordered pair of observed signs. The complete pair moves to another eligible object, keeping its within-object relationship. The declared synthetic law makes those vectors independent across positions and objects within a metadata stratum. Conditioning on their vector multisets provides the uniform table law derived in the protocol. The statistic is the preserved grouped, nested held-out log-score comparison.

Hurlbert's ecological treatment of pseudoreplication examines inference that treats statistically dependent samples as independent replicates. It supplies a useful experimental-design parallel for copies of an artifact. [Pseudoreplication and the Design of Ecological Field Experiments, Ecological Monographs 54 (1984), 187–211](https://esajournals.onlinelibrary.wiley.com/doi/10.2307/1942661).

The exact [copy-tail example](copy-tail-counts/README.md) quantifies that problem for a known independent-object law. The [noisy-face study](noisy-faces/PROTOCOL.md) adds two faces that often differ and preserves their joint sign vectors. Existing block-permutation work supplies the sampling principle; these experiments couple specified sign-table laws with the actual Indus fitting procedure and retain every simulated population and reference seed.

Physical blocks and predictive held-out components have separate roles. The synthetic physical block is one known latent object with two face records. The fitting component combines physical aliases and identical complete strings. The reference first follows its declared physical observation law; each resulting table then rebuilds the fitting components. For archaeological use, comparable blocks need a shared face-count, length and metadata profile. The unequal-copy example provides a separate sampler when expanded record counts also need to be held fixed.
