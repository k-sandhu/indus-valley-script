# A comparator suggested by the graph failure

The previous twenty-symbol administrative grid had high average symbol accuracy but few complete mappings. Its stationary graph score pooled typed slots across three forms. We specified a length/slot model on fresh systems, using the fact that the forms have different observable lengths. The decoder receives those lengths, rather than the hidden role pools.

A linear objective made exhaustive search unnecessary: each code-to-reference pair contributes its own profile score, so a linear assignment gives the maximizing map. The protocol initially called the solver a Hungarian method. Before any generation, the official implementation documentation identified SciPy's modified Jonker–Volgenant algorithm; the protocol now names the actual solver. No model or outcome changed.

The pilot passed direct-record/count score agreement, normalization through pseudocounts, boundary-compatible graph comparisons, exhaustive eight-symbol maxima and independent assignment-relaxation bounds. The main run completed without a fitting failure. Independent review rebuilt every profile, checked all held-out scores and answer-key comparisons, and found twenty-three conditions with a tied alternative assignment. Those alternatives remain part of the result.

The administrative gain and transition loss demonstrate a practical decision for a future decoder: select a reference score that retains the relevant distinctions. A reference-only model-selection test is a new branch. It should choose before seeing mapping truth, preserve its model-choice failures and use independently generated systems. The present data and intervals remain frozen.
