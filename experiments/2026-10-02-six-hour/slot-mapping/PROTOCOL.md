# Length and slot profiles for mapping short records

Written on 2 October 2026 before generating or fitting this branch. The preceding graph-mapping study recovered few complete twenty-symbol administrative mappings. This experiment asks whether record-length/slot conditioning provides a better mapping score for that generated process. The model choice follows the earlier result; the new systems use fresh seeds.

Generate twelve systems for each of the transition and administrative-form families at inventory sizes eight and twenty. Use the existing declared generators with new seed 810261002, plus 1,000,000 per inventory index, 100,000 per family index and 1,000 per replicate. Retain reference sizes 40/400, encoded training sizes 160/640, mixture change 0/.35 and 400 independently generated held-out records. Preserve the generator, known mappings, inputs and source hashes. Nested sample sizes share a world.

For each reference length and slot, estimate category probabilities with one count per symbol. An absent reference cell is uniform. Accumulate a linear score W[c,r] by multiplying each training code's cell count by the reference symbol's log probability in that cell. A bijection maximizes the sum of its selected W entries. Solve this linear assignment with SciPy's modified Jonker–Volgenant implementation. [Official implementation documentation](https://docs.scipy.org/doc/scipy-1.17.0/reference/generated/scipy.optimize.linear_sum_assignment.html). Only observed length, slot and code are supplied; no latent slot pool, true identity or generator probability enters the decoder. The known inventory size is supplied to both mapping methods.

Compare the length/slot map with the preceding multistart-refined boundary-seeded graph matcher on each fresh condition. Record complete identity recovery, symbol accuracy, unobserved codes, training objectives, held-out loss under both reference models, and computation time. At eight symbols enumerate all 40,320 maps for the linear objective. At twenty symbols verify the selected linear score with a separate linear-program relaxation and dual inequalities. Retain ties and unresolved code identities; a selected bijection alone is not a uniqueness certificate.

Run a one-system-per-family/inventory pilot with the smaller sample sizes, then the full 48-system, 384-condition grid. Check direct record scores against sufficient counts, code orientation, model normalization, exact eight-symbol maxima and the assignment relaxation. Independently rebuild all cell and transition counts and replay objective and answer-key comparisons. Resample twelve generated systems within each family/inventory for paired comparison intervals, aggregating their eight conditions first. These intervals describe the generated design. Preserve failed checks and keep refinements in separate endpoints.

Linear assignment and position-conditioned models are existing methods. The contribution is a matched recovery comparison that diagnoses whether the reference's sufficient statistics retain the distinctions needed for this generated decoding task.
