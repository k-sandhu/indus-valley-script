# Khipu numerical controls

The published Puruchuco alignment reproduced 16 of 20 quantity columns with total absolute error 16. Keeping the same order in a flat list reproduced the result when the list's start, row count and width were supplied. Deleting positional addresses produced substantially larger errors in the fixed permutation controls. [Report](REPORT.md), [source scores](source-aggregate.json) and [independent verification](source-verification.json) contain the results.

In a separate simulation, whole-part relations recovered three hidden positional values in 299 of 300 complete decimal-accounting worlds. The remaining world retained several exact positive solutions. Incorrect membership and unrelated ownership records sometimes produced a unique answer early, then failed on later relations. The [synthetic endpoint](endpoints/main-v1/aggregate.json) preserves each prefix, ambiguous witnesses and failures.

The [recorded-interval follow-up](INTERVALS.md) tested grouping without numerical quantities. Both a largest-gap rule and an equal-cord-count rule selected the two published partitions. Widening the recorded gaps or removing measurements preserved the resulting ambiguity as a set of admissible partitions.
