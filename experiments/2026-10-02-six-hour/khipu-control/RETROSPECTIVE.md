# Research record

The branch began by looking for a known numerical system with surviving physical structure and a documented account relation. The Open Khipu Repository offered a pinned relational database and stable object identifiers. The Khipu Field Guide supplied an explicit replication of the Puruchuco hierarchy, including the source partition, alignment and discrepancies. This bounded pair of sources supported a representation control and a field-coverage audit.

## Experiment decisions and checks

The representation comparison distinguished deleting labels from deleting coordinates. An ordered list with a supplied start and width carries the same additive calculation as the grouped rows. Reversal, phase shift and shuffled allocation provide explicit coordinate controls. Reporting every score also retained the published relation's four mismatches. Whole-row permutation was an arithmetic invariance check.

The numerical simulation concealed all three positional values and supplied one counted object. It avoided a known value bag. Exact ranks and positive solution families preserved unresolved systems. Before running, a separate protocol supplement added prefix evaluation so that a unique answer could be followed into later rejection. This exposed 97 incomplete-account and 47 ownership-code worlds with an incorrect unique decoder before final failure under the full representation.

The decoder's rank calculation used rational row reduction. Verification recomputed ranks with integer Gram determinants, tested row spaces and checked all 24,154 positive witnesses against the original equations. Exact negative certificates covered all infeasible endpoints. A separate 512-state linear-programming sample agreed. An independent HTML parser and scalar summation checked all 20,411 source predictions. Static checks and saved input projections verified the tested functions' separation from evaluator keys.

The complete-account world at seed 2026100442 remained ambiguous after eight observations. Its repeated carry pattern supplied only one independent ratio equation. The retained family is useful for a later observation-design study: a new relation must distinguish the free positional value, while further copies of the same carry equation cannot do so.

## Next work

The recorded cluster intervals deserve a separate quantity-hidden grouping test. They could recover the published UR063 and UR068 subunits at coarser resolution even though individual pendant positions are unavailable. Such a test should freeze its group-count priors, interval-gap rule and labels separately, then compare exact ambiguity after removing metric distances.

The simulation's noisy conditions suggest a second follow-up: derive candidate numerical decoders from subsets of relations, retain all candidates tied on a fixed agreement rule, and test them on newly generated relations. This would measure whether a few incomplete memberships can be localized while preserving the numerical code. Fresh seeds, held-out relations and an ownership control would keep that extension separate from the present endpoint.
