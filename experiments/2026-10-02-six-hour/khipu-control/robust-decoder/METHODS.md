# Exact consensus methods

The frozen [protocol](PROTOCOL.md) specifies fresh seeds, shared generated quantities, corruption operations, decision gates and withheld checks. The generator writes eight training accounts, eight fresh withheld accounts and three fresh counted objects for each world. The counted unit supplied to fitting fixes `u=1`; the withheld counts stay in the evaluator. Training features and memberships produce rows `(a,b,c)` with `a + bt + ch = 0`. Both unknown coordinates are strictly positive.

Coincident rows are normalized for constructing geometry, while every original account contributes a vote. Zero rows contribute a vote at every point. Nonzero constant rows contribute none. For each other line, positivity yields an exact open interval for `t` or `h`. Two distinct positive witnesses represent that interval. Every nonparallel line pair yields a rational intersection, retained when both coordinates are positive. The unconstrained plane represents points satisfying no nonzero row.

The objective is the largest number of exactly zero account residuals. A candidate with two independent equations occurs at an enumerated intersection. A candidate with one independent equation occurs on an enumerated line. A candidate with none remains in the plane. This covers the whole positive domain. The implementation keeps every point and family tied for the largest score. A unique result consists of one point and no family. Interval bounds and pair calculations are saved along with support indices.

At prefix `n`, the primary gate requires `ceil(3n/4)` supporting accounts and the secondary gate requires `ceil(n/2)`. Both accept only a unique best point, abstain on supported ties or families, and reject scores below the threshold. The all-relations comparator instead classifies the joint positive equality set with an exact count anchor. The thresholds count observed accounts, including zero rows and repeated lines. Neither threshold has a fitted confidence interpretation.

The experiment has 300 base seeds and five conditions, or 1,500 world records. Conditions reuse clean quantities within a seed. Eight prefixes and three decision rules reuse each world; they are separate outputs rather than additional independent samples. Swaps preserve the leaf-object pool but alter memberships. Incomplete groups remove associations and are fitted as if complete. Ownership controls preserve numerical mark encoding while assigning parent quantities independently.

Inference opens the projected component file and writes 12,000 prefix records plus an inference hash manifest. Evaluation then opens the key, compares accepted vectors with the true values, checks eight withheld relations, three counted objects and thirty-two held-out quantities, and records excluded training rows. It also checks whether a true vector survives in an ambiguous best set. Evaluation leaves fitted candidates unchanged.

Verification uses all 256 account subsets per world and the separately implemented rational equality solver. Maximum feasible subset size provides an independent consensus score. The union of best subsets provides an independent unique, discrete-tie, line-family or plane classification. Every positive witness and accepted vector is substituted into the original rows. The verifier reconstructs the object projection and corruption operations, recomputes held-out equations and residuals, checks both threshold decisions and inspects fitting functions for key or file access. Three constructed diagnostics exercise a plane, a line and five tied points. [Verification output](main-v1/verification.json).

Run `python src/six_hour/khipu_robust.py generate`, then `python src/six_hour/khipu_robust.py infer`, `python src/six_hour/khipu_robust_evaluate.py`, `python src/six_hour/khipu_robust_verify.py` and `python src/six_hour/khipu_robust_aggregate_check.py` from the repository root. The default directory is `main-v1/`; every command refuses to overwrite its completed output. Reproduction needs a fresh endpoint path or an isolated checkout. Python 3.13 and its standard library suffice. Frozen code copies and manifests record the actual implementation and version.
