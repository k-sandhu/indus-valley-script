# Source-defined Harappa object frame

Written October 2, 2026, before acquiring or inspecting new object figures for this run. The preceding metadata audit found that the principal sign-model population includes only two objects from three published groups of copied tablets, sealings and vessel stamps. This run builds a source-linked physical observation frame for those objects.

## Frame and intended comparison

Retain all 81 published targets: copied tablets H2218–H2239, sealings and a stopper H1719–H1725, stamped vessel sherds H1727–H1766, and rectangular seals H1704–H1715. Their inclusion follows the original HARP introduction and the post-audit acquisition design. Keep an entry for every target, including missing sources and unreadable figures.

Look for CISI3.1 plates and basic-data entries through ordinary public institutional, author and library routes. Record searched URLs, responses, identity checks, rights evidence, download hashes and failed paths. Acquired PDF/text/image witnesses remain local-only. Inspect printed figures through rendered pixels; OCR is a locator and caption aid. Preserve the completed context-audit endpoints.

If the full plates are unavailable, use equivalent original HARP publications that identify an object by registration or excavation-unit/item number. Prioritize a bounded coherent group with exact caption joins, then extend to other targets where source evidence permits.

## Ledger and observations

The ledger records CISI base, export family/face references, source registration, excavation-unit and item, museum/accession references where reported, primary source coordinates, join basis and unresolved alternatives. Registration and context keys remain separate. A published specimen number is scoped to its figure and publication.

For visible objects record medium, manufacture or physical action, published phase and dating basis, observed sign arrangement and broad group count, witness polarity, physical sides, motif, boss/perforation, attachment marks, production features and preservation. Each assertion has a basis: `visible-in-source-figure`, `published-caption`, `published-description`, `derivative-export` or `hypothesis`. Keep literal source values beside normalized identifiers. A drawing is recorded as a drawing; photographs and impressions have their own witness entries.

Use descriptive shapes when fine catalogue identities cannot be distinguished from the pixels. Count visible units and visible strokes separately. Store source-figure bounds and render scale. Record partial, unreadable and absent units instead of filling them from a catalogue prediction. If published workshop groups or physical-use interpretations exist, retain their attribution alongside the observed marks.

## Sequence of work

1. Create the complete target ledger from identifiers and preserved export joins.
2. Search for the original plates/basic-data tables and record access outcomes.
3. Freeze a first bounded image block with source coordinates before coding its graphics. Prefer caption-linked objects with visible multiple sides and physical production evidence.
4. Inspect the block and enter observations with field-specific bases. Cross-check the registration joins against captions after descriptive graphic coding.
5. Compute coverage, join completeness, source types, field availability and any clearly defined within-block comparisons. Preserve new endpoints and code snapshots.

This is an archaeological source and annotation run. A later prediction test requires its own frozen response, comparison model and withheld source block. Shared assumptions are that publication identifiers refer to the intended objects, that source drawings preserve the displayed side relations, and that uncertain joins remain unresolved in the ledger.

## Checks and report

Verify the 81 target identities, unique target rows, input/source hashes and the source-figure index. Check that every coded assertion has a source coordinate and basis, and that missing targets remain represented. Reinspect ambiguous joins and visible counts on enlarged source crops. The report should explain the acquired physical observations, the writer/potter/seal user's task, the most useful next experiment, and the access or annotation failures that affected the work.
