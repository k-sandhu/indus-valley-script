# Counting again after an interval already fits inside the stated precision

Written during the main run, after inspecting the valid-interval pilot and some main traces. This is a post-outcome refinement of the acquisition rule. Preserve the original policies and endpoint.

The original interval score is `max(0, 1 − 2r/w)`, where `r` is the prospective measurement radius and `w` is the present range width for that code. It scores a count as zero whenever the current range fits within the width of one reported interval. Another interval of the same precision can still trim that range because its centre can differ. In the valid-interval pilot, random acquisition reached one exact intersection, while the information/rank policy retained a scale interval in all four worlds.

Replace only the prospective interval score after an absolute interval has been acquired. For a bounded current range `[l,u]`, use `w/(w+2r)`. This score comes from a transparent planning distribution: choose a prospective measurement centre uniformly from `[l−r,u+r]`, the centres whose reported intervals intersect the current range. The integral of the intersection length is `2rw`; dividing by the centre range length gives expected remaining width `2rw/(w+2r)`. The resulting expected fractional reduction is `w/(w+2r)`. This is a geometric planning prior. It does not use unopened measurement centres, concealed quantities or the generator's error draw.

Keep exact-count scoring, first-scale scoring, membership scoring, costs, availability and tie rules unchanged. Preserve unbounded-coordinate treatment as one unit of potential information. Once a relative ray is known, a coordinate interval is a scale interval multiplied by that coordinate's relative weight, so this width calculation transfers directly to scale. Before ratios are unique it remains a coordinate-based heuristic.

Report exact identification counts, correct relative identification, retained scale intervals, positive ambiguity, false unique answers, count actions and first identification costs. For identified relative vectors with bounded scale, derive the final scale-interval width relative to the concealed true scale only in evaluation. Use paired worlds and preserve failed acquisitions. Verify saved certificates and classification claims with the existing independent checkers, extended only to recognize the additional policy name.

The original undercovered-count and ownership controls remain relevant: the repair changes only nonzero-radius interval scores. It therefore cannot detect a false exact count or turn ownership labels into quantities. The new endpoint addresses the interval policy's acquisition weakness; it leaves those observed control failures in the main endpoint.
