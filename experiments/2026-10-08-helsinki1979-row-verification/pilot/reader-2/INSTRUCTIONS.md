# Reader 2: read independently from source images

Read every assigned item from the source images and chart, and return its number, five-position classification, drawing count and ordered strict codes. You receive source locators and proposed-box geometry for judging crop completeness. You receive no proposed field values, counts or codes. Use a fresh independent session and a unique helper directory assigned by the coordinator.

Your permitted input is this role delivery folder: `INSTRUCTIONS.md`, each assigned `packet.json`, its image/chart assets and `return-template.json`. Do not inspect the checkout, any `proposals.json`, pipeline output, other roles, previous readings, reference answers, coordinator folder or PDF text layer. Disclose previous exposure to these corpus reference rows in `reader.independence_attestation`. The coordinator records provider/model/run, exact UTC timing, elapsed seconds and actual task usage. Missing tokens or billing stay null with a reason.

Each packet's `items` gives opaque IDs, page/column, a target y coordinate, context image and exact proposed-box image. Judge `crop_correct` from the exact box, then read the complete row from context and full-page images. A crop is incorrect when it loses target ink, including underlines, or includes another row or number/classification ink. Preserve every `item_id`, `sample_index`, page and column. Every item needs a return, including invalid locators, which use `valid_printed_target=false` and a source explanation.

Record modern drawing units in visual left-to-right order. Keep uncertainty underlines with their sign. A loss rectangle or hatched span is one editorial drawing; its ancient sign extent is unknown. Every unit needs integer `strict_candidate_codes`, `unit_kind` (`sign`, `hatched_span`, `loss_rectangle` or `unresolved`) and boolean `underline_dashes`. Retain candidate sets when fine variants cannot be distinguished; an empty set needs `uncertainty_reason`. Shape-only sets are optional diagnostics.

Use the positional chart cards and original chart images. Code 25 is the high pair of short ticks and 2 the centered pair; underlined forms have separate codes. Count stroke stacks directly: four over three use 19. Codes 597/13 are narrow hatched patches and 599/106 are wide patches, with underlined variants kept separate. Codes 597/598 distinguish cell position; spacing to neighbours can help, but insufficient spacing evidence leaves both candidates. Long-stroke drawings that coincide on the chart retain all compatible strict codes. Uncertain card labels need original-chart inspection. Included PDF16–18 images explain classification and auxiliaries.

`classification_literal` is exactly five digit/space positions, preserving all blanks, for example `11 40`. `printed_inscription_id` remains a string including letter suffixes. `drawn_unit_count` equals the length of `units`. Null fields require reasons in `unresolved_fields`. Describe visible observations directly; later adjudication uses these descriptions without reader identities. Set envelope `evidence_status` to `Frozen evaluation` for actual readings; `Synthetic` identifies constructed software fixtures.

Inventory every numbered occurrence in the assigned column using `column.png` and its full-page image. Assign top-to-bottom one-based source ordinals and approximate y coordinates in PDF points. Supplementary items may have other source pages; report their own column ordinals and exclude them from the assigned-column total. Attach unnumbered continuations using `continuation_y_pdf` and a parallel `continuation_rows` array. Each line needs `source_y_pdf`, `drawn_unit_count`, `units`, `source_observations` and `unresolved_fields`, following the same unit format. Main `units` and count describe the numbered drawing row alone, as in Package M. Uncertain attachment goes in `unresolved_boundary`. Each visible inter-unit gap of at least 16 PDF points is `blank_gaps=[{"after_unit_index":0}]` with its zero-based preceding unit index. This record assigns no ancient physical boundary.

For a numbered source row missing from packet items, add a full row with `item_id=extra:<batch_id>:<ordinal>` and `sample_index=1000000+ordinal`. Return one `columns` inventory with numbered and continuation counts, `coverage_complete` and observations. Check every source ordinal and packet item before returning; do not assume fixed row or column counts. Save the JSON to your private return location. The coordinator freezes it before exposing any other reading.

Report `observed_page_columns` from the full-page image. A difference from the packet's `detected_page_columns` needs bounds/observations in `unassigned_columns`; otherwise that array is empty. Other detected columns have separate batches and do not enter this array. A newly discovered column blocks page completeness until the coordinator prepares its reviewed packet.
