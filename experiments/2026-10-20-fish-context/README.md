# Fish signs and their object contexts

20 October 2026. We assembled 1,246 provisional fish-bearing objects and tested ordered combinations, stroke values and carrier preference. The fish order learned on discovery predicts the reserved seal texts. The numeral result depends heavily on two-stroke constructions. A narrow astronomical model and a calibrated seal-preference prediction failed their rules. A source check identifies the tablet in Parpola's 2010 Figure 6 as H-912 B, although that version labels it H-902.

Read [the report](REPORT.md), [the three-study synthesis](PROGRAM-REPORT.md), [the source correction](SOURCE-NOTES.md) and [the retrospective](RETROSPECTIVE.md).
