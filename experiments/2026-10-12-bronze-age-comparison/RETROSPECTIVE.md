12 October 2026 UTC. The user authorized pursuing four Bronze Age comparisons after discussing languages, writing maturity and short records. This run was performed by one agent with separate computational verification implementations. It did not commission a human specialist, an independent agent review or a blinded semantic-reading assessment.

## Starting evidence and source selection

The run read the README, knowledge index, registry, writing rules, redistribution record and prior methods/two-approach retrospectives. Previous controls had established reference-model uncertainty and the non-specificity of graphic grammar; resemblance coding and unrelated-symbol baselines retained defects. The new evidence is source-annotated, understood documentary material. Earlier fits and data were not repeated to select a more favorable result.

Before acquisition/scoring, the program saved five navigation files locally and hashed six further named inputs. It wrote a protocol defining observation units, source scope and preservation. A later pre-score cohort specification bounded a large Ur III archive by a fixed 3,000-entry hash sample and Greek collection by a fixed per-site sample. Letters, administrative accounts, vessel inscriptions, seals and natural subdivisions remained distinct.

## Source access

Python requests and urllib could not validate the ORACC certificate chain in this environment, while one alternate host timed out. Native curl with certificate validation obtained the public archives; no validation was disabled. The Ur III archive unexpectedly measured 561,755,376 bytes. It remains local, with streaming/hash-based checks rather than extraction into the tracked tree.

Primary Egyptian repositories supplied JSON source tokens and XML metadata at explicit commit pins. LiBER's documented page and catalogue routes supplied a fixed 512-document availability cohort. DAMOS documentation and a Linear B sequence paper were read as alternative/source-method records; no claim of an independent DAMOS numerical replication was made. Every successful or failed acquisition has a recorded URL, time, status and hash. Source permissions were inspected and all source payloads stayed under ignored data/.

## Representation repairs before scoring

Inspection caught empty/invalid ORACC JSON entries and TEI's `tla` identifier prefixes. The first normalization then stopped at Egyptian tokens without `_id`; it produced no scored dataset. The failed code and local log remain. The successor treated missing identifiers as exclusions.

The successful normalized-v2 census exposed further format errors. ORACC seal texts are surface markers and had initially been concatenated with their parent accounts. `nonx` nodes describe ordinary blanks/rulings through `state`; the initial predicate examined `subtype` and unnecessarily excluded records. AES glyph strings usually contain numeric HTML entities, so extracting literal characters found only one complete glyph sentence. The revised parser decoded entities, separated seal modules, handled layout correctly and excluded addition markers. Each source observation and earlier dataset is retained in the [parser amendment](PARSER-AMENDMENT.md).

These repairs changed available observations before any predictor was fitted. They were informed by source-format and census checks and remain disclosed as exploratory decisions. Ad hoc inspection also exposed a Windows console Unicode issue and a helper syntax error. Reusable Python files with UTF-8 invocation replaced those inspection commands; neither affected a saved statistical endpoint.

## Primary outcomes and a weaker observation set

The first statistical endpoint ran the fixed position reference, grouped word-category controls and lexical-pattern compatibility construction. It retained eight small complete Akkadian word groups and insufficient complete sign groups. The word control's strong Sumerian/Egyptian results also exposed its supplied segmentation and frequent-identity advantage.

That limitation motivated an explicitly post-outcome sign control. It expanded each source word tag over its sign/readings, hid boundaries from features and retained the same models/group rules. The new length unit changes eligibility, so the manuscript does not interpret word/sign accuracy differences as a boundary-deletion effect. Identity-only and shuffled-label controls remain in both endpoints. Greek's task stayed written-unit type prediction; a missing personal-name key was not invented.

The extension graphs matter. Frequent exact lines connect many different source documents. Preserving those edges produced a Sumerian word-control component with 12,563 rows and a strongly uneven fold. The endpoint reports that difficulty rather than splitting the component to improve the result's apparent independence.

## Source audit after the first results

A subsequent LiBER markup audit showed that query links can remove restoration brackets and underdots from displayed transcriptions. The initial parser assessed certainty from a query spelling. A scan flagged 298 anchors accepted despite displayed uncertainty, missing text or unsupported annotations. The old statistical endpoint was scientifically limited by that representation mistake even though its arithmetic/split checks passed.

The post-result source repair assessed both display and query, with unresolved arrow/bullet notation excluded. It acquired no replacements. The new input and endpoint have distinct names, normalized-v4/run-v2/sign-control-v2. The Greek complete short structural population fell from 45 to 28 distinct sequences. Its word-control contextual accuracy fell from 87.34% to 83.92%. Every non-Greek numeric cohort result matches the earlier endpoint exactly. The [comparison](source-correction-comparison.json) documents that scope.

This episode separates source correctness from numerical verification: a successful recount of a wrong representation cannot authenticate the underlying transcription. The final checker therefore adds direct displayed-markup audits alongside output hashes, analytic reference expectations and prediction replay.

## Interpretation and completion

All eleven testable structural cohorts retain ordering under their declared references. Known categories are partly recoverable, with repeated identities contributing substantially and source-unit/class support defining the result. Equal-entry-count lexical inventories all match most IVS equality patterns under the weak independent-per-face correspondence rule. The global inventory bound is a separate necessary constraint, not a fitted shared key.

The completed package contains the source/observation record, code, endpoints, manuscript, methods, claim map and prospective tests. All raw corpora and record-level derivatives remain local. Earlier input bytes and numerical endpoints were preserved; only research navigation and new registry entries were integrated after verification. No CI/CD, recurring automation, external submission, public push or visibility change was performed. Future work needs better matched physical glyphs, complete Akkadian short records, richer Greek semantics and independently observed Indus functional/quantity joins.
