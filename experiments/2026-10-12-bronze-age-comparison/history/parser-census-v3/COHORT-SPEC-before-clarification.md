# Acquisition cohorts and fixed comparison details

Written after format inspection and before scoring. This specifies choices left open in the initial protocol.

The acquired Ur III archive contains 80,181 text JSON entries. Parse the 3,000 entries with the smallest SHA256 of `20261012:<textid>`; retain their complete source metadata and exclusions. This bounds parsing and provides a reproducible sample without choosing texts by their results. Parse all acquired Old Babylonian Altbabylonische Texte letters and Rīm-Anum administrative editions. Check each edition's token-language codes rather than inheriting a language from the period.

For Egyptian, parse the acquired AES archive and Old Kingdom/First Intermediate Period tomb-inscription subcorpora. Use only date `OK & FIP` in the primary Egyptian population. The archive's examples have word/POS annotation but lack glyph encodings; retain that word-level control separately. Tomb examples with complete source `hiero_unicode` for every retained word can supply a glyph-level sentence extension. AES sentence IDs and source text IDs remain separate. A sentence is not automatically an entire object inscription. Retrieve AED-TEI metadata for source-check examples to resolve object and textual scope.

For Mycenaean Greek, acquire at most 96 documents per catalogue site, chosen by the smallest SHA256 of `20261012:<id>`. Include the smaller site inventories without replenishing lost or failed documents. This is a stratified availability pilot, not an estimate of the full Linear B corpus. Preserve all source line labels, editorial markers and compound/logogram notation. Source logograms, numerals and syllabic spellings provide a written-unit class key. They do not provide an independently resolved personal-name or title key.

For each language retain whole source texts, source seals and natural lines/sentences as distinct strata. Structural outcomes use distinct sequences of length 3–12 after rejecting unresolved damage, restorations and missing units. The full source text is eligible only when all constituent units are readable under the parser rule. A separately legible seal can remain eligible when its parent account is damaged, with the shared physical/text group retained. Indus eligibility follows the existing clean/completeness flags and preserves its full-register grouping.

The structural primary statistic is the weighted mean squared departure of a token's normalized position from 0.5, restricted to token types with at least five occurrences. For each type, use the square of its mean normalized position minus 0.5, weighted by its observed occurrences. Shuffle independently within each retained sequence, preserving length and unit counts, for 1,999 references. Also give opener/closer entropy, adjacent-pair repetition, identical-sequence counts and length distributions as descriptive outcomes. Comparisons between corpora retain their encoding and unit labels. No cross-language significance ranking is inferred from separate shuffle p-values.

Known-category control uses source word/POS classes for Sumerian, Akkadian and Egyptian. Source tags are mapped to NAME, NUMBER, VERB, FUNCTION, NOMINAL or UNKNOWN with explicit source-specific rules. UNKNOWN targets are excluded from the category score and counted. The model receives only random anonymous word IDs, preceding/following anonymous IDs, five normalized-position bins and length bins (3–5, 6–8, 9–12). Five grouped folds are selected by a seeded greedy token-balance rule after physical/text and exact-sequence closure. A categorical naive Bayes model with pseudocount 1 compares identity/context/position features against position/length-only and training-majority baselines. Label names and lexical glosses never enter features. This is a supervised held-out category calibration using source training tags, not an unsupervised discovery of meanings. The Linear B extension uses the source's separate NUMBER/LOGOGRAM/SYLLABIC class key and reports that different task explicitly.

Model selection is fixed; no outcome selects features or smoothing. Report micro accuracy, balanced accuracy, class support, known-ID and unseen-ID strata. Split failures caused by insufficient independent groups remain outcomes. A label-permutation training control preserves training class margins, uses seed 20261012 plus fold index, and evaluates against the unchanged held-out key.

Lexical ambiguity control uses source-observed complete word spellings in reading/glyph units. An equality pattern replaces each distinct unit by its order of first appearance. Under the deliberately restrictive hypothetical one-word-per-Indus-face and bijective-unit assumptions, count how many lexicon entries share each Indus equality pattern. Report natural lexicon sizes and a size-matched comparison using the same minimum inventory size, at most 200 entries, 500 seeded samples. This measures compatibility and ambiguity under the stated construction. It supplies no phonetic mapping, no probability for a historical language and no claim that IVS words coincide with complete faces. Sanskrit's dictionary-letter windows are documented separately because those letters are not an equivalent script-unit inventory.

All row-level datasets, folds, anonymous-ID mappings and predictions remain local. Public outputs contain aggregates, source locators, hashes and own explanations. A parser correction after calculation will receive a new endpoint and a documented amendment.
