# Observations that would improve this comparison

The completed controls identify specific gaps. New fits should begin with a dated protocol and new source/observation block; the existing outcomes remain frozen.

## Physical glyphs and the same source objects

Build a source-reviewed glyph inventory for short Sumerian seals and accounts, preserving variant, damage and sign-reading distinctions. Select the same objects for a paired experiment with word-boundary features available or concealed. Keep each object's units and source category key fixed. Measure the contextual increment over identity and the change in balanced category recall. This isolates information supplied by boundaries; the present word/sign cohorts change their eligible populations and cannot supply that effect.

Use held-out physical/production families and a separate unseen-name subset. A gain restricted to already-known names would identify lexical reuse rather than general recognition of a name field. Failed rare-category recall and inconsistent word annotations remain outcomes.

## Complete Akkadian records

Acquire an independently reviewed, dated set of genuinely short seals, receipts and labels with complete object/text joins. The present three short complete tablet readings plus one seal do not support the five-fold sign control. Source annotations must distinguish Akkadian words, Sumerian formulae and borrowed logograms. A period label alone cannot establish a word's language.

Freeze the physical-family/complete-text group rule before inspecting prediction scores. If the resulting graph provides too few independent groups, report the blocked sampling design and change the source acquisition rather than splitting related records across folds.

## Greek meanings beyond writing-unit types

The current Greek control recognizes syllabic spellings, logograms and numerals. To test names, titles, places or commodities, obtain assessed lexical interpretations with explicit alternatives and source loci. A disputed name reading cannot become a certain answer key through repetition in a lexicon.

Select cases with independent commodity or person/context joins, code the key before anonymous prediction, and retain uncertain classes. Hold out whole documents and scribal/physical joins. Report each category's support and prediction against position and identity baselines. Failure to distinguish names from ordinary syllabic words would limit the proposed semantic transfer.

## An IVS functional observation block

Use a source-joined group of Indus objects with independently observed attachment, contents, measured quantity, issuing association or use/cancellation history. Before reading their texts, define two or more rival uses and the observations that distinguish them. The earlier Lothal/Harappa/Kanmer frames and whole-object work can locate candidates, with their unverified joins retained.

For an identity interpretation, a module should persist across independently identified differences in goods or amounts. For a commodity or capacity interpretation, independently identified contents or measurements should predict its variation. For a reusable entitlement, use history and validity marks should distinguish repeated presentation from a completed transaction. Code those observations without the proposed sign meanings and keep production/copy families together.

## A shared linguistic key

Any word-based continuation needs a declared mapping model and correspondence scope. All target inscriptions must use the same key unless a separately specified regional/chronological model supplies a testable reason for change. Record segmentation, permitted sound changes, dictionary size/date coverage, compounds and every attempted reading.

First test that recipe on an understood source population with hidden identities and an independent reference. Measure incorrect confident mappings and transfer to genuinely withheld objects. For IVS, reserve an external quantity, name/context or bilingual observation where one is available. A high per-face dictionary coverage without a shared key should retain its current status as an ambiguity result.
