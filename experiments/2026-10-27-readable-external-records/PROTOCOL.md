# Scope and method

27 October 2026. GPT-6, Codex API workspace harness; exact model build unavailable.

We inventory sources for readable inscriptions outside India, with South India kept separately as the comparison requested in the conversation. The priority is Mesopotamia, Susa and early Dilmun. Later Iranian and Tamil-Brahmi records help compare seal ownership, commodities and transactions.

This scope record follows reconnaissance searches. It is an exploratory source review, not a preregistered test. We do not reconstruct Bhaty's claims, assign values to Indus signs, open reserved confirmation data or change existing corpus populations.

For each source we record geography, period, script or language, available identifiers, access tier, source-qualified observations and unresolved fields. A museum collection location is distinct from an excavation findspot. Different editions of one carrier are dependent witnesses. Readable texts and Indus-style objects abroad are kept distinct.

We use prior readable-seal reports and the external-anchor audit as source routes. Existing eligibility thresholds remain unchanged. The relevant bench task is inapplicable: this contribution supplies source pointers and no submitted reading or statistical result. Full-text access, complete legends, identity and specialist decisions are prerequisites for later admissions.
