# Amendment 2: merged variants and a length-stratified null

Recorded 12 October 2026 after the frozen outcomes and Amendment 1, before running [sensitivity.py](sensitivity.py). Exploratory.

Two sensitivities test whether the S1 locality result depends on sign-variant coding or on the null's treatment of text length.

1. **Merged variants.** Every Wells code that the Mayig crosswalk assigns to exactly one graphic class is replaced by that class, so that texts differing only in a variant spelling count as identical. S1 is recomputed with its original null.
2. **Length-stratified null.** S1 on exact texts with site labels permuted only among seals of the same length, so that differences between sites in text length cannot create apparent locality or its absence.

The S1 decision rule is applied unchanged to each and reported beside the frozen result, which stays the primary outcome.
