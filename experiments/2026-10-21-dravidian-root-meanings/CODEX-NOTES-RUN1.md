# Mechanical run 1

We acquired the five Kolipakam supplementary files, verified their MD5s and recorded their SHA-256 values, sizes, article identifiers, DOIs and licences. DravLex is pinned to commit `37578075e5ccb09c43022f7f1282125e748de84d` under CC BY 4.0. We fetched the selected dictionary pages, boundary pages, front matter and six definition searches. The source manifests in `run1/` record the new coverage and fields for later integration into the shared data records.

The code parses entries, builds the language mapping, prepares the tree sample, codes meanings and constructs reference pools. Dictionary text, evidence and per-tip states stay local. We tested reconstruction and reference statistics with fabricated and simulated traits. We computed no ancestral-state probability, parsimony score or reference statistic on real codings. The driver requires a matching code freeze before it reads real codings and refuses an existing result directory.

Author: GPT-6.1-Sol in the Codex CLI harness. Commands and file handling are in [TOOLS.md](TOOLS.md); [created-paths.json](run1/created-paths.json) lists the files. This contribution changes only the owned code, run outputs, three Markdown files and local source directories. Other sessions' changes are recorded separately in local `git-status.json`.

## Choices that implement the specification

| Area | Choice |
|---|---|
| Boundary acquisition | We fetched the following page for every requested primary page and every linked S4 page. This permits boundary inspection without deciding in advance whether an entry continues. Repeated complete entries are deduplicated by their numbered subentry; the longest complete block is retained, and genuine numberless continuation blocks are appended across consecutive pages. |
| Form counts | Comma-separated citation forms outside parentheses are separate records. Inflectional paradigms remain attached to the citation form. A form with different postposed dialect glosses gets one record for each dialect gloss. Inherited-gloss and segment totals count records, including shared and inherited text. The tip-coverage count includes forms before borrowing and doubt exclusions. |
| HTML | Bold runs supply forms; language sigla are recognised even when an italic tag is absent or shares a run with a dialect label. Grammar and citations inside a form stay attached across markup boundaries. Cross-references and the slash ending the Dravidian material close the parsed record. |
| Inheritance | A queued series shares the next gloss. An omitted gloss or an explicit identity marker inherits the immediately preceding gloss in the same entry. A missing predecessor is an issue for review. Numeric glosses remain available to numeral coding and are removed from reference pools under the reference rule. |
| Dialect scope | A dialect or source label persists within its language until another label appears. Labels after a form are read before parentheses are removed. A group containing Koya and another Gondi variety contributes to both corresponding tips. |
| Koya and Gadba | Explicit Koya labels map to Koya. Gondi `(Ko.)` is provisionally Koya and flagged because the front matter delegates that siglum to the comparative vocabulary. Unqualified Gadba is left unmapped. Ollari maps to the tree tip; Salur and Kondekor sources do not. |
| Badaga and the Kurumba varieties | Kannada Badaga and Hockings labels map to Badaga. The independent `Kurub.` label maps to Betta Kurumba. Other Kurumba labels retain their distinct language identities. No Yeruva label was found. |
| Sense matching | Heads follow the final-word rule literally. Multiword entries in the EARRING head list therefore cannot match a single-word head; its separate ring-and-ear clause still applies. Rules that say “contains” use substring matching, including WHITE and YOUTH; NORTH uses the specified whole-word match. Named STAR and VELGOD alternatives use accent-folded name matching. S6 uses only the literal first-keyword head. |
| S4 normalisation | Raised dots, including the Greek raised-dot character used by the HTML, the IPA length mark, and combining acute and grave accents are removed. Other letters remain unchanged. |
| S4 search cards | Cards are matched to headwords on their linked page. When a card lacks a usable headword, we retain entries on that page whose source text contains the queried definition term. Eighteen cards needed this recovery; eight have multiple candidates. The union is retained for review, with every candidate recorded locally. |
| S3 forms | The regular expression is applied to the pinned CLDF `Form` column after NFC and lower-casing. It is not applied to the segmented transcription, and an ASCII colon is not substituted for the IPA length mark. All forms for the STAR concept count, as the S3 rule specifies. |
| Eligible forms | Borrowings are excluded before establishing tip coverage. S1 also excludes doubtful forms; a tip with no remaining eligible form is missing. A compound's internal morphological linking marker is not treated as a borrowing arrow. |
| Reference pools | Pools contain distinct eligible heads. A head is removed if any eligible segment with that head belongs to an assigned needed class. The summary counts both dropped distinct heads and removed segment occurrences. S1 rebuilds pools after doubt exclusion; S6 uses the keyword rules for exclusion; S7 uses the literal entry locations. S8 keeps the primary pool exclusions while changing the explicitly recoded needed segments. |
| Reference random numbers | Rows are reference sets; columns follow the needed-meaning order in `common.ENTRY`. Pool heads are sorted. A single vectorised integer draw supplies 10,000 sets with the prescribed generator and seed. Empty pools remove the corresponding meaning from both sides of each comparison. |
| Rate fitting | Mk1 tests 61 equally spaced log rates, refines the interval around the best grid point and retains endpoint candidates. Mk2 uses ten starts: the symmetric estimate and a three-by-three grid of log-rate starts. Flat and stationary priors are fitted separately. A rate within `1e-5` of a log bound is flagged. |
| Nodes and ages | Scaling uses the root-to-tip height of the input tree. Ages retain the source scale. “Oldest node” includes tips if no internal node qualifies; ties use node identifiers. Year units are inferred from the article and protocol because the NEXUS file has no explicit unit declaration. |
| Posterior selection | With no burn-in statement found in the supplementary text, we discard the first 1,800 of 18,000 records. Integer-floor positions from inclusive `linspace` select 1,000 of the remaining 16,200. Every needed meaning is refitted on every selected tree. |
| Sensitivity scope | S2 fits all needed meanings under both root priors. S3 and S4 reconstruct STAR alone. S1, S6, S7 and optional S8 repeat the comparison using their coding variants. S5 reports root and North summaries for every needed meaning. |
| Sparse traits | The library returns a flag below two observed tips. If STAR has that flag, the driver leaves its pass, kill and credence conclusions uninterpreted. The reference statistic otherwise follows the specified nonempty-pool rule without an extra observation-count exclusion. |
| Synthetic tests | Calibration uses 500 traits on the MCC tree and 500 independently generated Yule trees, with rates drawn log-uniformly from 0.001 to 30 and about 30% missing tips. Known-rate and fitted-rate predictions use the same simulated traits. Intervals are exact Clopper–Pearson 95% intervals. The synthetic driver uses a three-tree sample to exercise the S5 summary code. |
| S8 hook | Local `manual-recode.json` addresses a segment by meaning, assigned entry and nonnegative form and segment indices. Membership must be boolean; an optional segment hash checks the text. The driver detects this file before the first frozen computation. |

## Checks and source problems

The exhaustive tests compare likelihoods and internal marginal probabilities to enumeration at tolerance `1e-10`, under Mk1 and Mk2 with both root priors. Sankoff sets are checked against whole-tree minimum-cost assignments, including missing tips. Closed cases, scale invariance, planted traits, parsing, sense classes, reference draws, NEXUS input and freeze guards are included in [selftest.json](run1/selftest.json).

Calibration is descriptive: it measures the behaviour of the specified estimators. The observed share of correct calls was 0.818 for known rates and 0.810 for estimated rates on the MCC tree, and 0.828 and 0.836 on Yule trees. The ten-bin counts, observed frequencies, mean predictions and intervals are preserved in the selftest. Several middle bins are small; their intervals carry that sampling uncertainty.

All chosen entries have zero unread issues. S4 still needs review of malformed source markup in entry 4333, form record 39 on language line 4, and entry 4572, form record 0 on language line 0. Indices are zero-based. Entry 4572 also has no preceding gloss to inherit. Local parsed records retain the source path and hash. The S4 search resolution lists the eight ambiguous recoveries separately. These are input-review matters before freezing.

The tree matches all twenty tips and is ultrametric. Its root age is 4,433.0664 years and its North node age is 1,942.7854 years. North, South I and South II are monophyletic; Central is not. The XML gives a chain length of 100,000,000 and a tree-log interval of 5,000, while the supplied archive contains 18,000 records. We apply the protocol's burn-in rule to those supplied records; the difference from the nominal logging count remains a source-history question for review.

Several mechanical failures were corrected. Isolated Python could not see the installed NumPy and SciPy packages, so the code adds the interpreter's package directory explicitly. The archive contains a macOS metadata file with a tree suffix; it is excluded from source selection. PDF text extraction initially used a non-UTF-8 default, so the command now requests UTF-8. A guessed figshare metadata identifier returned 404; the article catalogue identified the robustness supplement as `5965687`, and the manifest now verifies that article's file ID and licence. The request log preserves the failed requests.

Some italic runs combine grammatical text and the next language label. Reading those labels only as complete markup runs assigned later dialects to the preceding language. The parser now separates language labels outside parentheses, and synthetic tests cover that boundary. Early acquisition reused files only within the destination directory, so overlapping primary and S4 pages were requested again. It now reuses a logged URL and hash across destinations; the log retains the additional requests.

A storage failure interrupted a mapping write. We removed only the regenerable 34,309,239-byte posterior extraction, preserving the verified original ZIP and selected sample. The tree reader now streams that archive when the extracted cache is absent. JSON outputs are written through a temporary file and replaced only after a complete write. We rebuilt the interrupted mapping. Git's ownership check is handled with a command-local `safe.directory` setting; no global Git configuration was changed.

The source-text scan covers all parsed files, including intermediate records outside the current S4 index, and retains literal matches locally. Matches in filenames, booleans, grammar labels and ordinary English used independently in code are reviewed individually; the tracked record holds counts and hashes. Five matches labelled as forms arise from computational rate keys and grammar or source labels captured as forms by malformed or intermediate parses. They contain no dictionary form data. No dictionary form or gloss quotation is included in the code or aggregate outputs. The prose scan and specification hashes are checked again after the documentation is complete.
