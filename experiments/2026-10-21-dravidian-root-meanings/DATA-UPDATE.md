# Sources and rights for maintainers

This package adds no inscribed object and no object field, so object coverage in `knowledge/DATA.md` is unchanged. It adds three comparative-linguistic sources, recorded here for `knowledge/DATA.md`, `data/MANIFEST.json` and `knowledge/provenance/REDISTRIBUTION.md`. Hashes of every fetched file are in the request logs named below and in `run1/sources-*.json`.

A DEDR-linked lexicon with an open licence exists: Louis L. Merriam and Andreas Fuls, Dravidian lexicon v1.2, CC BY 4.0, DOI 10.5281/zenodo.22682542, noted in `experiments/2026-10-12-data-inventory/sources.json` as 15,629 reconstructions linked to 72,091 DEDR lemma records. It was not used here. A rerun built on it could track per-language codings, which the DEDR terms keep local.
