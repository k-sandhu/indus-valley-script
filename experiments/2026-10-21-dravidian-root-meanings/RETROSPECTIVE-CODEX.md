# What we delegated to Codex and how it went

The coordinating session (Claude Opus 5.5 in the Claude Code desktop app) wrote the protocol, chose the dictionary entries, wrote the amendment and every sense-coding decision, froze the code and wrote all prose. The mechanical work went to the Codex CLI (`codex-cli` 0.160.1) running `gpt-6.1-sol` at `model_reasoning_effort=xhigh` in a `workspace-write` sandbox: one run from [CODEX-PROMPT.md](CODEX-PROMPT.md) through [launch-codex.sh](launch-codex.sh), with web search and sandbox network access, and one follow-up in the same Codex session from [CODEX-PROMPT-1B.md](CODEX-PROMPT-1B.md) through [launch-codex-1b.sh](launch-codex-1b.sh), without network. Both were launched by hand, detached from PowerShell through Git Bash. Logs stay local in `data/raw/2026-10-21-dravidian-root-meanings/codex-logs/`.

## What Codex built

Run 1 lasted 88 minutes (03:26 to 04:53 UTC on 21 October). It downloaded and verified the five CC BY 4.0 supplementary files of Kolipakam and colleagues and a pinned CC BY 4.0 release of DravLex, fetched the dictionary pages, front matter and star-word definition searches with a request log, and wrote eleven scripts in `code/`: acquisition, a parser for the DSAL entry pages, the table from dictionary language labels to the twenty tips, a NEXUS reader with the posterior sample, the parsimony and two-state likelihood library, the sense coder, the reference pools and draw, the hash-gated driver, the tests and a validation script. Its tests compare likelihoods and node probabilities with brute-force enumeration on small trees under both models and both root priors, compare parsimony sets with enumeration, check closed cases and scale invariance, and measure calibration by simulation on the MCC tree and on random Yule trees; 238 tests passed at the end of run 1. Its notes, [CODEX-NOTES-RUN1.md](CODEX-NOTES-RUN1.md), list every place where it had to read the specification, and [TOOLS.md](TOOLS.md) gives the commands.

## What review found

We reviewed the outputs in three ways that did not use Codex's code: an independent count of language labels at line starts in the flattened text of every chosen entry, a reading of every tip's coded glosses against the sense rules, and an independent implementation of the primary model ([verify/independent_check.py](verify/independent_check.py)), checked against brute-force enumeration before any real coding was read.

The label count found that the first version of the parser missed a language label that follows a gloss ending in a period after a parenthesis ("… (masc.). Go. …"), so the Gondi and Konḍa forms of entry 5052 fell under Gadba and the Gondi tip was missing for "three". Codex found and repaired the same defect before its run ended; our count then agreed for every entry but 5496 (a), where a cross-reference inside parentheses opened a second Tamil line. Run 1b (04:57 to 05:15 UTC) repaired that, added an audit that no language line begins inside parentheses, and changed no needed-meaning coding; one reference gloss lost a spurious Tamil value. The final selftest has 241 tests and no failures.

The coding review found no parse error among the tips coded 1. It found five glosses that the frozen rules code 0 although they plainly carry the meaning, which became the plain-reading sensitivity analysis S8: "three persons" and "three things" in Kurukh, Parji and Kolami, the Tamil earring gloss whose head is "helix", and Malayalam "open field" for SPACE.

## Problems and repairs

Isolated Python (`python -I`), which we require for scripts that read downloads, drops the per-user package directory where NumPy and SciPy are installed on this machine; Codex and we both add that directory back explicitly. The first prompt described the posterior archive as trees "without burn-in removed"; the file holds 18,000 trees, which is 90% of the 20,000 that the XML's chain length and logging interval imply, so a 10% burn-in had probably been removed already, and the protocol's extra 10% discard only thins the sample. The drive filled completely near the end of run 1, through the downloads of several sessions running at once; Codex deleted its own 34 MB extracted posterior cache, rewrote its JSON writes to be atomic, and finished, but its final message could not be written. The selftest written during the run recorded the hash of an empty parser file while the parser was being rewritten; the final selftest matches every file.

## Judgement

The delegation worked for this kind of study. Codex's code was careful about provenance, hashing and the freeze gate, and its tests are stronger than the protocol asked. The one substantive defect, in parsing dictionary text, would have changed a coding silently; an independent check of the parse against the source text found it, and we would run such a check again before trusting any parse of DEDR.
