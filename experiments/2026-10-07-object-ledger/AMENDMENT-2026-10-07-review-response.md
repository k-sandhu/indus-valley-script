The accepted periodization scheme is recorded.

Museum dimension parsing accepts explicit mm, cm/cms./centimetre variants and inches, with labelled axes preserved and unlabelled axes kept as dimension_1 etc. Inches convert at 25.4 mm. No axis equivalence is inferred from position. Source count disagreements for L-141 and L-174 will retain separate witnesses; CISI corrigenda and plates support the accepted two-impression view, with L-141's caption interpretation flagged for expert review. L-173 to L-175 receive the source geometric-design classification in the eligibility queue. Targeted CISI pages will be opened, without bulk rendering.

Schema version 2 adds lot/citation/raw-identifier, country, periodization scheme and mass. The validator checks schema, table/cell assertion equality, references, locator records, source attribution for HARP dates, unit compatibility, finite positive quantities and plausibility (length at most 1000 mm; mass at most 100 kg; dates within 4000-1000 BCE). These broad pilot checks are error screens, not archaeological dating. Accepted Harappa intervals must fall within the period label's range. The sequence guard is a heuristic: inspect structured payload keys, short code arrays and token strings, plus CSV, Markdown and JSONL. Bare three-digit numbers in bibliographic contexts need explicit handling because dates/pages resemble sign codes. Reuse the review's 26 mutations without altering its scripts or outputs; compare added errors against a clean corrected baseline. Also test its fourteen sequence fixtures and single-sign cases locally.

The Helsinki interface accepts letter-suffixed text numbers and keys each occurrence by Package M segment_id. Text-level concordances expand to occurrences only after explicit surface alignment; duplicate witnesses remain distinct. A reviewed concordance may create a source-qualified surface on a catalogue-only carrier. CISI aliases normalize spacing and side suffixes within a declared scheme. An adapter converts Package M crosswalk fields and records unsupported/missing fields for quarantine. CISI 1 p.365's Finnish Concordance column is a lead requiring an edition-to-number verification, not an automatic object join. No real payload will be accepted without reviewed identity and surface evidence.

Report completeness, joins, disagreements, missingness, lookup cost including and excluding rights rules, external site/country counts and region/site coverage for each selection. Negative results include failed quotas, unresolved locator records, contradictory accepted cells, missed mutations, ambiguous joins or no metadata gain. The second selection and all revised outputs remain Exploratory because the design follows an observed review. A replay compares hashes and writes copies only in local raw. README commands and the list of local inputs will be checked, and Markdown will receive the repository prose review.
