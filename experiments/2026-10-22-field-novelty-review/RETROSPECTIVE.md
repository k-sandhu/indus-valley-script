# Retrospective

We began with the eight contribution families in the preceding discussion and the project's 2 October novelty review. We separated the novelty of each broad idea from the narrower measurement, correction or resource that the current evidence supports. We inspected source passages alongside protocols, saved aggregates, amendments and adversarial reviews.

The most consequential search result was a public project with closely overlapping approaches. Its current page claimed a September date, but a mutable page could not date every result. We queried the file's Git history and inspected its content at an October 1 commit. That established an earlier recorded version without treating the project's numerical claims as verified.

Primary sources further narrowed the structural and restoration claims. Koskenniemi preceded recurring-unit analysis; Bhaskar discussed physical line divisions; Rao's restoration model already used modified Kneser–Ney. Kenoyer and Meadow documented archaeological change. Raghavendra supplied earlier counterexamples to dictionary and unicity arguments. These comparisons changed the proposed publication claims rather than the preserved experimental endpoints.

We replayed the saved segmentation scorer into this directory. It reproduced the original endpoint and provenance. This verified the distinction between required-line recall and unavailable word-boundary precision. We did not retrain models or inspect new reserved objects. The review records remaining repairs for restoration dependency groups, Harappa chronology, Tamil frequency matching and dictionary parsing.

Some web routes failed: journal.fi returned a service error, a Harappa PDF filename timed out, Nature redirected to a cookie gate, and full-text routes for the permutation paper were blocked. Institutional author copies, a second primary PDF route and the accessible article page resolved the first three; the permutation comparison remains abstract-level in this review. A local print command encountered Windows character encoding on a mathematical minus sign; subsequent reads use UTF-8 or escaped JSON. No source file was modified by these failures.

The report recommends two focused existing manuscripts, a data paper after a bounded accuracy audit, and specified repairs for the next candidates. It makes no exhaustive first-in-field claim. The boldest supported assessment is that reproducible evaluation and source reconciliation are the project's strongest publication contributions; their deciding checks are independent source adjudication and replay under the declared dependency rules.
