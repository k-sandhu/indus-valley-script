# Amendment 1, 13 October 2026: caption check of every file name, name corrections and aliases

Written after the first development build of the index and before the verification samples were drawn. The protocol hash is in `PROTOCOL.sha256`; this amendment adds steps and changes no rule already applied.

**Caption check of every file name.** The protocol planned to check the names on a sample. Because every Lipi crop carries its printed CISI caption, the whole set can be checked first. `crop_ocr.py` reads each crop with tesseract (enlarged to a shorter side of 600 pixels, sparse-text mode) and `build_index.py` looks in that text for each key of the file name, tolerating the usual OCR confusions (O for 0, l or I for 1, S for 5, B for 8, a missing hyphen). Each file gets one of five results: all keys found, some found, another catalogue key found and the file's own key not found, no key read, or no text. The OCR text stays local; the tracked index holds only the result and the other keys found.

**Name corrections.** The 182 files in the class "another key found" were viewed as enlarged caption strips (`ocrcheck/strips-1.png` to `strips-5.png`, local), and six at full size. In most of them OCR had misread digits of a correct caption. In 23 the printed caption names a different object from the file name, for example `H-502_B.jpg` captioned H-902 B, `M-500_A (1).jpg` captioned M-900 A and `AL-18_A_1_LV_.jpg` captioned Kd-16 A (1). These 23 files, `His-1_A.jpg` (Hls-1), `H-795_B.jpg` (whose crop also shows H-800 F) and `Ad-8_ma.jpg` (captioned Ad-8 aa) are listed in `name-overrides.tsv` with the caption read; the index uses the caption, and the link carries the flag `file-name-corrected-by-visual-reading`. Files whose caption OCR could not read keep their file-name key; the random verification sample measures how often such a name is wrong.

**Aliases.** CISI 2 records that its Amri entries Ai-1 and Ai-2 are CISI 1's Amri-1 and Amri-2 (evidence census `catalogue-coverage.csv`, row Amri). Lipi uses Ai-1 and Ai-2, and the crops are named `Amri-1_A_66_.jpg` and `Amiri-2_A_66.jpg`. `key-aliases.tsv` maps the two CISI 1 keys to the Lipi keys; such links carry the flag `alias:<file key>`. The prefix rule for an upper-case I written for l stays as written; the single case of a lower-case i (`His-1_A.jpg`, caption Hls-1 A) is handled as a name correction.

**Verification samples.** Unchanged from the protocol, drawn after this amendment from the final link table: 60 links at random, 20 links from objects with several faces, and 15 links from several-key crops, corrected prefixes, aliases, name corrections and caption-read files. The caption check above is reported separately from the sample precision, because it measures agreement between the name and the caption, not the side or kind of the link.
