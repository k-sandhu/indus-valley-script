## 3. What to build

All code in `experiments/2026-10-13-cisi-basic-data-full/`, standard library plus numpy and pandas, runnable from the repository root, each script with a docstring giving its command line.

1. **`cisi_parse.py`**: a parser for one entry line of either volume, generalizing the pilot's `parse.py`. Keep the pilot's output fields and schema (`schema.json`) and extend them: CISI 1 column 3 markers `(o)` and `(t)` and multiple excavation numbers; CISI 1 museum codes. The CISI 1 abbreviation list (printed p. 366) includes ABD, AI, AM Trichur, ASI, ASI-EBS, ASI-VC, DAH, DC Pune, Hardwar, IM, KC, KM, KRI, LCKN, LTH, MDS, NMI, PTN, PWM, Rohtak, Sali, Saraswati and SRG among institutions and HU, Si., Pu., KVR, FEM, EH, CE, MIC, Rao, Thapar, Yule and others among photograph and publication sources; CISI 2's codes are in the pilot's parser. Parse unknown codes generically (a leading code followed by numbers) and report them. Parsed fields are derived only from the printed cells.
2. **`compare_passes.py`**: for every block with both passes, align the entries by CISI number (handling piece lines, duplicated overlap rows within one pass, and rows present in one pass only), compare the five cells after normalizing whitespace, and write (a) a local disagreement list per block, `data/raw/2026-10-13-cisi-basic-data-full/compare/<block>.todo.json`, giving each disagreeing cell with both readings, plus the strips of the block in which the entry's CISI number is likely to appear (by its position in the pass order), for the adjudicators; (b) a tracked per-block count file `accuracy/<block>.compare.json` with cells per column, agreements, disagreements, rows in one pass only, duplicate rows, bracket counts per pass, reading times from the `# started`/`# finished` lines, and no values.
3. **`build_finals.py`**: apply each block's adjudication to pass 1 (cells both passes agree on are final as read), write `data/raw/.../final/<block>.final.txt` in pass format and `final/<block>.final.jsonl` parsed, and write tracked `accuracy/<block>.accuracy.json` and a volume summary `accuracy-summary.json`: per volume and column, cells, agreement, outcome counts, first- and second-pass error rates and upper figures as defined in `PROTOCOL.md` (an error is an adjudicated wrong definite reading; a bracket whose candidates include the final reading is not an error; the upper figure adds undecidable cells in which the pass gave a definite reading). Refuse to build a block whose disagreements are not all adjudicated, and list them.
4. **`merge_volumes.py`**: merge the final blocks of each volume, adding the pilot table for CISI 2, into `data/raw/.../cisi1-basic-data.jsonl` and `cisi2-basic-data.jsonl`; refuse duplicate CISI numbers; for each site prefix, list every number between the lowest and highest present that has no row (ignore letter suffixes when computing gaps), write that list locally and its counts to tracked `merge-summary.json`.
5. **`crosscheck.py`**: after merging, list for re-reading (locally) every cell where (a) the excavation number differs from the Lipi family's `excavation-idno` after allowing for an appended FC tail and area prefixes, using the pilot's rules in `join.py`; (b) the museum number differs from the older export's `MUSEUM`; (c) for Mohenjo-daro entries that join a Mackay or Marshall table row in the join table above, the FC number differs from 2000 + Mackay No. or 1000 + Marshall No. Write a tracked count file `crosscheck-summary.json`. Also accept a recheck file `data/raw/.../recheck/recheck.json` (records with cisi, column, outcome `confirmed|corrected|ambiguous|source-defect`, final) and apply it on a rebuild, only to cells no blind adjudication decided, as the pilot's `build_final.py` did.
6. **`join_full.py`**: join both merged tables (and the pilot) to Lipi families by CISI base number with the pilot's rules; write tracked `coverage.json` (before and after by volume, by the inventory's object-type group and site group, for museum number, holding institution, FC number and excavation number, counting bracketed cells and, separately, only unbracketed ones), tracked `object-flags.csv` (per CISI number and Lipi family: join status and which fields the row supplies; no values), and a combined museum-number union with the source sets in `combined-coverage-post-fix.json` (`combined-coverage.json`, counts and family ids only). Also compute the protocol's two frozen predictions into tracked `predictions.json`: (1) the share of Mohenjo-daro entries outside M-621 to M-947 that join a Mackay or Marshall row, with an unbracketed FC number, satisfying FC = 2000 + Mackay No. or 1000 + Marshall No., listing the exceptions by CISI number; (2) for Harappa entries whose Lipi `excavation-idno` extends the printed excavation number, the share whose appended digits equal the FC number without its first digit (state exactly how you normalize and what counts as an extension). Report the counts behind every share.
7. **`selftest.py`**: tests on synthetic pass and adjudication files (a few blocks with known disagreements, piece lines, brackets, one-sided rows, overlap duplicates and a missing adjudication) and on the pilot's real final table (merge and join must reproduce the pilot's `coverage.json` figures for M-621 to M-947: museum number 74 to 276 of 283, FC 283, excavation 278). Save the result as `selftest.json`.

Write `TOOLS.md`: the order of commands from pass files to final tables, coverage and predictions, what each writes and where, and which outputs are tracked.
