# Review errata, 7 October 2026

The [review](REVIEW.md) reproduced the headline computations and identified the following corrections. Original protocol text, the auxiliary-loss amendment and numerical endpoints remain preserved; the current protocol appends the review amendment. These corrections require no model fitting.

## Smoothing attribution

Yadav, Joglekar, Rao, Vahia, Adhikari and Mahadevan's 2010 *Statistical Analysis of the Indus Script Using n-Grams*, *PLoS ONE* 5(3): e9506, uses Witten–Bell smoothing and Katz backoff in its model construction. Rao, Yadav, Vahia, Joglekar, Adhikari and Mahadevan's 2009 *A Markov model of the Indus script*, *PNAS* 106(33): 13685-13690, specifies modified Kneser–Ney on PDF page 6. The original [protocol](PROTOCOL.md), Families and fixed grids, item 1, incorrectly associates that estimator with 2010. This package tests higher-order interpolation, sparse-count fallbacks and a finite-vocabulary floor for an estimator already used on Indus sequences. [Yadav publisher text](https://journals.plos.org/plosone/article-id=10.1371/journal.pone.0009506), model construction and smoothing discussion; [Rao author PDF](https://homes.cs.washington.edu/~rao/PNASIndus.pdf), page 6; [source record](sources.json), `Yadav2010`, `Rao2009`.

## Epoch restoration

The protocol's lowest-loss-epoch sentence omits the improvement threshold used in `models.py`. Restoration uses the last epoch improving best loss by at least 0.001 bits, consistent with the stopping rule. This erratum describes the code that produced the saved outcomes.
