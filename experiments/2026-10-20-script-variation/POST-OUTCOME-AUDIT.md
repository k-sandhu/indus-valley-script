# Post-outcome source and matching audit

Recorded after `run-v1/summary.json` was read, 20 October 2026. The frozen prediction, source layer and actual-source scores are preserved. This audit supplies source candidates and explains feasibility; it does not change the primary result.

The frozen model lost 0.01584 bits per target when city was added. Its strict exact-frame comparison had no informative groups. We now document how support falls as constraints are added, using all eligible target events from the already examined corpus. These counts guide object acquisition and annotation. We report no new p-value or successful hypothesis test from a relaxed matching rule.

The automatic source layer flagged 15 repeated museum keys across 30 object families. Reading the original museum cells reveals a specific defect in the upstream parsed field: a comma inside two accession numbers was treated as a separator, leaving a repeated prefix. We classify these two keys as parser-fragment collisions. The other 13 keys remain repeated source values and require plate and context checks. Shared old and new museum numbers can identify different numbering systems, so a repeated key alone does not join objects. We retain the literal fields, all competing assertions and their pages locally.

The audit records the nine scored graphic families and their support among objects and sites, then counts cross-site frames with and without each recorded object restriction. Target events can overlap within an inscription. We therefore present these as a source worklist and aggregate coverage. The frozen one-component prediction and exact-context endpoints remain the tests of this package.

The decisive acquisition is a set of cross-city objects with the same fine-code frame, an independently checked target shape, and matched manufacture and date. Carving style and workshop features must be coded from images independently of the sign variants. That will distinguish a convention carried by a workshop from a convention distributed across unrelated workshops.
