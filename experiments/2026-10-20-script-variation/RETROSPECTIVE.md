# Script-variation study retrospective

We tested whether city improves prediction of fine graphic variants after their common graphic and object contexts are known. We also built a reusable source layer and a worklist for cross-city frames. The work stayed in the assigned experiment directory, its local raw directory and its unique attempt entry. Other contributors' chronology, findspot-map, legend-unit, archaeological-setting and fish files were left unchanged.

We began with the entry instructions, data gaps, registry, writing and source rules, and the orient, add-data, start-study and test-conjecture workflows. The earlier allograph study already supplied a substitution result and a Wells-code-order control. The chronology and region retrospective identified excavation-source confounding. That ruled out another broad regional-divergence run. The changed input was the held October 13 CISI basic data and excavation-table joins, which could qualify source locations and identity uncertainty for a different prediction problem.

The protocol fixed the graphic grouping, target-code range, component selection, count-model hierarchy, +0.03-bit threshold, exact-frame matching, exclusions and simulations before the actual outcome. Generated controls detected the planted spelling effect and gave nearly zero city gains for the null and motif-confounding controls. The bench shots synthetic checks passed. We copied the current spending ledger privately, registered one participant and froze every scoring artifact before loading confirmation. The confirmation loader logged one spent exploratory read. The proposal for the new shared-ledger entry preserves concurrent entries.

The actual score was negative, and the exact-frame test had no informative cells. Both results remain at their original endpoint. We then wrote a separate post-outcome audit to explain support loss and inspect repeated accession keys. This audit found two parser-fragment collisions among the fifteen automatic candidates. It recorded their literal source fields locally and retained the original exclusion sensitivity. The remaining thirteen pairs need a source-image identity check. No new identity edge was asserted.

We inspected four objects in two of the cross-city frames. Their photographs support the broad shared arrangements, while fine target details remain unresolved for the tablet pair. The side check identified the four-part M-1419 A inscription with exported face `3706.2` and recorded H-775's plain reverse. Complete texts and photographs stayed local. These notes are catalogue-informed source observations, not independent transcriptions.

A separately written verifier imported no fitted scorer. The coordinating review caught an error in the protocol's rationale for its code cutoff: fish signs are above 200, so the cutoff did not exclude them. A new scope audit checked the fish study's explicit B220 graphic family. It found 49 selected discovery and 47 selected confirmation fish targets, all code 240. That class failed discovery support for two variants and supplied none of the 306 primary scored targets. We preserved the frozen files, recorded the source of the mistaken rationale, and corrected the report's description. The initial empty exact-frame endpoint did include those fish observations. No numerical score or pass rule changed.

The next useful work is the missing source and context data for the matched frames, followed by image-based carving-style annotations that do not use the target code. Retrying the same city model with another seed would add no fresh population. A useful retry needs independently sampled objects, checked dates, observations of workshops or carving styles, or a specific model change justified before scoring. The report's strongest working model is a cross-city written standard in the nine tested graphic families, at credence 0.55. New objects showing the declared +0.03-bit regional gain after those controls would overturn it.
