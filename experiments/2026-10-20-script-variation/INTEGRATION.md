## Finding proposal, no ID allocated

Title: **City did not improve prediction of fine variants in nine graphic families.**

On a previously examined corpus, a frozen site-conditioned model lost 0.01584 bits per target relative to a common-context model on 306 confirmation components. The 95% component-bootstrap interval was −0.04107 to +0.00610; the prespecified useful gain was +0.03. Every leave-one-family-out gain was negative. Seals-only, source-qualified and identity-exclusion sensitivities retain a nonpositive increment. The exact-frame test had zero informative groups and cannot estimate a regional effect. Scope: a submitted exploratory comparison with no identification of the spoken language or languages. Evidence: [report](REPORT.md), [summary](run-v1/summary.json), [bench freeze](bench-freeze-v1.json), [bench inspection](bench-inspect-v1.json), [verification](verification-v1.json).

## Working-model proposal

Claim: **The tested graphic families belong to a cross-city written standard.** Credence: **0.55**. Risk: `stretch`.

The city label supplies no useful predictive increment in the frozen model after the common graphic context and object fields are supplied. Two source-photograph comparisons show related forms in the same written slots at Harappa and Mohenjo-daro. Common speech, several languages using common formulae, and administrative categories have the same observed predictions here. This proposal continues the shared-format account; it does not select a language mechanism.

Prediction for new material: the model's pooled fine-variant probabilities transfer across independently sampled cities after matching manufacture, date and source. The kill condition is a regional gain of at least 0.03 bits, 95% interval above zero, surviving source and carving-style controls and every leave-one-family-out check. The appropriate bench attachments are this package's shots freeze, inspection, access log and custom score; a future test must register its own genuinely new source population.
