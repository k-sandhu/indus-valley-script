# Amendment: conservative line-order control

Recorded 12 October 2026 after the first line-break run (`run-linebreaks-2026-10-12/`).

The protocol compared complete lines with windows that straddle a break "under either line order". Pooling both orders includes windows built in the wrong order, which cannot occur in the inscription and are unlikely to be found elsewhere, so the pooled control understates how often straddling windows recur. The amended run keeps the pooled figures and adds, for each face, the straddle rate of the more favourable order, which is the conservative comparison. The first run stays in place.
