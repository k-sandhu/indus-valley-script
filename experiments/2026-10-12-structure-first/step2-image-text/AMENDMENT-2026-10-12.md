# Amendment: copper specificity and odds-ratio reporting

Recorded 12 October 2026 after the first run (`run-2026-10-12/`) and before its 2d result was interpreted.

The first run judged a copper sign group class-specific only if it occurred in no other copper text, including tablets whose image is unrecorded. The protocol defines specificity against other copper image classes. Unrecorded tablets often show the same image as a labelled class, so the first rule removed genuinely class-specific groups: hare, anthropomorph, rhinoceros and tiger received none. The corrected code compares each labelled class only with the other labelled classes. The first run also reported a Haldane odds ratio for classes with no hits, which is uninformative; such classes now report `null`.

Both runs are kept. `run-2026-10-12-v2/` is the endpoint for step 2d; tests 2a–2c are unaffected by the change, and the rerun reproduces them with a new permutation stream.
