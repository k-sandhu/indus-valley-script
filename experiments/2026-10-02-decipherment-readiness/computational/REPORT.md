# Computational readiness for one decipherment test

The repository has reusable graphic predictors, correspondence solvers, exact numerical constraints and validation routines. Its strongest missing input is an independent link from a particular Indus inscription to a measured quantity, object relation or operation. That link determines what a recovered symbol or parameter would mean. The present Indus packet supports graphic prediction and some bounded physical-use constraints; it contains no independently measured held-out quantity that confirms one numerical value.

This audit maps all 101 registry entries into seventeen capability families. [coverage.json](coverage.json) lists every reviewed registry ID, its identified output, present inputs and remaining requirements. The review uses the indexed designs, current family methods/results and relevant retrospectives. It runs no model, simulation or frozen experiment. Root's separate preservation audit captures registry bytes and file integrity.

## Four readiness levels

| Level | Current position |
|---|---|
| Tools ready | Prediction, assignment, positive-constraint, rank, conditional-reference and reserved-validation routines have executed controls and preserved reviews. Some acquisition pipelines and historical populations remain unsuccessful or superseded. |
| Actual input packet for a semantic test | Source-defined physical cohorts allow limited tests of a proposed support or operation category. Numerical and full correspondence tests still require external targets or a justified reference. |
| Evidence confirming one value or function | No indexed Indus packet currently confirms a numerical or lexical value through an independent reserved target. Published attachment observations support particular object uses; assigning that use to a particular sign remains a further inference. |
| Further reading | A verified quantity or function would be one anchor. The remaining inventory, phonetic values and productive readings require additional observations that distinguish their surviving alternatives. |

Use the output's level when describing an advance. A graphic code identifies a transcribed unit or candidate set. A positional role identifies where that unit occurs. A mixture parameter describes a probability distribution. A numerical solver identifies values within a specified quantity model. A semantic role connects a sign or expression to an independently observed referent or operation.

Several premises recur across the methods. A test needs stable source/object identity, graphic units and boundaries, a target recorded independently of the proposed reading, and the appropriate observation unit. Numerical models also need the operation, commodity/unit relation and completeness status. Validation needs a reserved target that distinguishes the remaining alternatives. Source copies, repeated faces and text-derived context labels affect those premises and the effective amount of evidence. ## What the cryptographic and latent-model work supplies

The relabelling example enumerates all 720 six-symbol permutations with equal internally fitted structural score. Fixing two identities leaves 24 maps. One secure identity reduces that ambiguity without generally identifying the other symbols. The mapping benchmarks therefore introduce an external reference and, in some branches, an oracle that returns correct symbol identities. Their recovery target is the hidden bijection into that reference's abstract alphabet. [CRYPTO-01 protocol and result](../../2026-10-02-cryptography-framing/results.json), [CRYPTO-02 findings](../../2026-10-02-six-hour/anchor-benchmark/FINDINGS.md).

Those controls expose two further limits. A changed record process can make a wrong mapping score above truth; greater search effort then retains the objective's preference. A nonlinear fit can also miss a better-scoring true mapping. The latent-form comparison separates these cases: 56 failed mixture maps score above truth and six below it. Its three-component reference mixture improves several same-length conditions, with a supplied form count and known reference records. The exact grouped-rank result identifies mixture weights and slot distributions within the fixed population model, leaving one common permutation of form labels. A fitted form class acquires a function through an independently observed operation or object class. [Latent-form results](../../2026-10-02-six-hour/latent-forms/README.md), [observable work record](../../2026-10-02-six-hour/latent-forms/RETROSPECTIVE.md), [population proof](../../2026-10-02-six-hour/latent-generator-identification/METHODS.md).

Acquisition and source-channel routines operate downstream of an observation interface. The entropy policy can choose which exact identity to ask for, but the experiment supplies the answer oracle. The source-once/coupled-swap comparison supplies its source error model. The reserved-map audit's exact bound uses reliable identity responses and a complete bijection, where a wrong permutation has at least two disagreements. Those inputs need their own archaeological evidence before using the routines to confirm a sign role. [CRYPTO-03](../../2026-10-02-six-hour/reference-uncertainty/FINDINGS.md), [CRYPTO-04](../../2026-10-02-six-hour/active-identities/FINDINGS.md), [CRYPTO-05](../../2026-10-02-six-hour/reserved-verification/FINDINGS.md), [CRYPTO-06](../../2026-10-02-six-hour/correlated-sources/FINDINGS.md).

The joined stamped-vessel block has 32 faces with reported lengths one/two/three in counts 18/10/4, across preservation and direction categories. The tablet pipeline should preserve three physical faces as one object, retain possible common-end and face-order conventions, and measure individual stroke groups from the original image. Seven face counts are currently readable in the native source raster, including three and four strokes; most fine counts remain unassigned. The paired lower-face calculation retains two arrangement classes under a common end reversal and one under independent reversal. Adjoining-face photographs or 3D records determine which convention corresponds to the physical tablet. ## A minimal conditional path to one role or quantity

Start with a single precisely defined graphic module and a small set of competing functions. A useful first quantity target would be an independently counted contents group or measured capacity on the same securely identified marked object. The packet must establish the mark's boundaries, the object/target association, the measurement unit and uncertainty, and whether the contents are complete. Choose targets from that physical frame before seeing the model's predictions.

For the simplest declared model, let `c_j` be a source-confirmed graphic coefficient and suppose `T_j=u*c_j`, with one unknown unit value u. One reliable calibration target with nonzero coefficient fixes u. A reserved object with a different coefficient then tests the predicted absolute target. Additional unrelated signs need a declared role or a model term, and the measured objects should vary enough to distinguish a count rule from a fixed owner, batch or container class. A richer numerical hypothesis may need more observations; there is no universal object count that identifies one value.

The reusable solver can make the one-value goal precise. Let S contain every positive assignment compatible with the acquired relations, incompleteness inequalities, measurement intervals and candidate graphics. Compute the projection `V_s={value_s(x): x in S}` for the target sign/module. A singleton identifies that coordinate within the declared model even if other values remain free. A non-singleton supplies the surviving alternatives and identifies which new measurement can distinguish them. One anchor fixes the entire inventory only when the remaining feasible geometry already has that property.

Reserve a target whose predictions differ across the surviving role models. Under a cardinal-count model, the mark predicts a contents count in the fixed unit. Under a capacity model, it predicts volume while piece count may vary. Under an owner/batch model, it persists across changed quantities linked to the same operational identity. Under a graphic-modifier model, it tracks a sign/form class or display relation without a stable quantity mapping. The assay should retain these alternatives and their target predictions before measuring the reserve.

Falsifying evidence includes the same proposed quantity expression attached to independently differing counts beyond the stated error; complete observed wholes violating the predicted total; a geometric sign variant changing the target without the model's allowed term; an independent quantity selecting an alternative value; or a second unit/commodity relation required only after an error appears. A proposed one-support-category label fails when the same verified legend occurs on independently verified different supports within its declared scope. Source identity or completeness failures return the case to acquisition, with the original prediction preserved.

The most useful deliverable after that test would be one function or quantity assignment with its eligible object frame, alternative predictions, measured targets, exceptions and scope. The current repository can calculate and preserve that result once the independent physical packet is acquired.
