# Review of the evidence needed for decipherment

This review asks which existing observations and tools can support a restricted reading of the Indus signs, and what further evidence each route requires. The [reader's report](../../knowledge/directions/decipherment-readiness-2026-10-02.md) connects the findings to concrete source groups and proposed tests.

The baseline contains 101 registered research entries, including experiments, resources, sensitivity analyses and audits. Their [preserved registry](baseline-v1/registry-input.json) and [input inventory](baseline-v1/inventory.json) record the starting state at Git commit `973b7a88b525f0653144be1300d5105ba9812ce7`. All indexed evidence paths exist locally. The four manuscript drafts and relevant source/failure records are reviewed for their inputs, outputs and semantic implications. Existing numerical fits and simulation outcomes are preserved.

## Contributor reviews

| Review | Responsibility |

Each contributor retains a separate report, registry coverage and audit history in its owned directory. The root reviewed the returned prose and source claims before integration. [External source checks](external-source-checks.json) preserve verified bibliography and access limits for supplementary primary-source searches.

The [root verification](review-v1/verification.json) checks all three exact registry-ID lists, the seventeen-family partition, preservation of the original registry entries and the baseline source bytes in Git. The [corpus checks](corpus/verification.json) and [physical checks](physical/verification.json) retain their separate scopes. The [audit history](RETROSPECTIVE.md) links the observations that changed the next research priorities.

## How to use this review

Start with a named object family and an independently observable target. Use the existing code that matches that question. Freeze competing predictions and reserve an object block before examining the target values. Record the outcome under a new dated endpoint.

For numerical readings, the [source audit](../../research/literature/metrology/numerical_source_audit.md) specifies unresolved H904 and M-1383 joins. For physical function, the [Lothal frame](../2026-10-02-six-hour/lothal-physical-use/README.md) supplies attachment observations and repeated-inscription groups. For short paired records, the [Harappa frame](../2026-10-02-six-hour/harappa-object-frame/README.md) supplies 22 objects and all 66 faces.

This is a review of recorded work and source availability. It does not refit each numerical study or re-examine every pixel of every source witness. Its computational checks establish coverage, arithmetic and preservation for the specified review, while the proposed archaeological tests have their own future endpoints.
