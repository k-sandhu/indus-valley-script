# Corpus readiness audit

This descriptive audit reviews the preserved Indus photographs, transcriptions, physical identities and archaeological fields. The earlier metadata, source-frame and transcription audits supply their frozen counts; no prediction model is rerun. Generated administrative systems and khipu controls are method evaluations outside the actual Indus observation inventory.

The audit reads every registry entry and records its ID and registry hash. Direct corpus/source review covers the normalized Lipi, Mayig and earlier-export schemas, their normalizers, the existing 25-object plate audit, and the Harappa, Lothal and Kanmer source frames. It records source-inspected fields separately from derivative catalogue assertions and published functional interpretations. Graphics, measured dimensions, modern catalogue identifiers and authenticated semantic referents have separate entries.

One new descriptive computation follows Lipi's actual image-index file into its local image directory. Count indexed identities, referenced image assets, missing files, exact catalogue-key matches and duplicate image bytes. Image-file counts remain asset counts until a source-specific object/side/polarity annotation establishes what each witness shows. The audit does not transfer picture content, transcription sequences or proposed readings into tracked outputs.

Check raw interpretive columns by presence only and verify that normalized analytical schemas exclude those columns. Safe handling distinguishes absent CSV cells from empty strings. Reuse the prior placeholder audit for depth, dimensions, motif absence and chronology, then check whether any quantity, personal name or semantic outcome in the current object frames has an independent measurement or source join.

For a feasible current hypothesis test, name a fixed object/string subset, an externally observed outcome, alternative explanations and the available independent review. Keep a physical association test's predicted outcome explicit. For the three-faced Harappa group, retain its short faces and source geometry, including the seven directly counted stroke groups, and assess how the main length/single-line/direction filter changes coverage.

Save aggregate inventories, input hashes, code snapshot, coverage IDs, a plain report and a retrospective in this new folder. Raw source material remains in its preserved local locations. Any source or hypothesis gap is recorded as the observation needed next.
