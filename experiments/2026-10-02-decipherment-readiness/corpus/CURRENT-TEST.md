# Current Lothal test: inscription stability across physical contacts

The available test concerns the physical referent of one recurrent inscription. It asks whether the eight-sign G01 string is restricted to one narrow closure/contact configuration. This is a source-association test with measured or image-coded contact outcomes. It supplies a constraint on functional proposals while the actual owner, commodity and sounds remain unlabelled.

The fixed source population is G01's eleven objects: L124–L129, L190, L191, L193, L197 and L206. The local corpus supplies the repeated complete string; the source table supplies object-level assertions; Frenez and Tosi's Figures 3–7 supply photographed geometry. Four objects have existing trace records: L124, L126, L193 and L206. Their source coordinates are in [selected-trace-observations.json](../../../experiments/2026-10-02-six-hour/lothal-physical-use/independent-review/selected-trace-observations.json). Exact glyphs and full source images stay in their preserved local files.

Before another reader inspects outcomes, specify the proposed restricted physical referent. For example, a claim of a smooth cylindrical peg closure predicts concave cylindrical contact and an associated fastening route on readable rear views. A claim of one angular board-edge closure predicts an edge or adjoining plane arrangement instead. The competing operational account permits several contacts under the same inscription. A responsible actor/stamp label and a common commodity can also permit several contacts, so surviving that test leaves those meanings unresolved.

Use one row per physical object, with separate rows for views and traces. Two coders can receive rear/side views and source panel coordinates while inscription and support labels are concealed. They record flat/concave/corner/channel geometry, crossing ribs/parallel ribs/pleats/smooth texture, visible fastening route, broken surface and image limits. Keep mixed features on one object. The source author's proposed material and support are consulted after this coding is frozen.

Independently inspect exposed stamp views to confirm the joined inscription and record motif, border, overlap and polarity. A shared complete string need not identify one physical stamp. L193's overlapping impressions warrant particular attention. Keep absent photographs and unresolved joins among the eleven targets. Use the source object ID to join outcome records, never the order of a montage or an export-family number alone.

The primary endpoint is whether two independently readable objects contradict the specified single-contact prediction. Record the conflicting surfaces and source coordinates, rather than fit a broad classifier on four coded examples. An unreadable surface has no observed contact outcome. If the images cannot distinguish the chosen configurations, preserve that outcome and request calibrated views or replica traces.

Current independent validation consists of the original primary photographs, a second source-linked observer and the preserved independent table transcription. The earlier second reader knew the first reader's aggregate counts; neither pass supplies an epigraphist's or laboratory worker's blind validation. Replica impressions against declared supports could validate the trace interpretation, and original-object photography could resolve missing surfaces. The publication's W1 warehouse category is partly stamp-derived, so it stays outside the independent outcome set.

This prospective coding design follows an already observed recurrence and trace audit. Its current records motivate the test and are retained as development observations. A claim extending beyond the named G01 objects requires a separately chosen source block or newly acquired object views.
