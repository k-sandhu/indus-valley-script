# Register after held-source review

This release keeps the version 2 core schema and every parent object, face, image, identifier, measurement and rights record. `register-v2.json` contains the inherited assertions followed by attributed review assertions. It adds source-qualified candidate relationships and correction records for reviewed spatial layouts. The release name and parent hashes are in the tracked run manifest.

`objects.jsonl` and `faces.jsonl` retain their earlier fields. Objects with candidate inventory relations gain `candidate_reviews`, which links each source row to its assertion and review. A supported relation means the metadata supports that source row's link to a provisional export family. Physical families remain provisional and are never merged by this build. Unresolved candidate relations keep candidate confidence and cannot populate accepted core fields.

The 29 reviewed faces gain `layout_review`. `accepted_for_physical_layout` records compatible observations from two separately sealed AI visual passes, including any later source adjudication. `accepted_for_segment_order` records agreement on the location of catalogue segments in those visible groups. It does not establish the historical linguistic traversal; that field stays null. Accepted spatial arrangements replace the core surface's displayed arrangement, with its previous value retained in `changes.jsonl` and its earlier assertion preserved. Expert acceptance remains pending.

`candidate-reviews.jsonl` retains all 358 inventory rows, including unlinked rows. It includes supported and unresolved family IDs, exact source coordinates, duplicate relations, event references, participant scope and the reason confirmation eligibility is false. `exposure-events.jsonl` retains the historical documentation events and adds the current face-image review events. Historical page-level image or text display is never promoted to exact object viewing. Event counts count documentation records; two records can describe the same historical access.

The current face review records actual image display to the two contributors. Objects receive an aggregate exposure flag only when one of their faces was displayed. Other objects retain the parent's exposure flag; their linked candidate reviews carry the more specific historical metadata without inferring which object a page display revealed.

`lexical-sense-review.jsonl` and `lexical-compound-review.jsonl` are separate source-review resources. They preserve dictionary entry IDs, proposed senses, source evidence, language corrections and unresolved decisions. Their contents are not copied into object or sign meanings. The forty frozen compound sample entries and three known diagnostic cases remain distinguishable.

The parent missing-value, join-queue and CISI reader-decision files are preserved byte for byte. Reviewed candidate rows supplement those earlier queues; this release does not pretend that the parent's other unresolved joins have been adjudicated. All detailed review outputs and third-party derivatives remain local under `data/raw/`. Tracked manifests, code and aggregate reports identify the exact inputs needed to reproduce this version.
