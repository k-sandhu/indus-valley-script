# Integrating three source reviews

We split the work by evidence type and gave each contributor separate experiment, raw-data and registry paths. The face reviewer inspected the 29 fixed images, the lexical reviewer checked dictionary and proposal sources, and the identity reviewer used metadata and access logs for all 358 candidates. The integrating contributor made a separate visual record of the same 29 faces before seeing the other record. Both records were sealed by hash before catalogue-code alignment and comparison.

The face passes agreed on the visible geometry. Alternate photographs supported two additional layout decisions, while several images still could not establish a division. Source-font renderings then allowed twelve explicit segment-location maps. We kept rotations, composite panels and unknown signs in the detailed annotations. Supplemental caption checks distinguished image groups, detected a duplicate image payload and separated a main face from its inscribed edge. A proposed image-to-face association with unresolved catalogue suffix identity was retained as a candidate.

The lexical reviewer found that exact spelling alone could select the wrong homograph or even a form attributed to another language in the cited proposal. Original dictionary blocks and visually inspected proposal pages supplied bounded corrections. The fixed compound sample also exposed an accepted wrong boundary, omitted compounds, grammatical headers used as roots, and origin marks lost from parent entries. The contribution records these outcomes and a general source wrapper without claiming a complete parser repair or a new reading effect.

The candidate audit initially treated one project-prefixed registration too literally. Its preserved revisions verify the documented namespace while retaining complete numeric components and site context. The final twenty-four supported links are rechecks of existing relations. Page coordinates required similar care: an event can document a page display while leaving the object or crop uncertain, and a derived HTML or OCR label may not establish pagination in the original PDF. These distinctions are retained in every review row.

The first integration passed the core schema and reference checks. Independent code inspection then found a provenance defect: the face-review function reused its input-path variable for an image and then the font. All twenty-nine compact `review_path` fields consequently pointed to the font. We preserved the first output and its producing code as `integrate-v1.py`. A new test reproduced the defect, and separating review, image and alignment path variables made all eight integration tests pass. The corrected build uses a new `run-v2` directory.

The integration retains the old object and face populations, source assertions, unresolved queues and rights records. It adds review assertions and local resource tables. The many candidate-to-family review assertions are counted separately from the twenty-four supported links, so the larger assertion count does not imply that thousands of identities were established. Raw source details remain outside the tracked payload.

The strongest supported result is a register whose newly reviewed geometry and candidate relationships can be traced to exact held-source observations, alongside a lexical resource with explicit source corrections. The next deciding evidence is expert review and the missing identity, exposure and morphology documentation needed to prepare an eligible, calibrated comparison.
