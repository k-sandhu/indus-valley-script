# Transmission after the Indus cities

12 October 2026. A new exploratory historical study following the [October 11 continuity work](../2026-10-11-early-indian-continuity/REPORT.md) and [societal-persistence theory](../2026-10-11-societal-persistence/REPORT.md).

The study tests particular practical and institutional contributions against five compatible routes: local post-Harappan transmission, inherited Indo-Iranian or Indo-European repertoires, wider regional contact, independent reconstruction and later intellectual combination. Its argument is that operation, organizing relationship, terminology and explanation can have different histories. The comparisons ask which parts of a proposed route are observed and which require new evidence.

## Reproduction and scope

The coordinator's source control can be reconstructed manually from its three acquisition scripts, preserved witnesses and successor ledgers. The population control uses one author PDF; the PMC challenge is excluded. The method controls use a publisher article and an institutional accepted manuscript, with exact reading scopes and version metadata in [sources-v2.json](coordinator/sources-v2.json). Original population-only ledgers and earlier extraction endpoints remain preserved.

Run the declaration audit against a new output directory after the cited contributor observations are available:

```powershell
C:\Python313\python.exe experiments/2026-10-12-transmission-hypothesis/coordinator/audit_comparisons.py --output experiments/2026-10-12-transmission-hypothesis/coordinator/reproduction-new
```

The audit checks existing source IDs, schema and declared-record completeness. Historical relevance, feature matching and rival discrimination are source-based scholarly judgments separately reviewed. The [audit amendment](coordinator/AUDIT-AMENDMENT.md) and the reviewer's negative fixture expose that boundary. Historical comparisons and invented inference countercases remain separate.

Contributor guides give acquisition and reproduction details for their own packages. Python source tools use `requests`, PyMuPDF and BeautifulSoup where indicated. Raw PDFs, source-language exports, extraction and rendered pages are ignored local files, so a repository checkout alone does not contain those inputs. The protocol, authored metadata, code and aggregate output records remain reviewable.

Use a new dated directory or output version for further historical tests. Preserve the present endpoint, source lineages and unknowns. No script decipherment, authenticated Harappan language, numerical historical likelihood or external publication is part of this study.
