# Original sources and registered views

This follow-up carries out the acquisitions named after the regional numerical and publication-priority study. Three parallel agents handled Oxus, Susa and physical views; the root agent handled South India and integration. Each branch owns its sources, observations, reusable code and retrospective. The [account of findings](../../knowledge/directions/source-recovery-2026-10-02.md) explains what changed.

These are exploratory source follow-ups. Source authors retain their interpretations. New downloads, full source text and image derivatives are local-only under `data/raw/2026-10-02-source-recovery/`; tracked manifests preserve their hashes, retrieval routes and coordinates. The prior endpoints remain unchanged. No new numerical fit was run, and no external collection request was sent.

[Integration retrospective](RETROSPECTIVE.md) and [preservation checks](integration-checks.json) document review and retention. The registry keeps each branch's unresolved acquisition condition so future work can begin from the actual missing observation.
