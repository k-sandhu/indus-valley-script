# Oxus source-recovery retrospective

The preceding regional packet had an explicit Gonur Fig. 41 locator and a Kircho Plate 94.2 locator, with an inaccessible Bonora article PDF. This run followed those locators to the institutions and expedition that published the original books. The institute's Altyn Depe PDF was accessible by ordinary download although the web reader rejected its 24 MB size. The Margiana expedition bibliography linked its 1998 book through a public cloud share. The share's HTML exposed the expected file name, size and ordinary public download route, which recovered the 29.5 MB PDF. No login or challenge was bypassed.

The 1998 scan had no usable text layer. Native page images were extracted without resampling, and Tesseract English OCR was used to locate surrounding passages. Each report claim about the hoard total, caption, location or chronology was then checked against the native page. A console encoding error interrupted the first diagnostic print after extraction; setting Python's output encoding to UTF-8 fixed the diagnostic read. A Windows wildcard passed as an rg pathname failed; using rg's file glob option fixed that search. Neither error changed a source witness or produced a count.

The counting protocol preceded figure inspection and explicitly disclosed the earlier source interpretations. The first read counted 23 photographed representations and 23 drawings. The root agent's source-informed recount agreed on each row. The author reported 26 physical tokens in the pile. The different row layouts and absence of individual IDs made a positional photo-to-drawing match unreliable, so no specimen matching, sign-type total or mark value was coded. The lower representation counts are preserved beside the author's total.

Kircho's original Plate 94 linked three drawings under one item number and gave the excavation, horizon and room. The marked face has two main bands of elongated impressions, with partial forms at the upper edge. An exact impression count would require a clearer surface witness because adjacent lines do not always bound separable cavities. The original classification remains tentative. The room-level associated objects and later-horizon sealing group were recorded with separate contextual scopes.

The expedition's 2005 palace volume had a broken relative link. Resolving its observed publication path against the domain root recovered the original book. A normalized text search of all spreads added no token inventory or numbered find room, but it did locate the original elephant-seal publication with its Temple of Water, autumn 2004, Room 19, Area 9 statement and original/impression figure. That packet strengthens the previously indexed museum join and remains separate from the token pile.

The first checker run flagged the report's results link before that output existed. Its failed result was retained, a new result endpoint passed, and the report's final links were rechecked. The durable outputs are bibliographic identities, access and hash records, faithful derivative manifests, bounded observations, a report and a read-only checker. Raw PDFs, OCR and images remain local-only under the repository's redistribution policy. The next recovery target is the excavator's token inventory and specimen photographs. All earlier novelty, Lothal and regional endpoints were retained unchanged.
