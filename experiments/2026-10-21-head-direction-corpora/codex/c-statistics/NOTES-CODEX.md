# Run C interface and review notes

We wrote and tested the tools on synthetic records. The only held records read were the specified step 6 regression file, on which we computed S1 at sign and word level. We acquired no sources and changed no object coverage. The transcriptions, normalized comparison records, scans and page images being written by the other runs were not opened.

## Record conventions

`members`, `tags` and `tag_source` are parallel nested lists, one list per word. `lines` contains the normalized words, and `line_of_word` indexes those lines from zero. The validator accepts the five declared corpora and the languages, scripts and categorical fields in SCHEMA.md. A null site requires a nonempty `site_reason`, `site_missing_reason` or `site_ledger_entry`. Such a record can validate but cannot enter a statistic. We preserve transcription metadata and extra source fields locally, with strings in NFC.

For word statistics we use a tuple of each word's signs as its identity, preserving the editor's word boundaries. This follows the step 6 word inventory and makes editorial compound hyphens irrelevant to word identity. Members retain those hyphens for lexical tagging. A physical object shared by different impressions does not merge those impressions. An explicit alias can link to another record's die, record or object identifier; duplicate register numbers in `duplicate_objects` never create a link by themselves. Groups and their representatives are formed separately in each corpus, with ties resolved by `record_id`.

## Choices requiring attention before the real run

The Survey conversion follows the brief's literal sequential replacements. Both `chh` and `ch` therefore become `c`. If aspiration should survive as `ch`, that requires an amendment before normalisation; the tests currently assert the literal rule. Mahadevan's transliteration retains its printed case; an unsupported capital in a sign spelling requires review.

Amendment 1 supplies Marshall's collection language rule but no collection rule for Bloch or Spooner. We do not infer a language from spelling. An entry must supply its language remark or reviewed `collection_language` and `collection_language_rule`. Marshall's pre-Gupta category maps to `mixed Sanskrit-Prakrit`, expressing the stated Prakrit-or-mixed collection rule; Gupta and later maps to Sanskrit. Missing chronology prevents that inference. Script categories also require an explicit script or a period that names a declared stage. `--source-rules` accepts a JSON mapping of source identifiers to reviewed defaults for those collection fields, `script` and `period`. Entry values take precedence. This file stays local. Defaults must express an edition's documented collection statement and should cover only fields the entry leaves unresolved.

Restoration brackets containing letters retain those letters and mark the whole legend `restored`. Explicit gaps at an edge mark `damaged-edge`; internal gaps mark `damaged-internal`; only gaps mark `illegible`. An isolated question mark is an unread letter, while a question mark attached to a reading marks doubt and is removed from the word form. `illegible_part: true` without a position maps to `damaged-internal`; review must supply an explicit `completeness` when an edge is lost. Restoration alone does not mark a reading doubtful. A supplied `completeness` is preserved and validated. We recognize the common gap spellings of dots, ellipsis, bracketed dashes, standalone x and standalone question marks. Other editorial symbols produce a normalization error for review.

Spooner cross-references can be structured objects with `source`, `entry`, optional `equated` and `uncertain` fields, explicit `bloch1903:<number>` aliases, or a `bloch_equivalents` list. An ordinary prose citation is insufficient to establish identity. The parser accepts prose only when it states an equivalence and names the cited numbers. Review unresolved references before grouping. Spooner's entry number is the register number when no separate register field is supplied, following the transcription brief. Bhita entries 1–13 are seals and all later entries are sealings, following run C's identity rule.

Mahadevan rows require a table, row, object kind and language basis. `site` or `site_as_printed` supplies the place name. Karur is recognized in a river-bed description, whose full form is retained in `findspot`. A Karur mention in `findspot_as_printed` also supplies that site. Other unresolved river-bed descriptions remain null with a review reason. We do not invent place names.

## Sampling conventions

Tamil's fallback is decided once for each base level, sign or word, using the threshold of 25. Within S6 shares the sign population; S4 and S5 share the word population and then select their own legends with counted pairs, using the threshold of 15. Thus 25 word-eligible Tamil seals with 15 legends containing a title and name pair can enter S4 without coins. A Tamil base population still below 25 cannot enter that level, though its count and S1 shuffle description remain available.

Every replicate starts at index zero. Its sample is drawn from representatives sorted by `record_id`, using the exact primary seed prefix. Sensitivity runs filter records before grouping, use that same seed prefix, and recompute their populations and n. A less doubtful or Sanskrit alternate witness can therefore become the representative after filtering. The S3 reference has 200 full within-legend permutations using a generator seeded by the caller seed plus `:within:S3`. The S1 reference uses 1,000 permutations seeded by the corpus's full-set seed plus `:within:S1`. These suffixes separate shuffle randomness from sampling randomness.

Quantiles use linear interpolation between sorted non-null replicate values at position `(N-1)*q/100`; the null share is reported separately. Complete separation is strict, so equality fails. A replicate containing a null never counts as separated. The nearest-median gap is positive when separated and null otherwise. Conditions are reported even when too few primary corpora enter to make the decision testable.

The primary n is capped at 400. The sub-corpus n is `floor(0.8 * smallest qualifying sub-corpus)`, without a cap, as section 9 states. Sub-corpora qualify at 15 legends, including S4 and S5 after pair selection. Tamil rings are separated from other seals by `object_kind`, and coins are described as their own sub-corpus even when the primary population excludes them. `every_subcorpus_on_primary_side` is null when either group is absent or the primary medians supply no direction. These descriptions and the secondary Sumerian corpus do not change the primary decision.

The exchangeability test uses one generator with a randomly chosen common internal inventory for each corpus, 25 distinct legends, distinct first units and a shared last unit. Every matched subset has the same S1 within its corpus, while corpus values remain exchangeable. We use eight replicates for each of 300 independent draws and also verify all 24 orderings of four fixed values, of which eight separate the groups. This tests the chance separation of stable corpus differences described in section 9.
