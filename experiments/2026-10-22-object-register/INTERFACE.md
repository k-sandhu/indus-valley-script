# Object and face exports

The reproducible command in README writes a new directory under `data/raw/2026-10-22-object-register/`. Its `register-v2.json` follows the unchanged pilot schema. `objects.jsonl` and `faces.jsonl` are the compact interface for the two parallel readiness audits. They contain no inscription payload.

Each object has `object_id` (`LIPI:<object_family_id>`), `source_family_id`, `physical_identity_status` (`provisional`), `face_ids`, `aliases`, `fields`, `conflicts` and `exposure_status` (`unreviewed`). The `fields` entries retain a displayed value and canonical status (`catalogued`, `inferred`, `unknown` or `conflicting`); conflicting means source assertions differ and no reconciliation has been made. Bracketed uncertainty is recorded separately. A displayed value is the first source assertion, not a judgement that it supersedes another source.

Each face has `face_id` (`LIPI:<record_id>`), `object_id`, `source_record_id`, `source_cisi_raw`, `catalogue_key`, `source_id`, `source_sha256`, `image_links`, `identity_status`, `conflicts` and `exposure_status`. Image links have `path`, `sha256`, `kind`, `side_match`, `relation`, `note`, `source_path`, `source_record`, `source_id`, `source_sha256` and `join_status`. Side matches reflect the existing image audit and remain distinct from an object-level pointer. The four object keys affected by the later plate audit are excluded from `side_match=true` pending image-by-image reconciliation; their links remain visible with `join_status=needs-later-audit-review`.

`assertion-values.jsonl` preserves each assertion's raw and normalized values with `value_status`, source hash, locator and join status. `missing-values.jsonl` lists absent object and context fields with a reason. `join-queue.jsonl` preserves unresolved joins and source records outside the base population. No file treats an absent exposure record as evidence of freshness. The base population and external catalogue-only queues must be reviewed before a complete physical-object or fresh-cohort claim.
