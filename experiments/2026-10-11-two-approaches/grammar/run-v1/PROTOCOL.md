# Learned sign classes and a probabilistic field grammar

Written 11 October 2026 before new model calculations. This project is exploratory because earlier corpus results and candidate sign roles are known. The present splits, model grid and outcome rules are fixed for run-v1.

Rao et al., *A Markov model of the Indus script* (2009), Discussion, printed p. 13690, recommend inferring a grammar directly from the inscriptions. Yadav et al., *Statistical analysis of the Indus script using n-grams* (2009 preprint; 2010 article), connect their sign-context classes to a future stochastic grammar. We will fit a grammar with latent sign classes shared across lengths. The previous project fitted sign-level Markov models and length-specific mixtures of independent slots. This changes the predictor and its class-sharing mechanism; the previous template endpoints remain preserved.

## Input population and grouping

Read all 5,680 faces in `data/normalized/lipi_observed_faces.jsonl`. Before eligibility or deduplication, form transitive components using physical object-family identifiers and identical nonempty stored reading-order strings. Exact equality of strings containing unknown placeholders is retained as a conservative grouping edge; it supplies no sign interpretation. All physical identifiers attached to a retained text survive deduplication. Analysis requires `clean_rtl_singleline`, observed completeness, a single line, no unknown/blank flags, no uncertainty/damage flags, and length at least three. Choose the lexicographically first record per distinct eligible text. Its full-register component determines every split. Do not add other-direction, damaged or multiline strings to model fitting.

Use five outer component folds, balanced greedily by token count with seed 20261011, and three component folds within each outer training set with seed 20261011 plus the outer index. Build each alphabet from that fit's training signs plus one UNKNOWN bucket. The unigram prior adds 0.5 to every training type and to UNKNOWN. No validation/test codes create output classes. Report OOV rates. All models in a fit use the same alphabet.

Before the main run, a graph-only diagnostic was added after parent review: record component sizes when placeholder-bearing exact strings supply no string edges. Physical edges are retained. This diagnostic will explain over-grouping; it does not replace the primary closure or select a predictive result.

## Probability models and selection

Every reported score is the log probability of the entire code sequence conditional on its observed length. Length is given to every model. No model predicts an end token; its successive code distributions sum to one, so no unnormalized end-factor enters the comparison. Primary units are bits per all observed code tokens. Whole-text and noninitial-token sensitivities use the same saved predictions.

The positional baseline shrinks each `(length, index)` cell toward the training unigram. Select shrinkage 5, 20, 100, 500 or 2000 by pooled inner likelihood.

The sign-level comparator uses hierarchical first- or second-order transitions with unigram backoff and strength 20, 100 or 500. It combines each transition probability with the positional distribution by multiplying by `(P_position / P_unigram)^lambda` and normalizing over the fitted alphabet. Select order, strength and lambda in 0, 0.5 or 1 by pooled inner likelihood. The positional component has strength 100. Initial distributions use the positional baseline. These are new fixed-length predictive comparators; the earlier masked-slot restoration scores have a different observation law.

The grammar is a hidden-state finite-state grammar. A state emits a code from a learned shared emission distribution. The next state depends on the preceding state. In a contextual variant the start-state distribution also depends on length and the transition distribution depends on `(length, index)`, shrunk toward the global state transitions. Learn parameters by scaled forward/backward EM with empirical shrinkage, using emission strength toward the unigram, global start/transition pseudocount 0.5 per cell, and contextual strength 50. The empirical global prior is updated from the pooled posterior counts. This smoothed update is not asserted to maximize one fixed penalized objective; retain its likelihood trajectory, including decreases. Grid: 4, 8 or 12 states; emission strength 5 or 20; global or contextual transition mechanism. Each fit has two independent starts, at most 60 iterations and a relative training-likelihood tolerance of 1e-6. Choose the restart by its final training sequence likelihood and the configuration by pooled inner sequence likelihood. Outer targets never select parameters, starts or training duration.

The grammar's forward filtering gives a normalized next-code distribution based only on the known prefix and length. The product of those probabilities equals its forward sequence likelihood. The latent states and productions do not require a phonetic or semantic assignment. The learned state inventory will show at most six high-probability codes per state, occupancy by initial/internal/final position and a bounded set of frequent latent-state paths. Full emissions, rows, state paths and predictions remain local-only.

## Outcomes and theoretical development

Compare selected grammar against selected Markov and positional models on every outer text. Report paired differences and 95% conditional component-bootstrap intervals from 5,000 draws, with fitted models/splits held fixed. These intervals describe this grouped benchmark. Separately report each fold, known versus OOV targets, unseen-in-training bigrams with known targets, and seen bigrams. The latter strata are descriptive, fixed here in advance, and will not select a model. A negative grammar-minus-Markov result remains a negative result.

Fit one descriptive full-population grammar after outer evaluation. Its configuration is chosen by the pooled inner validation scores across the outer training sets, rather than outer performance. Align same-size outer state inventories by a common-alphabet emission distance and record stability. Interpret recurring states as candidate opener/core/qualifier/closer roles only where their measured occupancy supports that description. Provide language, administrative-record and mixed-function scenarios as hypotheses, with explicit predictions that would distinguish them using independent archaeological joins or later withheld objects.

## Structured controls

Generate three seeded pairs of synthetic datasets from a shared class grammar. One account describes optional administrative fields, repeated items and a closing authorization. The other describes optional clause particles, repeated modifiers and a closing inflection. Their hidden field graph and code emissions are identical; independent random realizations differ. Each has 1,600 distinct strings of lengths 3–10. Use grouped 70/15/15 training/validation/test folds. Select exactly the same model grids on training/validation, then evaluate test likelihood. Also construct an identical-sequence semantic twin as an exact identifiability witness. These are synthetic controls for structural specificity, not historical examples of real languages or administration. The totem and weather endpoints are not rerun because their coverage and grouping defects remain unchanged.
