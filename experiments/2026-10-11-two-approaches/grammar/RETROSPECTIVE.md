# Grammar induction and backoff retrospective

Completed 11 October 2026. This account records observable designs, calculations, review requests, repairs and outcomes.

## The changed research path

The previous repository found that independent-slot template mixtures did not match its sequential predictor. It also preserved defects in early uniqueness handling, source alias closure, small totem controls and weather grouping. The new work therefore learned sign classes and state transitions shared across lengths, used the full observed register for grouping before filters, and evaluated normalized whole-sequence likelihood. It did not repeat the old template model or the failed totem/weather protocols.

The primary source recommendation came from Rao et al. 2009 and Yadav's n-gram work. During parallel source review, the literature agent identified Tiwari's July 2026 categorical HMM as a direct prior. This changed the related-work claim: a generic hidden-state grammar and positional classes already existed. The report credits that precedent and locates the present work in grouping, held-out comparisons, stability, backoff and fixed future predictions.

## Before the primary calculation

`PROTOCOL.md` was written before new model calculations. A small training-only pilot checked runtime and probability code; it did not score held-out corpus targets. The parent reviewer requested a graph census without placeholder-bearing string edges, which was added before run-v1. The full declared closure remained primary. Two grammar starts, the complete state/shrinkage grid and all folds were retained.

Toy enumeration checked normalization at lengths 1–4, explicit hidden-state path summation, posterior normalization and prefix invariance to an altered later target. The full graph join included short omitted texts before eligibility and kept every physical alias during uniqueness selection. This left 1,363 eligible components, including a 180-text component, rather than the earlier benchmark's 1,526 components.

## Primary outcome and useful failures

Run-v1 completed five outer folds and six synthetic controls in about 232 seconds. The class grammar gained 0.2912 bits per token over position but lost 0.4726 against tuned Markov. All five folds selected the largest declared state count, 12, with contextual transitions and emission strength 20. The negative result and the grid boundary are retained; neither is repaired by relabelling twelve states as twelve ancient functions.

The predeclared strata exposed a tradeoff. Shared classes improved relative to Markov on known targets in unseen bigrams, while positional prediction was still better in that stratum. Specific seen transitions strongly favored Markov. The grammar also reduced UNKNOWN-bucket probability too far, producing 18.43 bits per OOV token against Markov's 16.01. Its positive result against position did not establish that it was the best predictor.

The synthetic controls generated independent administrative and compositional-clause realizations of exactly the same field mechanism. Grammar gains appeared under both invented semantic accounts, and an identical-row semantic twin supplied exact equal sequence probabilities. These controls explain why recovering fields or compositions does not select their meanings.

## Post-outcome repair and adversarial matched control

After the primary result, `POST-OUTCOME-PROTOCOL.md` froze a convex probability mixture with weights selected on refitted inner predictions. Run-v2-mixture preserved the original outer probabilities and reused their selected configurations. Its 0.1113-bit gain against Markov motivated a parent-review request for a positional backoff comparator. That request arrived after run-v2 had started, so the running code was not edited and its endpoint was retained.

`AMENDMENT-V3.md` was written before the positional-mixture calculation. Run-v3-matched-mixtures used the same eight weights, alphabets and OOV handling. The class-containing mixture gained 0.0557 bits per token over the matched position mixture, with a conditional component interval of 0.0436–0.0675. Every fold had a positive point difference. Both later families remain exploratory because the outer population was exposed before their design.

The parallel reviewer rebuilt positional probabilities from counts without importing the model implementation and passed 57 mixture checks. The review requested explicit UNKNOWN-event wording, equal mixture grids, source prior credit and a clear statement of the bootstrap's fitted-model scope. The parent independently checked normalization/grouping and asked for readable number spacing and loss-based table labels. Those reporting changes do not alter frozen numerical endpoints.

## Source scope, interpretation and preservation

Learned classes recurring across folds include an opening 817/820/861 family, an internal 002/060 family and a completion 740/520 family. Broad intermediate classes are less stable. The full-data class paths motivated a selected post-outcome audit of late attachments: 740→400, 740→090 and 520→400 frequently place the right member last. The report develops administrative operator, compound-ending and mixed-notation hypotheses from these aggregate observations. Those labels remain working scenarios and receive future source/context tests.

The effective token-weight component count is 123.1 because the largest group carries 8.59% of tokens. Removing that group's saved predictions leaves a 0.0551-bit class increment over positional backoff; no models were refitted for this sensitivity. The corpus remains one transcription export of archaeological witnesses, not an independent source of excavated objects.

Primary verification recomputed all 8,009 forward scores from saved arrays with maximum error 3.55×10^-15 bits. Inner constituent scores reproduced exactly within floating tolerance during mixture fitting, and the saved outer mixture audit had zero score discrepancy. Output directories refuse replacement. Bulk rows, predictions, vocabularies and fitted arrays remain in ignored local data; tracked files contain our code, protocols, bounded class summaries, aggregates, source pins and prose. No global registry/index file, source witness, repository visibility, publication endpoint, CI/CD or automation was changed by this worker.

## Carry forward

Use the frozen full-data class model and both 0.2 mixture weights for the next genuinely unseen input. The future prediction sheet fixes object/text closure, minimum sample counts, OOV reporting and structural/functional tests. A larger state grid, calibrated UNKNOWN mass or a different grammar family would require a new protocol and endpoint; their possible usefulness does not justify changing the present result.
