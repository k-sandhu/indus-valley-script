# Source and asset handling for this program

Scope: new files in `experiments/2026-10-11-two-approaches/` and its knowledge-base additions. The [repository redistribution rule](../../knowledge/provenance/REDISTRIBUTION.md) was read before source acquisition and integration. This review permits preserving the described own-work research package; no external publication or repository visibility action was requested or performed.

| Material | Retained location and treatment |
|---|---|
| Downloaded primary papers, selected-page extracts and acquisition witnesses | Local-only `data/raw/2026-10-11-two-approaches/literature/`; source URLs, editions, access depth, rights uncertainty and hashes in [sources.json](literature/sources.json) |
| Acquired transcriptions and source rows | Existing ignored `data/normalized/` inputs; source-specific hashes in package manifests |
| Complete face modules, bundles, aliases, per-text predictions, vocabularies and fitted arrays | Local-only raw grammar/administrative directories; no bulk reconstruction table in the retained package |
| Pilot/tail allocations and per-object reference witnesses | Local-only administrative raw directories; aggregate effects, counts, tails, seeds and verification retained |
| Prior navigation bytes and initial Git state | Local-only coordinator baseline directory; [manifest](baseline-v1.json) records preservation pins |
| New protocols, source summaries, code, reports and hypothesis sheets | Project-authored files retained in the dated package |
| Bounded sign-class summaries, aggregate productions and field hashes | Derived research summaries; these describe selected classes/counts rather than reproducing complete input records |
| Finite semantic twins, prototype counterexample and contextual-anchor calculation | Explicitly invented examples with their generating code and complete synthetic distributions |

The grammar's [changed paths](grammar/changed-paths.json), administrative path manifest, literature [manifest](literature/CHANGED-PATHS.json) and reviewer [manifest](review/CHANGED-PATHS.json) distinguish retained own-work files from ignored payloads. Existing Git ignore rules cover `data/`, binary model arrays, downloaded texts/images and Python caches. This program does not change those rules or vendor third-party libraries.

Source photographs, downloaded figures and text witnesses are not copied into a new viewer or manuscript. The source ledger preserves short locators and our summaries. Acquisition links use public static source locations; access records remain local. The [adversarial review](review/REVIEW.md#source-attribution-theory-and-handling) separately inspected reconstruction risks and source attribution.

Reproduction of the empirical outcomes requires the pinned local transcriptions and arrays. A checkout can inspect methods and outcomes and run the mathematical examples with standard Python; full refitting additionally uses NumPy/SciPy and the retained source inputs. The [program manifest](manifest-program-v2.json) records the files and raw-directory ignore check without packaging the raw payloads.

Nine earlier Bonta code, protocol or prose files changed in the shared workspace after the starting hashes were taken. Six exact initial versions were recovered into ignored coordinator data, and all nine current versions were copied there. Three initial versions were not found in snapshots or Git objects: the old context protocol, context-review code and hypotheses code. Their original hashes remain in the starting manifest. The new-program numerical endpoints are separate; source corpora and earlier pinned numeric outputs are unchanged.
