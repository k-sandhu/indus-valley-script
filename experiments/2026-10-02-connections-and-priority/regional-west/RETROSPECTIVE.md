# Research retrospective

This records observable searches, source joins, implementation changes and outcomes. Work stayed in the assigned experiment and local-only raw directories.

The repository registry, external phonetic-anchor audit, Tell Jokha README and physical-acquisition retrospective supplied the starting point. They already separated Shu-ilishu's cuneiform seal, the Gadd objects, Tell Jokha's unavailable figure, and the symmetric SB 1940 token mixture. The new search focused on measured and inventoried objects. A guessed Tell Jokha retrospective path did not exist; its README supplied the account.

The close limestone duck group lies near 492–511 g per stroke. Wider ranges occur in other shape/material groups. Most entries lack creation dates, so chronology is a useful new grouping field. An unrestricted unit for every artifact would provide no cross-object constraint.

The accession review found two tasks for museum verification. Cats. 119 and 129 both assign SB 13514 with different masses and dimensions. Cat. 120 assigns SB 13747 to a 16.44 g marked ovoid, while cat. 609 and the appendix assign it to an incomplete 20-mina duck. The three small entries remain in the census and leave the fit.

Access failures were bounded. Web PDF searches failed; local text extraction worked. The Englund 1998 route returned HTML. Persée's PDF route failed its format check; the author full-text view supplied the exact Bonora pp. 66–67 passage. Brill contents verified the newer chapter, whose full text remained unavailable. Louvre image access failed through the web tool. No new four-mark shape reading was substituted for source descriptions.

The Dholavira audit first missed two entries lacking punctuation after the site name and one Nageshwar entry. A revised parser verified every ID from 1121 through 2058 before saving the endpoint. Descriptions contain no explicit marking term. Selected plates show modern collection ink and natural banding; the compressed images leave minute marks unresolved. DHR identifiers and excavation coordinates provide the next join to seal/sealing records.

Reusable outputs are the object table, interval code, complete graphic-census procedure, transparent exclusion history, and source recovery targets. A follow-up should recover dated contexts and full mark geometry, then freeze the next comparison before calculating its mass relation.
