# How the South Indian source study progressed

The user suggested that numerical links may survive in South India. The search began with government archaeology pages and the new Tamil Nadu graffiti project, after reading the repository's source, writing and retry rules. The web reader returned an empty page for the JavaScript portal. Inspecting its public HTML and deployed client identified the same read-only API routes used by the site. The client was parsed as text; its code was never executed.

Initial reads of four routes established the schema. A subsequent protocol and reusable acquisition script froze six catalogue routes and all 42 sign-family routes. The unparameterized concordance returned its missing-parameter response. Government sign 39 subsequently returned the desired concordance; using its internal RMRL number 87 returned a server error. These responses remain separate witnesses. A site-and-sign filter showed that context margins can be restricted while specimen registrations remain absent from that API response.

The 2025 morphological-study PDF link supplied by a review page returned 404. The current government library page exposed a different file path, which worked. Its filename resembled the full study, but the acquired PDF was an eight-page illustrated brochure. An attempted render of page 66 failed and exposed that mismatch. We retained the acquisition under its original name and recorded its actual page count. Searches then located both complete 2026 catalogue volumes, with 740 and 712 PDF pages, from the government's library. They supply more useful specimen and concordance material than the brochure.

Searches for known Tamil numerical controls found Mahadevan and Bhaskar's 2011 article on Tondur and Alagankulam. Direct access to the newspaper was restricted. An official CICT download proved to be a 57-page preview of Mahadevan's 2020 revised epigraphy volume, whose printed full-book pagination is much longer. It contains a figure-list lead, while the numeral discussion itself was unavailable in the preview. The claim of a new numerical anchor was therefore not added from these incomplete witnesses. The useful next acquisition is the original numeral pages with their specimen and inscription references.

Aggregate checks compared the portal's family and site routes, revealing four spelling/identifier differences and mixed units in the family `totals` display. The occurrence calculation instead uses the rows' site margins and checks their habitation, ware and depth sums. Graphic identifiers stay strings, preserving one horizontal line (`39.1`) versus six (`39.10`). These corrections concern data handling; the acquired bytes remain unchanged.

The first compound calculation required a named government identifier for every component. It unnecessarily discarded forms when an unrelated component lacked that crosswalk. A separate protocol and endpoint count membership in the complete plain-stroke code set, resolving 194 forms while leaving 15 opaque. The older 115-form endpoint remains available. An exploratory shell probe also failed through a loop-variable typo before producing results; the corrected probe and saved implementation use an explicit component-key list.

The printed concordance supplied a direct check on the digital representation. Two selected forms agreed; 4.19C omitted a stroke component in the portal array. The original page was rendered and visually inspected to verify the table columns. An independent agent confirmed the printed cells and found a second discrepancy: the last printed base component 5.0 maps to variant 5.7 in the digital array. The analysis reports its frozen digital counts and the separate source disagreement. A future study should adjudicate the relevant photographs before treating normalized component order as an observed sequence.

The source-integrity checker initially assumed every acquisition record was a dictionary. The extra-read log is a list, so that attempt stopped before writing verification. The checker now handles both manifest structures; the source and analysis bytes stayed unchanged.

Downloaded photographs, PDFs, raw API responses, client maps and full keyword extracts remain local. The repository receives our methods, aggregates, source coordinates and acquisition hashes. The study has produced a comparative graphic population and concrete specimen targets; quantity readings await the named independent observations.
