# Report wording after the source audit

The [independent review](independent-review.json) records the hash of the report it read. That exact version is preserved as [REPORT-reviewed-v1.md](REPORT-reviewed-v1.md). The [current report](REPORT.md) subsequently defines a stroke block as consecutive components in the normalized array, illustrates the definition with 39.13C, and links the completed audit. All numerical results and source comparisons remain unchanged.

The [revision record](review-followup-v1.json) gives both hashes. The [preservation helper](preserve_review_input.py) reverses only those two prose edits and requires an exact match to the auditor's recorded hash before saving the reviewed version. The earlier [endpoint manifest](endpoint-manifest.json) retains its original file set and hashes.
