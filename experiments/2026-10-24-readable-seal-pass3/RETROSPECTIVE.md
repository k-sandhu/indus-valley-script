The DOI’s new repository handle supplied the useful change in access. The old eprint page and presumed PDF URL returned HTML with HTTP200. We checked signatures and retained these responses. The public PID endpoint returned genuine repository JSON, whose bundle and bitstream links yielded the full scan. We extended the direct-request bound before following that chain and preserved the amendment.

The scan has no source text layer. We used contact sheets to find the contents and catalogue, then read the relevant catalogue and epigraphic pages at higher resolution. REG257 proved to be catalogue 308. This joins the primary carrier record to Eidem’s published reading and prevents confusion with catalogue 257. The remaining admission obstacles are a partly restored sign, language classification and baseline deduplication.

The first two-query response was not saved in full. Subsequent tool responses and every direct-request body were preserved. A console display failed on Unicode after extraction had already written its UTF-8 file; we repeated only display with UTF-8 enabled. No source bytes were altered. We retain all intermediate response manifests and rendered pages, including pages not visually opened. The checksum mismatch between stored metadata and delivered PDF remains explicit.
