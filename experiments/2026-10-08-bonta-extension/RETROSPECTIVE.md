# Retrospective: extending Bonta’s proposed values

The user asked for imaginative meanings for as much of the remaining inventory as possible, using Bonta’s recommendations and the balance of available evidence. During the first pass the user also identified the saved second-edition manuscript and requested new Sanskrit anchors supported by internet searches. The work therefore produced a candidate map, a visual review tool and reusable search code. It did not repeat the earlier construction-set work as a confirmation test.

The original pass built dossiers for 713 Wells codes from 5,680 face observations, with a separate clean frame of 1,859 distinct complete sequences. The saved manuscript’s Table 18 and the retained first-coder drawing crosswalk supplied provisional values for 117 codes. Those are catalogue codes, including graphic variants, rather than 117 independent linguistic signs. Two- and three-sign windows with a single unknown were compared with the local Monier-Williams dictionary. Full strings, object identifiers and dictionary excerpts stayed in local data storage.

The saved paper was found in `data/raw/2026-10-08-bonta-review/papers/`, rather than the root manuscript directory named `papers/`. Its SHA256 matches the retained 259-page witness, `12e8e6b1c427dbdc995e64991d5d0a676b8d397956f28379b046a230a5065f14`. A rendered table leaf showed that the author’s looped DHANYA sign differs from the cereal-ear drawing used for the new yava comparison. The closing section discusses unresolved juncture, enclosure and ligature functions; those became candidate modifiers rather than fixed grammar rules.

Four class sheets supported the first semantic families. Another 215 Wells codes had no direct Mayig class, which would have left many rare signs with only a positional placeholder. The local Lipi font supplied drawings for all 713 codes. Its frontend explicitly uses U+E000 plus the decimal code; this encoding was checked before rendering five additional contact sheets. The new manual interpretations cover the remaining shapes, retaining the font and rendered witnesses locally because their reuse license is unresolved. These were direct model visual comparisons; no separate VLM service batch or semantic-model accuracy benchmark was run.

Sixteen new Sanskrit comparisons were selected before the expanded dictionary pass. Their preferred and alternative stems opened 256 additional windows across 111 other codes. The two scenarios have 164 and 158 nonempty full intersections, respectively, but many are based on one context or permit numerous residuals. Common short strings dominated several rankings. The map therefore retains sound alternatives and assigns meanings from the joint graphic/role scenario rather than turning every dictionary hit into a lexical reading. Three narrower meanings were selected after inspecting the results: W233 as a heavy-load class, W231 as a provisioned/collected asset unit and W204 as a share-bearing product/name element. Their post-outcome status is recorded in each entry.

The internet work used primary dictionary interfaces, Rao’s labour-account proposal, HARP’s public sealing and food accounts, and Kenoyer’s textile paper. A dictionary scan screenshot timed out, so the underlying definition check used the retained Cologne entries. Homonyms needed explicit sense selection: the first entry under yava refers to part of a month, the first jala entry to a different sense, and the first saha entry to strength. `SANSKRIT-ANCHORS.md` records the barley, water and together senses actually used. Later attestations help formulate occupational or institutional meanings without establishing Bronze Age words.

Implementation repairs included UTF-8 execution on Windows, replacing an incomplete 65-row table index with the full retained source catalogue, and using the existing frozen candidate crosswalk rather than inferring code identity from a visual resemblance alone. Two manually copied font-sheet labels were corrected by comparison with the rendered witness index. Broad filename searches initially missed ignored PDFs; the retained source directory resolved the manuscript. First-pass results were preserved while the October 9 amendment added the new searches.

The v2 catalogue was preserved when review showed that worked examples should be selected for the named anchor relationship. The v3 projection reuses its dictionary outputs byte for byte and selects suitable account examples. The final drawing review corrected the angular hatched W383 and staff/person compounds W951/W953 in a separate v4 projection. V5 gives the short-stroke W001/W002/W060 forms a relational/juncture function while retaining numerical uses, following Bonta’s unresolved-juncture recommendation. These refinements changed semantic labels and role categories; they did not change the lexical searches. Prior code copies and catalogue versions remain available. Independent recounting reproduced the corpus token and position totals. Checks reconstructed 261 exact and 135 normalized dictionary examples, verified every search window against an observed complete sequence, checked all drawing paths and confirmed that the 256 anchor windows were new. The prose review found no listed stock-writing patterns in the report.

The in-app browser automation timed out during initialization. Playwright then loaded the catalogue for local browser inspection. A stale element reference required a fresh snapshot, and unsupported run-code syntax was replaced with CLI keyboard/select actions. Search for W151 produced its one card with a loaded drawing, anchor and inherited filters returned 17 and 117 entries, and unaccented bhara search retained W151. The mobile document matched its 390-pixel viewport width. The sole observed resource error was a missing favicon. A separate local anchor sheet shows eight selected drawings with their proposed meanings. The earlier runs, source witnesses and current v5 output remain separate. New project files include the search, rendering, semantic-prior and catalogue code; the source tables, report, HTML/CSV/JSON catalogue, verification, license notice and retrospective. Only narrow index/registry entries and HTML ignore exceptions were added outside this experiment directory. No CI/CD, recurring automation, corpus edits or external publication was introduced.
