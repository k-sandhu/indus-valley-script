# Retrospective

The local site-coverage export gave a useful starting point for the regional census. Joining it by site label revealed Pabumath and Juna Khatiya as additional local rows. Pabumath has a CISI 1 identifier, so it was added as a confirmed missing inscription-bearing site. Juna Khatiya has a pottery-face record without a CISI identifier; it remains in the table as a local coverage lead, not as a confirmed script find.

The first count comparisons exposed a unit mismatch. The local export counts faces, while publications variously count seal objects, impressions, texts or catalogue entries. Lothal also has figures from different publication versions. The rows now keep those figures adjacent with their basis and preserve the local values separately. CISI sequence maxima are retained as observations, not converted into coverage ratios.

Some publications were available as opened articles or PDFs, while several site reports appeared only as institutional catalog records, snippets or secondary citations. The source records retain those access states. This limited the completeness of director lists, exact page ranges, object metadata and current holdings. Coordinates were also inconsistent across sources: site-village points and mound points sometimes differ, and the Rangpur report snippet appears to transpose latitude and longitude labels. The reported coordinate should therefore be checked against the original maps before it is used for spatial analysis.

The aggregation script produces stable row and search counts from the local coverage file and the curated source notes. The search log stores three normalized query formulations per site with outcome summaries. It is not a verbatim engine transaction log; the exact query variations used in the live-search batches were not captured separately. A later frozen evaluation should record the raw query strings and result URLs during each search, open the final excavation reports where available and add page-level citations before computing any completeness statistic.
