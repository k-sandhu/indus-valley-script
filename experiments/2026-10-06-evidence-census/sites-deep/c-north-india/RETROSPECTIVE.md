# Retrieval retrospective

The earlier broad census was reused for the distinction between object counts and faces, the Farmana report count, and CISI 1's scan/counting caveats. The local coverage summary supplied the per-site face and identifier fields. Search-index snippets from ASI, NMMA, IGNCA, Harappa.com and bibliographic catalogues identified primary report passages and later finds.

Search returned especially useful primary leads for the Hulas sealing, Manda incised pottery and unfinished seal, the Tarkhanewala Dera impression, Karanpura's two-letter seal and Rakhigarhi's later inscribed objects. Where the result gave a plate, registration number or count basis, that detail was retained in the site row. A search result was not promoted to a fully opened source unless the page or catalogue record itself was accessible.

Several official PDFs could not be opened by the web fetcher because of file size. The RMRL June 2025 bulletin search result returned relevant Banawali and Kalibangan passages, but opening its URL returned 404. These outcomes are listed in `sources.json`. They leave source-page checks outstanding. A source URL reused by search results for more than one article (the IGNCA 88233 PDF) also needs identity resolution before future citation.

The planned three-query-per-site search was not completed. The executed set has 32 query strings, some grouped across sites; that shortfall is explicit in `searches.json` and the report. Because the work did not include systematic coordinate retrieval, campaign-page checks, class-by-class counts, final-report verification, current holdings, rights statements or object-level joins, the rows retain nulls and explicit limitations. No site count was inferred from a missing search result.
