# North India site census

This exploratory register contains **24 site rows**: the 23 named sites in the batch plus Tigrana, added after the local coverage file showed a Haryana/Inter-Riverine TAG record. The local file matches **13 rows** in this batch, with **290 faces** across those rows. These are transcription faces, not a published archaeological object count. Detailed rows are in [site-rows.json](site-rows.json) and [site-rows.csv](site-rows.csv).

The clearest published object-count claims found here are older Mahadevan totals of 99 objects at Kalibangan, 7 at Banawali and 4 at Chandigarh. The local export has respectively 212 faces/197 CISI IDs, 26 faces/23 IDs and 3 faces/3 IDs. These values use different counting units and source versions; they show where a catalogue join is needed, not corpus completeness. Hulas has one reported unstratified sealing (Reg. 990) and one local Hls-1 record. Farmana's preliminary report describes two seals and two terracotta impression objects, including a seal from the preceding season. See [REPORT.md](REPORT.md) for post-CISI finds, limitations and the count table.

The strongest later finds located in this search set are an inscribed lead ingot and inscribed sealings/tablets reported from Rakhigarhi, a two-letter seal at Karanpura, the inscribed sealing from Tarkhanewala Dera, and Manda's incised pottery plus unfinished seal. The source passages are identified in the row notes and [sources.json](sources.json); some were available only as search-index excerpts.

Read the [protocol](PROTOCOL.md) before interpreting missing values. It records the source rules, count units and search limits. [searches.json](searches.json) records every executed query and its returned source references. The [retrospective](RETROSPECTIVE.md) documents the retrieval failures. This package reuses the Farmana count audit and CISI 1 page-duplication/counting conventions in [the earlier census](../../sites-and-publications/REPORT.md).

## Reproduce local rows

From the repository root:

```powershell
python experiments/2026-10-06-evidence-census/sites-deep/c-north-india/build_site_census.py
```

The script reads `local-site-coverage.json` and writes `site-rows.json` and `site-rows.csv`. Source and search manifests are curated records and are not generated by the script.
