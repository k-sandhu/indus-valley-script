# Evidence census synthesis protocol

Recorded 7 October 2026, before synthesis arithmetic or source-sample outcomes. Package B3 synthesizes the October 6 census and its October 7 follow-ups. Status: Exploratory. Numerical consistency checks can receive Verified computation; the contributing archaeological assertions have not received independent review.

The question is whether all discoverable evidence for the Indus script is indexed with the available metadata. The synthesis will report the evidence covered by the nominated sources, demonstrated omissions from particular accessible indexes, and pools whose size or identity remains unresolved. An exhaustive worldwide denominator requires publication and collection inventories that this census may not supply.

## Methods and comparisons

1. Pin input bytes with SHA-256. Recompute each batch's row count and local face, family and CISI identifier sums from its rows. Compare these with its saved aggregate. Recompute coordinator and local derivative totals independently. Preserve literal site labels and record name aliases and cross-batch duplicates before selecting a single regional attribution for aggregate totals.
2. Extract each published count as a separate assertion with unit, class, date, selection rule, source and page. Catalogue ranges supply entry counts, which can include uninscribed, geometric and comparative objects. IM77 supplies a historically selected inscription population. ICIT's published numbers are historical. No subtraction across unequal populations will be labelled missing physical objects.
3. Join site-level publication records by names and explicit aliases. Confirm object joins only through identifiers with a source version, excavation/accession concordance or published field-and-plate reference. Recheck the museum audit against the local derivative. Keep unconfirmed museum and alias candidates in a separate local register. Candidate links cannot merge objects. CISI range membership is index-entry coverage, not a complete physical-object census.
4. Sample at least 20 site rows, at least five from each batch. Select major count-bearing sites and smaller or exceptional sites, with the exact selection recorded before reading the cited passages. Compare one or more material assertions per row with the cited local source witness. Inspect catalogue boundaries and page images where text extraction cannot establish a number. Record supported, qualified, contradicted or unavailable outcomes. This purposive sample has no statistical error-rate interpretation. Use live web search only for a named conflict that the saved sources cannot resolve; log every failed route.
5. Measure metadata presence on pinned Lipi and Mayig rows and the museum confirmed-original frame. Normalize empty/dash/unknown values and zero dimension placeholders explicitly. Separate site from excavation findspot, stratigraphy from cultural period, numerical date ranges from independent absolute dating, image slots from inspected photographs, and policy-level licences from item-level clearance. For ICIT, CISI and IM77 report documented field availability and unmeasured denominators rather than invented completeness percentages.
6. Rank gaps by documented scale, evidence added, obtainable source route and identity uncertainty. Keep confirmed index-entry omissions, unjoined records, under-described records and unmeasured inventories distinct. Give ranges only when source bases permit them. Propose schema and 200-object pilot changes in a new document.

## Negative result and limits

The completeness claim fails if an accessible source contains relevant entries absent from the nominated index, unresolved object joins remain, required fields are demonstrably missing, or a nominated primary inventory remains inaccessible. If no common worldwide object denominator can be reconstructed, report the missing total as unknown and quantify only bounded, source-specific gaps. A large transcription family count alone cannot establish worldwide completeness. A source title copied from a long search snippet will be flagged by path and record ID and will not be reproduced in the synthesis.

## Outputs and preservation

Code, protocols, aggregate tables, reports, schema proposals, source metadata and the proposed registry entry belong in this owned directory. Third-party extracted rows, object crosswalks, text snippets, images and temporary files belong under `data/raw/2026-10-06-evidence-census/synthesis/`. New computed endpoints use dated subdirectories and refuse to overwrite an existing endpoint. The top-level requested output names will be byte copies of the first completed endpoint, with a manifest identifying them. Any post-outcome method change receives a dated amendment here and labels affected results Exploratory. Scripts run from the repository root. No shared files, repository history, publication settings or contacts will change.

## Field clarification and final endpoint, 7 October 2026

The successful v2 and v3 computations remain unchanged. The v3 revision adds exact source-URL register links and checks the saved CISI and selected-count totals. Inspection of museum date strings showed that broad period labels and numerical calendar attributions need separate columns. The v4 endpoint adds `calendar_date_assertion`, defined as a numeral with an explicit era/century/millennium or a French negative-year range. A bare numerical range without an era is unresolved by this rule. Calendar attribution remains distinct from independent dated-sample linkage, whose completeness is not adjudicated for museums.
