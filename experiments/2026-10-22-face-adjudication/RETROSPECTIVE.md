# Retrospective: the 29-face visual review

We selected the fixed 29 rows from the integrated readiness queue and prepared a neutral manifest containing only identifiers, image paths, hashes, dimensions and source locators. The protocol preceded image viewing. We viewed each primary file directly and recorded approximate group bounds in the original image coordinate system. Eight additional views helped distinguish insufficient resolution from a usable layout. One linked file was a narrow side view and did not supply inscription evidence.

The visual-only record was saved and hashed before the first source-code display. The coordinating agent performed a separate visual pass and sealed it before either reader saw the other's decisions. After both seals, we compared the source-code shapes with the images and distinguished catalogue segment location from historical reading traversal. The two contributors agreed on 12 provisional maps; the parent integration remains a separate record.

The additional views changed two layout dispositions. Another enlarged view clarified individual marks without establishing a second row. Composite files and rotated groups required explicit geometry. Several cases remained unresolved despite plausible placements, because unknown codes, surface abrasion or scene details prevented a reliable correspondence.

The first attempt to add one batch of observations to the tool's working store contained an incomplete JavaScript expression and failed before execution. We repeated the complete batch, then checked that the sealed file contained exactly 29 unique observations. No earlier output was overwritten. The source font was already held locally; rendering its encoded glyphs avoided importing the upstream project's proposed readings or translations.

Three supplemental checks inspected printed captions and image payloads directly. They preserve suffixes, repeated-image hashes and the difference between a main face and an inscribed edge. The detailed records remain local because the images and catalogue derivatives have unresolved redistribution rights.

During the final payload check, we moved the authored supplemental observations out of the tracked builder into a local JSON input. The exact first-run builder is preserved locally with the hash already recorded in the result. The public code reads that authored input, while the completed review outputs remain unchanged.

The output contains 21 accepted spatial observations, 12 provisional source-segment maps and 29 unresolved historical traversals. The next source work is expert review of those maps and targeted acquisition for cases that remain undecidable at the present resolution. We have made the geometry explicit enough for that review without replacing the earlier audit.
