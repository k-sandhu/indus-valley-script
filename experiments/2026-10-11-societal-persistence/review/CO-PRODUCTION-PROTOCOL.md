# Post-baseline shared-operation variant

11 October 2026. This amendment was written after the baseline outcomes and the independent review were available, and before this variant's enumeration. The coordinator requested it after the reviewer identified that independently adding repair and teaching effort can count one shared operation twice. It is an exploratory law change, with no independent historical confirmation or parameter calibration.

Keep the baseline state space, safe set, current-skill eligibility, asset aging, skill aging of one per period, renewal/training resets, shock timing and unit shock severity. A selected teacher present at the start can complete the period's operation. The current state is fully observed before an action, and the shock is observed after it. There is no recovery after leaving the safe set.

Only the action cost changes. Cost is the number of selected asset renewals, plus one if training is selected alone. When training accompanies at least one asset renewal, its incremental cost is zero. This stipulates one shared operation producing both restored service and a successor skill resource. It does not establish that historical learning was free, instantaneous or possible during every repair. Training selected alone still costs one, and no nonempty action is allowed when current skill is zero.

Enumerate budgets 0–3 and the four original shock supports, for 16 worlds. Compute possible and robust sets for horizons 0–12 and their infinite greatest fixed points, including complete state sets, the primary state `(2,2,3)` and policy witnesses. Use a new implementation that does not import coordinator or baseline-checker functions. Compare all finite and infinite sets against the frozen coordinator's aging-skill worlds, whose results were independently verified. Record the baseline result hash, this protocol hash and the new code hash. Verify that baseline action choices remain allowed and that no baseline state membership is lost. Report gains without selecting only favorable worlds.

Use a refusing-overwrite CLI and a new `co-production-v1/` endpoint. Preserve the original baseline, checker, sensitivities and counterexamples. Any implementation correction requires a retained attempt and new code/output path. Interpret state counts as memberships in invented worlds, not ancient communities. The purpose is to determine whether a declared shared operation changes the artificial replacement deficit and to sharpen the need for actual task-level cost and learning evidence.
