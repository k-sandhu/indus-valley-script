# Retrospective

We began with the frozen head-direction package and its shortfall in Akkadian and Tamil-Brahmi legends. We froze admission rules before adjudicating candidates and kept the original statistical threshold. Primary Urkesh figures supplied physical carriers for two existing legends; a mixed-language royal legend and a recut damaged seal supplied explicit exclusions.

The current institutional Tamil PDF link failed, but the existing local inventory preserved its earlier bytes. The restored file's title page and page count showed that it was a 2020 preview of the revised edition. Its figure list supplied a new seal target but omitted the catalogue needed to establish eligibility. Text extraction of its legacy fonts was corrupt, so we rendered and read the title and figure-list pages. The 1998 courtier PDF also needs image reading because its text layer is empty. We retained these access and extraction limits with exact source hashes.

An initial console inspection could not print Tamil diacritics through Windows cp1252; subsequent display used UTF-8. No source data were changed by that display failure. We placed source texts, rendered images and detailed candidate records on D: throughout.

This first contribution closes two physical-carrier documentation gaps and narrows the revised Tamil source request to named catalogue pages. It admits no new distinct legend. The next attempt needs those pages or a new primary Akkadian corpus, followed by author-independent reading checks. Acquiring more impressions of the same dies will not close the population gap.
