## Problems and repairs

The first Rangpur PDF guess returned 404. A later search found the original issue, which supplied 222 marked sherds and its speculative absolute chronology. The NIO Bet Dwarka request returned HTTP 200 with a bot challenge; a mirror supplied the paper. A candidate Pirak link pointed to another article and was corrected to the publisher's 1095 record. Direct Changizi PDF guesses failed; the web tool opened the full publisher HTML, while the direct HTTP403 payload was retained. The full Anuradhapura paper, two Tamil Nadu government resources, the IAR download and Bactrian primary collection pages remained unavailable. Counts and exact failure witnesses appear in [retrieval-audit.json](retrieval-audit.json) and the local failure log it links.

The initial acquisition script reused two metadata filenames during OCR processing, replacing their URL/timestamp fields. The PDF bytes remained intact. A separate correction ledger restores the metadata observed in the acquisition outputs, and the script now writes a distinct processing record. An incorrect response-file label for the wrong Pirak target was corrected by searching the preserved URL witnesses; the failure record keeps its previous label and correction note. Unicode output initially encountered Windows encoding errors; subsequent inspection set `PYTHONIOENCODING=utf-8`.

Before computing coverage, the protocol separated calendar strength from the specimen-to-phase grade. This was necessary because a stratified mark can belong to a phase whose absolute dates are weak. The full A+B series and its high/moderate subset were both computed. Conventional radiocarbon labels, old MASCA corrections, calibrated intervals and calibrated midpoints were preserved as different assessments. The coverage method remained unchanged after the first outcome. Supplementary laboratory metadata in [dating-details.json](dating-details.json) extends documentation without changing the endpoint.

A final audit found that the Ahar–Banas/Gilund comparison concerned ceramic links without a verified graffiti image corpus. Documentary revision 02 corrects that flag, adds the unselected conventional Prakash bracket and records the Daimabad laboratory identifiers. The original input/code/protocol snapshot and run 01 were preserved. [revision-audit.json](revision-audit.json) verifies that selected dates, counts and the entire century table are unchanged; only the global image-row count and Central India image count change, from 28 to 27 and from 2 to 1 respectively. The affected source assessments remain Exploratory. Revision 03 also corrected the Ashokan reign start from the assumed 268 BCE to the opened book's 272 BCE and changed its source locator to p. 133. This four-year adjustment stays within the same century bin; run 03 has the same aggregate values as run 02. The dated amendments preserve both earlier input snapshots.
