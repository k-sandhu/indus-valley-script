# Reserved collections and decisive readings

Recorded 20 October 2026. Status class: record. Contributor: Codex, GPT-6 family, desktop harness; the parent backend identifier is not exposed. Three delegated contributors use the explicitly requested GPT-6.1-Sol model.

We are assembling a new object collection and checking the source evidence for inscriptions found outside South Asia. This package coordinates those contributions, checks the existing prediction files and records the next research objectives. It does not read the reserved inscriptions or score a real confirmation set.

## Responsibilities

The acquisition custodian owns `experiments/2026-10-20-fresh-test-collection/` and its local source directory. The custodian selects a site using source access, reported counts, identifier overlap and context coverage, before inspecting inscription content. All candidates receive a disposition. A small or wholly overlapping collection triggers the protocol's recorded fallback, rather than selection for signs that support a prediction.

The foreign-script analyst owns `experiments/2026-10-20-foreign-script-audit/`. A separate GPT-6.1-Sol reader owns `experiments/2026-10-20-foreign-script-blind-review/` and receives a packet without model scores. The analyst disclosed seeing legacy per-object scores during orientation. The independent reader's observations will be frozen before the revised analysis. The revised analysis remains exploratory on previously examined objects.

The parent owns this directory. It reads only the acquisition custodian's safe manifests, aggregate coverage and exposure records. It does not open the new source plates, crops, transcriptions or outcome-bearing metadata rows. Source acquisition and inspection by a custodian are recorded access, not absence of access. The shared filesystem supplies a procedural separation, not an enforced access barrier.

## Reservation rules

1. Preserve the whole acquisition frame, including known objects, uncertain aliases, missing images and incomplete records. Record source identity, coordinates, rights and hashes.
2. Distinguish absence from the pinned export, a distinct physical object, absence from prior project analysis, and absence of a previously seen text. These are separate claims. Missing identifiers do not prove any of the latter three.
3. Keep all faces, copies and impressions related to an object together. Preserve possible identity links until adjudicated. Do not count a second photograph or alternate transcription as a new object.
4. Freeze the recovered collection and its exposure history before a model builder receives it. Curator-visible object data remain local-only. The coordinator receives coverage and custody information, without sign strings, pictures or distributions relevant to predictions.
5. Review every participating prediction and scorer before release. An existing model's hash is not enough: the eligibility rule, comparison, pass rule, dependence treatment and joint rule for related tests must be fixed. All participants sharing confirmation must freeze before the first read through the shared shots loader.
6. The current task reserves material. It does not authorize a confirmation read as part of acquisition. A later study will name the release, verify the frozen files and source history, and log the read. Predictions added after exposure are exploratory on the exposed material.

## Checks and stopping rule

The parent checks existing prediction hashes without importing their scoring modules, opening new observations or changing their files. It exercises the shared loader on generated data only. The collection review checks the custodian's accounting, hash inventory, exposure grades and readiness report. It will report any acquisition shortfall directly, including zero eligible fresh objects.

Source and statistical checks for the foreign study are separate from the reserved collection. The parent reviews its report, source scope, independent annotations and influence checks. Repository checks run without rebuilding generated maps or editing shared data inventories. Earlier and concurrent work stays intact.

The contribution ends with a saved reservation, the completed bounded foreign audit, a review of exact outputs, and a research plan distinguishing work possible with current sources from work needing new physical evidence. The retrospective records observable changes and repairs.
