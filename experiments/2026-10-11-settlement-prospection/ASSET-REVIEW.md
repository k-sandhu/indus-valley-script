# Assets and source reuse

The project redistribution guidance was read before acquisition and packaging. The reusable outputs here are authored narrative, source metadata and bounded observations, calculation code, aggregate results, original plots, editorial rectangles, and commissioned AI review text. No complete downloaded source or source figure is incorporated into the paper. Scientific and institutional titles, pointers and short locators support attribution.

The 50 acquired source witnesses and related extracted text, page images and access failures remain in ignored `data/raw/2026-10-11-settlement-prospection/`. Their source records retain path, size and SHA-256 so a local acquisition can be checked. Those files have unresolved or source-specific rights and were not added to Git. A challenge page retained during acquisition is not a reading witness for the corresponding scientific claim.

Charts are original visualizations of published aggregate facts or explicitly constructed examples. The GeoJSON and coordinate diagram contain authored, coarse regional rectangles and source-linked questions. The PDF reproduces the project's reviewed prose and these original figures. The selected inscription-oriented metadata audit reports aggregates; it carries no raw inscription sequence.

Claude packets contain authored prose, summaries, register observations and aggregate results. The reviews and CLI records retain the requested model, access scope and observable completion metadata. Credentials and account tokens are not included. An invalid environment API key was omitted only for the review child process to use the user's existing Claude subscription; no key value was copied to an artifact.

Targeted ignore exceptions permit the project's generated figures, offline viewer, authored review packets and final PDF. They do not permit downloaded PDFs, HTML, XML or source images in `data/raw/`. The staged print exports and raster pages remain local; authored inspection records retain their hashes and the final PDF allows regeneration. The research task did not publish or submit this new package externally.
