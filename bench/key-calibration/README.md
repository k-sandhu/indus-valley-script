# Key calibration

This task asks whether an independent language model prefers a proposed key over frequency-matched rearrangements of that key. It scores emitted values in bits per value, compares order against an independently shuffled copy of each text, and checks the supplied key on two closure-preserving halves. Whole value-option lists move together in the null, using the eight frequency bands of the published Sanskrit study.

```text
python -m bench key-calibration --synthetic --out experiments/NEW-DATE-my-study/key-synthetic.json
python -m bench key-calibration --corpus data/raw/my-study/objects.jsonl --key data/raw/my-study/key.json --model data/raw/my-study/model.json --other-model data/raw/my-study/rival.json --permutations 999 --out experiments/NEW-DATE-my-study/key.json
python -m bench key-calibration --local-published --out experiments/NEW-DATE-my-study/published-key.json
```

The key is a JSON object such as `{"S1": "k", "S2": ["n", "m"], "S3": ""}`. A string fixes emitted characters; a list supplies alternatives. Lists of token lists support multi-character value labels. The scorer uses the original study's greedy choice among options, so that choice is recorded as part of the key's freedom. Corpus rows carry `signs` or `signs_reading_rtl` and a `component`, `group` or `object_family_id`. Repeated groups and identical complete texts are closed transitively before the half split. Contributors must supply all known physical aliases in the group field.

A model JSON carries `alphabet`, `order` (1–5) and `training`, a list of independent sequences. The imported interpolated Kneser-Ney implementation trains on these sequences. `--word-list` instead accepts one independent word per line and fits order 3. A dense original NPZ model carries `table` and `unigram`; `--alphabet` specifies its original symbol order. Proposed values must belong to that alphabet. Additional models must share the declared projection alphabet, which keeps key freedom fixed across the comparison.

Output gives likelihood, order gain over the model unigram, emitted-value counts, the full aggregate rearrangement score distribution, its quantiles, finite Monte Carlo p-value and distance in standard deviations. It also gives an order-only comparison, both halves' results and supplied rival-model results. The default pass requires p ≤ 0.01 and distance ≥ 3 SD overall and in both halves, plus an order-only p ≤ 0.01. All declarations precede outcome inspection. The half checks evaluate a fixed supplied key; this command does not learn a key from one half. Language identification also requires supplied unrelated models to fail the same separation rule. An externally documented freeze establishes whether these diagnostics are withheld prediction.

Synthetic mode encodes independently generated plaintext using 577 possible homophones into 1,859 distinct short texts. A separately trained model scores the correct, within-band scrambled and random keys, plus a reversed-transition rival model. This generated grammar has its own separation; the output separately cites the original study's true-key separations of 27.38, 33.17, 37.15 and 72.47 SD. Those four published values came from Sanskrit, Latin, Tamil and Sumerian running text under the original synthetic law.
