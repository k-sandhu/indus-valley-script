Methods package

The manuscript combines physical acquisition and known-system controls. Each branch retains its own design, answer keys and source exposure.

Branch Design Current output Checks and research record
PHYS-01 Six positive labels, complete/incomplete physical membership, one count, finite-bag diagnostic Corrected endpoint Review, retrospective

PHYS-01's corrected measurement endpoint supersedes its ownership-count diagnostics; original equations, ranks and old output remain preserved. PHYS-02's interval rule is an explicitly post-outcome refinement tested on fresh worlds. KHI-01 records prior exposure to the published target values and isolates predictor inputs computationally. Its generated answer keys are separate from the source replication.

Reproduction instructions and dependencies are in the branch READMEs and KHI-01 RUNS. Every completed run requires a fresh output directory. The local Python used for most calculations is 3.13, with NumPy and SciPy; endpoint manifests record actual versions. Exact arithmetic certificates form part of the output.

The source package retains original access routes, local paths, source hashes, field coverage and rights observations. Raw acquired khipu data and detailed source vectors are excluded from Git. The redistribution record governs future packaging. The generated controls and our own observations/code are the tracked reproducible part.

Before submission, supply authorship and affiliations, select a venue, resolve source-package access and data-use requirements, and obtain independent review of the archaeological observation design. The computational paper can be reviewed from its declared controls; an Indus value claim would require an eligible physical relation and separate measurement target.
