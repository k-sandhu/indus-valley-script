# The Indus excavation gap

The [manuscript](manuscript.md) asks why far fewer Indus sites have been excavated than recorded, what published area estimates measure, and how investigation could recover overlooked settlement evidence. It compares later-city construction, alluvium, low-relief rural occupation, piedmont and cave contexts, landslides, and changing coasts. The printable version is [the reviewed paper](../../output/pdf/indus_settlement_survey_gaps_2026-10-11.pdf).

The paper, completed on 11 October 2026, is a structured narrative review with descriptive calculations on aggregate counts and an unrun survey design. It cites 69 references from a 72-record register. Twenty-one overlapping hand-drawn regions organize its hypotheses and comparisons. We discovered no new location, analyzed no satellite scene, obtained no field access and fitted no missing-site total.

We froze the first complete draft before commissioning adversarial reviews from Codex and from Claude Code running Opus 5.5. A second Opus 5.5 review through the Claude Code CLI examined the complete revision before the final text. The [response to reviewers](../../experiments/2026-10-11-settlement-prospection/review/response-to-reviewers.md) links findings to repairs and unresolved source questions. These AI reviews are documented with their access limits and are not archaeological peer review.
