# Testing a published Sanskrit key against its own rearrangements

The [manuscript](manuscript.md) evaluates the complete sign-to-sound table behind Yajnadevam's 2024 Sanskrit decipherment of the Indus script on 1,859 distinct complete inscriptions, together with the argument offered for it: that past Shannon's unicity distance, only a correct key could produce readings. Because readers supply the vowels, the key fixes only a consonant skeleton. We measure how predictable that skeleton is, test the dictionary criterion for accepting readings on random strings, and score the key under a Sanskrit language model against rearrangements of its values among signs of similar frequency. We give Latin, Old Tamil and Sumerian the same freedom, build synthetic Indus-shaped encodings to show what a correct key would score, and test whether signs the key reads alike substitute for one another.

The work was done on 12 October 2026 in the [published-claim tests package](../../experiments/2026-10-12-published-claim-tests/README.md), whose Study A was revised after an [adversarial review](../../experiments/2026-10-12-published-claim-tests/sanskrit-key/review/REVIEW.md). The [evidence guide](methods.md) maps each claim to its output. The printable version is rendered locally by [render_paper.py](render_paper.py) to `output/pdf/indus_sanskrit_key_calibration_2026-10-12.pdf`; it is not tracked, because the repository ignores PDFs that are not explicitly listed in `.gitignore`.

Prepared with AI research and writing assistance; author names, affiliations and a submission venue have not been assigned. The study evaluates one key and its argument, and assigns no sound value, meaning or language to Indus signs.
