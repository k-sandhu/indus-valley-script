Figures are generated by `sanskrit-key/make_figures.py` from these outputs. The printable version is rendered by [render_paper.py](render_paper.py) from this manuscript; it rasterizes the SVG figures locally before layout.

The analyses use Python 3.13 with NumPy 2.2 and Matplotlib 3.11. Raw sources (DCS texts, Monier-Williams, Latin, Old Tamil and Sumerian text, the preprints) and per-inscription outputs are kept locally under `data/raw/2026-10-12-decipherment-claim-tests/` and are not redistributed.
