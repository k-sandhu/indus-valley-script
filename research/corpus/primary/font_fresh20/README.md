# Fresh20 source-only drawn-unit pilot

The20 original1979 PDF30 rows were fixed with
`random.Random(20261015).sample` over both columns, rows8–34, then sorted.
Every selected row is retained, including damaged and auxiliary-only rows.
`manual_reference.json` contains96 modern drawn units:91 charted glyph drawings
and5 editorial auxiliary drawings. These counts do not establish ancient
inscription length, words or physical line/side boundaries.

The original chart assigns different stable codes to visually similar full-height
bar drawings. Seven such glyph units preserve ambiguous candidate sets. Three
hatched auxiliary drawings also retain fine-code ambiguity. Large rectangles
in rows1062/1063 represent complete loss of formerly inscribed content, rather
than ancient rectangle signs. Hatched spans retain unknown original sign count.

The full reference was saved and released after root reported its20-row prediction
file complete. No selected-row code, drawn-unit count or glyph detail was sent
to root before that notice. No fresh20 matcher, predictions or automatic
candidates were consulted. Earlier source-only chart comparisons were reused
as locators, and source ambiguity was preserved instead of inferred from context.

Source crops are unchanged original-PDF rasterizations at8x, with selected14–20x
rechecks. Conservative crop bands include neighbouring context; only the
explicitly labelled selected row is annotated. The chart references use the
original chart pages, with zero-based column/row and one-based PDF page numbers.
The primary1979 edition is CC BY4.0 and is attributed to Koskenniemi and Parpola.

This pilot concerns digitization of an existing editorial font. It supplies no
new phonetic or semantic value and no new archaeological inscription. It is an
AI annotation with qualitative confidence, not specialist palaeographic review.
