# Ten-row original-font glyph pilot

`manual_reference.json` preserves source-only AI visual comparisons for PDF30,
printed page29, columns0/1 rows3–7. These are Finnish inscription IDs1018–1022
and1054–1058, not CISI identifiers. The unchanged1979 primary PDF is under
CC BY4.0; its hash, original source crops and direct chart references are recorded.

The annotation contains61 drawn units. Fifty-seven have one qualitative
source-chart assignment. Four retain multiple possible fine codes for bar
drawings. Candidate sets do not assert mathematically identical templates or
epigraphic equivalence. Auxiliary underlines are retained separately and also
constrain the strict candidate sets; shape-only candidate lists show the
additional uncertainty that arises if those annotations are removed.

The source photographs underlying the1979 editorial font were not reannotated
here. A match to its plotted font tests digitization of an existing publication,
not a new reading of ancient objects. Printed rows can combine original object
sides and inscription lines, so their physical traversal boundaries remain
unknown. No phonetic or semantic value is assigned.

The complete reference was released after the root agent reported its ten-row
prediction file frozen. Before that freeze, the root received a partial
description of row1020 and the short paired glyph25; this partial unblinding is
recorded in the reference. The annotator never consulted the font matcher,
predictions or automatic candidates. Root's evaluation must retain that
disclosure rather than describe all ten rows as a fully blind experiment.

The corrected chart-reference location for766 is PDF20 column5 row34. An initial
serialized location column6 row33 was corrected as metadata; candidate codes
and drawn-unit segmentation were unchanged. Wider original page crops were
used to verify column ownership because the PDF21 chart has a different column
pitch from PDF20. Earlier narrow crops can include neighbouring numeric labels
and must not be paired with the preceding drawing by proximity alone.
