# Independent-text context sensitivity

Registered at 2026-10-01 23:53 UTC after the original context results and independent code review, before these sensitivity outcomes. This is a robustness analysis, not a new confirmatory discovery.

The original context study groups exact texts for cross-validation and uncertainty, but its object-wise label permutations assume exchangeable artifact rows within site and length. They break the shared-label dependence that duplicate production cohorts can have. Inverse-frequency weighting does not remove this assumption.

Select one deterministic representative per globally identical principal text, using the source record identifier as the tie breaker, independently of the outcome. Keep an audit of label and site disagreements within each text cohort. Then repeat the fixed logistic comparison and 1,999 permutations within site and length. Include site-by-length interactions in all models. Run the two original outcomes separately.

Repeat after the three independently curated, conservative glyph collapses (861→817, 405→390, 706→705), retaining one representative per collapsed whole sequence. The representative is an artifact chosen by identifier; it does not establish the true canonical archaeological label of a shared text. Results apply to that selection. Report whether sign information survives removal of exact production duplicates, and do not infer what any sign means.

Even unique texts can share workshop, institution, or excavation dependence. This sensitivity addresses exact sequence duplication only; the site-transfer limitation remains.
