# Chart reference records

These records support the attributed 1979 chart work. The [interactive atlas](../../output/chart_atlas/index.html) and its [reference metadata](../../output/chart_atlas/reference.json) identify the source cells, original PDF coordinates, numeric ambiguities and CC BY 4.0 source.

The [source review](../../knowledge/provenance/REDISTRIBUTION.md) defines reuse. Graphic recognition and crosswalk candidates describe the drawings; their relation to phonetic values or meanings is assessed separately in the research reports. This navigation file was added October 11 to resolve an older first-pass link.
