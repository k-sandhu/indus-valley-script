# Fresh original-font glyph pilot

Created after the failed numerical OCR audit and before the ten selected rows' manual glyph assignments or improved matcher outputs. The labels and boundaries from the old prototype are not accepted observations.

The source is Koskenniemi and Parpola (1979), official CC BY 4.0 edition, PDF page 30. Score both zero-based text columns, rows 3 through 7: printed IDs 1018–1022 and 1054–1058. The corpus agent independently reads the original images and compares graphics to the original sign chart. It does not inspect matcher outputs. Preserve alternative stable codes, uncertainty auxiliaries, and doubtful boundaries. A printed row may combine physical sides or lines, so no original-surface interpretation is assigned.

Replace the failed OCR numeric labels with manual source readings, retaining independent corrections and unresolved numeric alternatives. Match glyph shapes using image geometry only; no sign-frequency, language, proposed meaning or sequence model is used. Preserve template alternatives when identical drawings have different auxiliary codes. Test a preregistered per-glyph segmentation penalty grid (0.5,1,2,4) as an exploratory development comparison, not a selected held-out endpoint. Report every variant and every selected row, including failures and unmatched ink. The independent manual annotations are held out until outputs are saved.

This is a small acquisition/recognition pilot on the same historical corpus. It does not establish an independent archaeological corpus, phonetic value, or semantic reading. Numeric chart reference quality and glyph extraction quality are separate questions.
