# Original outputs (frozen)

This directory holds the result files of the first investigation's studies: restoration and its site-held, collapsed and superseded variants, gap restoration, identifiability, the independent annotator, microcontext, paired surfaces and context. They were committed on 2 October 2026 and have not changed since. [REPRODUCING.md](../REPRODUCING.md) names the script in `src/` that produced each one. Papers and registry entries cite these files as evidence, so they stay as they are, and a rerun writes to a new location.

New outputs go in a new dated package, `experiments/YYYY-MM-DD-short-slug/`. New reusable code goes in [bench/](../bench/) for shared evaluation or [tools/](../tools/) for repository operation.
