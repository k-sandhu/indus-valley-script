# Public repository asset review

The user explicitly requested public visibility on October 11, 2026. Before that change, the current payload and reachable Git history were screened and source-bearing files were inspected. The [initial audit](audit-initial.json) covered 15,616 selected files and 14,306 reachable blobs. Known token formats and private-key headers had zero matches. That bounded signature result does not certify arbitrary strings as harmless.

The [expanded screen](expanded-payload-review.json) identified twelve payloads for review. The graph/slot mapping, overlapping-form and reference-selection arrays belong to synthetic generated worlds. Their source code and generated-unit labels distinguish them from acquired observations. The 3,000 Q-code workflow records are synthetic. Font prediction arrays are authored assessments of the licensed 1979 chart. The north-India quotation fields are repeated six-word placeholders. The Bonta claims ledger contains seven small source quotations across distinct sources and predominantly authored summaries. These were retained with their existing citations.

The large numerical/khipu JSONL files inspected in this package describe synthetic units, models and simulations. Acquired khipu source data stays in the ignored local source tree. Public size screening uses a 90 MiB per-file limit; no selected file exceeded it. Large frozen authored simulations are retained as evidence, rather than deleted to make the folder look smaller.
