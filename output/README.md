# Original reports and chart atlas (frozen)

This directory holds the first investigation's report, figures, chart atlas, environment record and evidence manifest, committed on 2 October 2026. On 13 October two later items were added to `pdf/`: the 11 October settlement-survey report and the layout record of the 12 October key-calibration report. Papers, the website and [REPRODUCING.md](../REPRODUCING.md) link to these paths, so the files stay as they are.

New reports and outputs go in a new dated package, `experiments/YYYY-MM-DD-short-slug/`, and manuscripts in [papers/](../papers/). New reusable code goes in [bench/](../bench/) for shared evaluation or [tools/](../tools/) for repository operation.
