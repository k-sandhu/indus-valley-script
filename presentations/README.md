# Presentations

These folders hold slide decks, maps and visual summaries built from results already recorded in [experiments/](../experiments/). They add no new data or claim; each one links the studies it draws on. The folders moved here from `experiments/` on 28 October 2026 with their contents unchanged, apart from links repaired for the new location. Decks and images built from third-party sources stay local where their rights require it, so some folders keep only the builder code and manifests.
