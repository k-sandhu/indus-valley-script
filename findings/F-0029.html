F-0029: Seals sharing a text share their animal almost only when it is a unicorn

status class
exploratory
area
seals

Finding

Among 130 pairs of identical-text seals with an animal recorded on both, 89 show the same animal, and 88 of these are unicorn pairs. Of 42 pairs involving another animal, only 1 shares it.

Evidence

  • experiments/2026-10-12-seal-text-identity/run-2026-10-12/review-response.json, JSON field /E_motif_pairs/pairs_with_both_motifs.
  • experiments/2026-10-12-seal-text-identity/run-2026-10-12/review-response.json, JSON field /E_motif_pairs/same_motif.
  • experiments/2026-10-12-seal-text-identity/run-2026-10-12/review-response.json, JSON field /E_motif_pairs/unicorn_unicorn.
  • experiments/2026-10-12-seal-text-identity/run-2026-10-12/review-response.json, JSON field /E_motif_pairs/pairs_involving_non_unicorn.
  • experiments/2026-10-12-seal-text-identity/run-2026-10-12/review-response.json, JSON field /E_motif_pairs/same_motif_among_non_unicorn.
