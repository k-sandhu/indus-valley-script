F-0011: Two codings of the signs into families agree closely

status class
verified computation
area
images

Finding

Two codings of 577 sign codes into graphic families agreed with adjusted Rand index 0.884 unweighted and 0.975 weighted by occurrences; the index is one for identical groupings and near zero for chance.

Evidence

  • experiments/2026-10-12-structure-first/step1-signs/run-2026-10-12/summary.json, JSON field /coder_agreement/ari_unweighted.
  • experiments/2026-10-12-structure-first/step1-signs/run-2026-10-12/summary.json, JSON field /coder_agreement/ari_token_weighted.
  • experiments/2026-10-12-structure-first/step1-signs/run-2026-10-12/summary.json, JSON field /coder_agreement/codes_compared.

Scope

Both coders were instances of the same AI model working from sheets in code order, so a human coding from shuffled sheets is the proposed independent check.
