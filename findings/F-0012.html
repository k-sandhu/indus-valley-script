F-0012: Grouping signs by their added marks does not improve prediction

status class
failed
area
structure

Finding

Grouping signs by modifier signature, the added marks (such as inner marks, doubling or hatching) a sign carries on any base shape, did no better than random groupings of the same sizes (p = 0.11).

Evidence

  • experiments/2026-10-12-structure-first/step1-signs/run-2026-10-12/summary.json, JSON field /grouping_tests/modifier_signature/p_value.
  • experiments/2026-10-12-structure-first/step1-signs/run-2026-10-12/summary.json, JSON field /grouping_tests/modifier_signature/passes.

Scope

The test predicts codes in Wells's sign list on held-out texts. The failure concerns this coding scheme and population.
