F-0013: Base-shape families improve prediction of signs unseen in training

status class
frozen evaluation
area
structure

Finding

For held-out signs whose code never occurs in training, falling back on the base-shape family lowered loss from 14.60 to 14.19 bits per sign.

Evidence

  • experiments/2026-10-12-structure-first/step1-signs/run-2026-10-12/summary.json, JSON field /grouping_tests/B_coder1/by_training_frequency/seen0/tokens.
  • experiments/2026-10-12-structure-first/step1-signs/run-2026-10-12/summary.json, JSON field /grouping_tests/B_coder1/by_training_frequency/seen0/baseline_bits.
  • experiments/2026-10-12-structure-first/step1-signs/run-2026-10-12/summary.json, JSON field /grouping_tests/B_coder1/by_training_frequency/seen0/class_bits.

Scope

These are held-out signs whose exact Wells code is absent from the training fold. The comparison is the ungrouped Kneser–Ney bigram baseline. The published Parpola and Mahadevan groupings are scored separately in the same output.
